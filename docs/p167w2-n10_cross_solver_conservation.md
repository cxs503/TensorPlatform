## ① 案例介绍（物理背景 / 几何 / 参数）

多物理耦合的"最后一公里"不是解算器，而是**交接面**：FEM 单元断裂后把断裂面交给 DEM 生成碎块、
LBM 把格子场交给 FVM、两个解算器按各自的 dt 推进。三处交接若账目不平，泄漏的能量或质量会在后续
每一步被当成物理源项，且**不可与真实物理区分**。本节点把三类交接各自做成可机器裁判的守恒/语义账本。

几何与参数（全部合成，零领域语义）：

| 面 | 几何 | 参数 |
|---|---|---|
| FEM→DEM | 立方实体单元，边长 1，密度 1 | 初速 v=(1, 0.5, 0)，角速 ω=(0.2, −0.4, 0.6)，断裂释放应变能 U=0.3；断裂面由 1/3/6 个平面切出（2 / 8 / 28 个碎块） |
| LBM→FVM | 源：8³ 立方格子 h=0.1；目标：4³ 体积元 H=0.2（同一物理域 [0,0.8]³） | ρ=1+0.4 sin(2πy)cos(2πz)，u=(1+0.5 sin2.5y cos3z, 0.2 sin3y, 0)；耦合面 Γ: x=0.4 / x=0.37 / 斜平面 (x+y)/√2 |
| 时钟 | 双解算器 ODE 状态（标量），dt_A=0.02，dt_B=0.01 | 采样周期 0.1（5 步），时域 1.0，乐观前瞻 1 个采样周期 |

## ② 怎么做的（方法 / 流程 / 工具链）

**几何内核（`geometry/polytope.py`）**：凸多面体以顶点 + 半空间表示，体积/质心/惯性张量由
四面体分解的闭式矩精确求得（`∫_T xxᵀ dV = V/20(Σv_kv_kᵀ + ssᵀ)`，s=Σv_k），
四面体体积、剖分加和即得整体量；盒体走解析路径（无 Qhull 调用），耦合面截面走
"边–平面裁剪 + 平面内 shoelace" 精确路线。

**FEM→DEM 四账本**：消费 `failure_faces.json`（顶点 + 外法向 + 面积），用面所在平面逐次切分单元得到
**真实凸碎块**（不是等效球），按刚性运动给初速 `v_i = v + ω × d_i`，并把释放的应变能投入
**质心无污染膨胀模态** `u_i = α d_i, α = sqrt(2U/Σm_i|d_i|²)`——由质心恒等式得
`Σm_i u_i = 0`、`Σ m_i d_i × u_i = 0`、`Σm_i v_i·u_i = 0`，故能量账可闭合而动量/角动量账不受扰动。
四账本（含角动量和全张量）= 质量、线动量、角动量、能量，另加体积（剖分自证）。

**LBM→FVM 通量**：库存用**体积重叠超网格** remap（`φ_j = Σ_i φ_i V_ij / V_j`，V_ij 为凸多面体交集体积）；
耦合面通量用**面积权重**算子（`Φ_j = Σ_i ρ_i(u_i·n)A_ij`，A_ij = Γ∩cell_i∩cell_j 的面积），
并规定"平面恰与某个面重合时截面归上游单元"，避免双重计数。

**时钟语义**：保守=屏障（慢者优先，禁止读未提交数据，审计屏障偏差与未来读）；
乐观=快者优先 + 前瞻插值，真实样本到达时回滚重放（检查点 + 确定性重放），
验收陈述是**重放等价**：`state(乐观+回滚) ≡ state(确定性重放)`。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **"不能失败的门"比没有门更危险**。原有 LBM→FVM 通量检查对每个单元的六个面求 `ρu·n`（恒为 0），
   且 FVM 侧读的是不存在的 `density` 属性（`hasattr` 守卫使之为 0），因此**任何场**的残差都是 `|0−0|/0 = 0`，
   永远 PASS。本节点把它替换为同域质量库存恒等式，并新增"平移目标网格必须 FAIL"的负控测试。
   由此暴露出原测试夹具的 FVM 网格与 LBM 网格**覆盖不同物理域**（偏移 0.02），已一并修正。
2. **等效球碎块过不了张量账**。球惯量各向同性，只能对 trace 做文章；一旦单元各向异性，全张量残差
   0.85、角动量残差 1.06（>15% 不可接受区）。凡"只比 trace"的惯量校验都应视为弱判据。
3. **耦合面与单元面重合会双重计数**：截面必须只归上游单元，否则 Φ 恰好是物理值的 2 倍。本节点用
   "顶点全在下游侧则该单元截面记 0"的归属规则处理，并用重合面/单元内/斜面三种取向分别验证。
4. **dV/dh 求截面只在多面体面断点外精确**：水平集路线在平面穿过顶点处有折点，中心差分给平均值而非真面积
   （曾导致 2.4e-5 的伪截面）。因此改为 shoelace 精确路线，水平集仅作独立交叉校验（一致性 2.04e-05）。
5. **回滚必须回滚状态，不只是时钟**。既有 `SyncState.rollback_solver` 只改时间戳，乐观耦合会静默地
   用错误的历史继续算；节点内改用"检查点 + 确定性重放"，并用重放等价（残差 0）作为验收。
6. **局限**：(a) 几何限凸多面体（非凸碎块需再分解）；(b) 超网格交集体积是 O(N_pair) 的显式求解，
   大网格需空间哈希/八叉树（当前盒–盒走解析快路径，通用多面体仍走 Qhull）；(c) 截面面积对
   "平面恰好穿过顶点"的退化情形按 0 处理；(d) 时钟审计是标量 ODE 模型，未覆盖真实解的守恒量漂移。
7. **平台侧登记**：能力卡 `docs/capability_registry/cards/CAP-007-*.json` 已按
   `docs/capability_card.schema.json` 校验通过；该 schema 的 `discipline` 枚举是领域词表
   （本平台"零领域语义"铁律的既有债务），故中立能力登记为 `reporting`，此处如实记录。

## ⑥ 误差判定（关键量 vs 基准，逐项回答"是否 <3%"）

基准=解析恒等式（源侧积分）与确定性重放，不是文献值；因此"误差"是账目残差，可判到舍入误差量级。

|---|---|---|---|

| 线动量账 Σ(mv) vs Mv | 解析 | 2.91e-13 | 是 |
| 角动量账 Σ(Iω + d×mv) vs I_element ω | 解析 | 1.97e-13 | 是 |
| 能量账 Σ(½mv²+½ωIω) vs T+U | 解析 | 2.01e-13 | 是 |
| 惯量全张量 Σ(I_i+m_i(|d|²1−dd)) vs I_element | 解析 | 1.75e-13 | 是 |

对照的**既有做法**（说明精确路径确实带来改进，而不是换个写法）：

| 既有做法 | 指标 | 相对误差 | 是否 <3% |
|---|---|---|---|
| 等效球碎块 | 惯量全张量 | 8.49e-01 | **否（85%，远超 15% 不可接受线）** |
| 等效球碎块 | 角动量 | 1.06e+00 | **否（106%）** |
| 逆距离（胞心采样） | 耦合面通量（最差取向） | 7.44e-03 | 是（0.74%），但**不随网格干净收敛**（实测衰减阶 0.18–0.42），且取向相关；以精确算子为验收 |

结论：本节点面向的九项关键量全部通过机器判据（残差 ≤ 1e-12 量级），**全部 <3%**；
既有等效球替代模型在两本账上（85% / 106%）处于"不可接受"区，已由精确几何路径取代并留作回归守护。
诚实声明：网格研究里逆距离基线的衰减阶（0.18–0.42）不是干净的一阶，本报告不宣称理论阶数，
只陈述实测值；时钟审计为标量 ODE 模型，未覆盖真实解的长期守恒量漂移。
