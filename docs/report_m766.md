## ① 案例介绍（物理背景 / 几何 / 参数表）

### 物理背景

碎冰水域中船舶运动响应（RAO）受冰-船碰撞引起的附加阻尼和附加质量影响。本模块（`backend/services/ship_performance/seakeeping/broken_ice.py`，由 mission 766 创建）实现了以下物理机制：

1. **敞水基线**：切片理论参数化模型（Franck 附加质量近似 + Smith 衰减效应 + Froud-Krylov 激励）
2. **碎冰碰撞**：逐 floe 事件驱动冲量模型（Hertz 接触 + 恢复系数）
3. **平均场近似**：碰撞频率 × 单次动量传递 → 等效附加阻尼/质量
4. **阻尼反演**：对数衰减率法从自由衰减信号提取阻尼比

参考文献：
- Lubbad & Løset (2015), "A numerical model for ship–ice interaction"
- Metrikin (2014), "A frequency domain model for ship motions in ice"
- Tsai et al. (2021), "Added resistance and damping from broken ice"

## ② 方法 / 流程 / 关键设置

### 2.1 敞水 RAO 基线

频率域线性理论，垂荡运动方程：

$$[-\omega^2(M + A_{33}(\omega)) + i\omega B_{33}(\omega) + C_{33}] X_3(\omega) = F_3(\omega)$$

- **附加质量** A₃₃(ω)：Franck 近似的频率依赖插值，低频极限 A₃₃(0) = 1.0·M，高频极限 A₃₃(∞) = 0.5·M
- **辐射阻尼** B₃₃(ω)：共振峰参数化模型，峰值 B₃₃_max = 0.15·M·ω_n
- **激励力** F₃(ω)：Froud-Krylov + Smith 衰减效应（exp(-kT/2)）
- **静水恢复力** C₃₃ = ρgA_wp

### 2.2 碎冰碰撞模型

Hertz 接触力 F = k·δ^(3/2)，冲量 J = (1+e)·μ·v_rel

- 约化质量 μ = M·m_floe / (M + m_floe)
- 动量守恒：M·V₀ + m·v₀ = M·V₁ + m·v₁
- 恢复系数定义：v₁ - V₁ = -e·(v₀ - V₀)
- 动能损失恒等式：ΔKE/KE₀ = (1-e²)

### 2.3 平均场附加阻尼

$$B_{ice}(\omega) = f_{coll} \cdot m_{floe} \cdot (1+e) / \omega$$
$$A_{ice}(\omega) = c \cdot \rho_{ice} \cdot h \cdot A_{wp} \cdot \alpha(\omega)$$

碰撞频率 f_coll 正比于浓度 c 和特征频率 ω。

### 2.4 对数衰减率法

$$\delta = \frac{1}{n}\sum \ln(x_i/x_{i+1}) = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}}$$

反演：ζ = δ / √(4π² + δ²)（精确恒等式）

## ⑤ 注意点 / 局限

1. **平均场近似**：本模型使用碰撞频率的平均场近似，未解析单个 floe 的离散碰撞时序。适用于浓度 c > 0.1 的密集碎冰场；稀薄冰场（c < 0.05）需离散事件模拟。
2. **Hertz 接触假设**：假设 floe 为弹性半空间接触，适用于中等碰撞速度（v_rel < 5 m/s）。高速碰撞需考虑冰的破碎 / crushing。
3. **频率无关附加阻尼**：当前模型中 B_ice 近似与频率无关（碰撞率正比于 ω，除以 ω 后消去）。更精细模型应考虑碰撞持续时间的频率依赖性。
4. **仅垂荡完整**：当前仅实现垂荡（heave）RAO 的完整冰效应；纵摇（pitch）的冰效应为简化处理。
5. **无冰脊效应**：模型假设均匀 floe 场，未考虑冰脊（ridge）或冰帆（sail）的额外阻力。
6. **无实验对标**：本模块为理论/数值模型，尚无实验数据对标。误差判定仅针对内部自洽性（守恒律、极限行为），不涉及绝对精度。
