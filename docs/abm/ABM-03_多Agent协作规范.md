# ABM-03 · 多 Agent 协作规范（五角色 × 挑战者独立判断权 × 多路线竞争）

> 规范族 ABM 第 3 件。上位文件：`ABM-00_总纲.md` §3.4（交叉验证）/ §3.5（对照实验）/ §6（认知支架）。
> 本件规定：五角色职责、挑战者的独立判断权、多路线并行竞争的统一六维评价。
> 配套：假设登记与预测盲见 `ABM-04`；独立审查（S3+ 硬门）见 `ABM-05`。

## 1. 五角色职责表

| 角色 | 职责 | 输入 | 产出 | 禁止 |
|---|---|---|---|---|
| 攻关负责人 | 定问题、定验收、排七环、裁决分歧（走区分实验）、对最终 S×E 申报负责 | 任务单、基线报告 | 问题陈述、验收标准、验收申报 | 自批自己的成果（机制 C）；跳过准入门 |
| 理论研究者 | 物理/数学依据、解析解、量纲与守恒律、极限行为 | 问题树 M1/M2 层 | 理论依据（假设五件套第 1 件）、解析参考 | 无出处的断言；把猜测当理论 |
| 实现工程师 | 按假设五件套实施修改、跑实验、落原始数据 | 假设登记、基线报告 | 代码 + 测试 + 原始结果 + 实验配置 | 无假设修改；事后改预测 |
| 挑战者 | 独立质疑假设/实验/结论；有独立判断权（§2） | 假设登记、实验结果（盲序优先） | 挑战意见（引数字/工件路径）、区分实验设计 | 沦为帮作者完善方案；投票式和稀泥 |
| 独立验证者 | 按公开配置独立复现；盲序复算；S3+ 独立审查（ABM-05） | 工件 + 配置（不含作者结论） | 复现记录、审查 verdict + grade_reason | 与作者共享凭据互评；复现失败不报 |

**同一灵魂可多执行分身，独立判断工作必须不同知识结构与评价视角**（总纲 §6）：
挑战者/独立验证者必须使用与实现工程师**不同的专业知识包**（理论包/验证包/挑战者包），
S3+ 还须不同模型族（ABM-05 §2）。

## 2. 挑战者独立判断权

1. **独立判断权**：挑战者对「假设是否成立、实验能否裁决、结论是否过度」有独立判断权，
   其意见不隶属攻关负责人；挑战者可以否决「进入验收」，负责人不得以排期为由绕过。
2. **不是帮作者完善方案**：挑战者的产出是「哪里不成立 + 凭什么」，不是「怎么改更好」的善意建议。
   善意建议可以附，但否决理由必须独立成立。
3. **分歧不投票**：不同结论不用投票裁决——设计能区分不同假设的实验（总纲 §8 原则 2）。
   区分实验设计由挑战者与理论研究者共同提出，实现工程师执行，数据裁决。
4. **常设化**：挑战者席位常设（总纲 §10：红队 D/E + E5 盲序复算为既有资产），
   每个 S≥S2 的攻关任务至少一次挑战记录。
5. **免责与激励**：挑战者提出后被证伪的质疑不计其失败率；发现真实缺陷计入缺陷发现率
   （七指标，ABM-06 §3）——缺陷发现者不算低产出。

## 3. 多路线竞争与统一六维评价

**路线**（至少两条并行，高难任务三条）：
- 路线 A：修正现有（在现有代码/方法上改）
- 路线 B：换数值方法（格式/离散/求解器层面替换）
- 路线 C：参考成熟开源重构（以成熟开源为参照重建）

**统一六维评价**（所有路线同一张表，证据定胜负，**不按 PR 先后**）：

| 维 | 判据 | 数据来源 |
|---|---|---|
| 正确性 | 守恒量闭合、边界行为、单元测试 | 测试输出（工件路径） |
| 精度 | 关键量 vs 参考值误差（逐项，显式回答是否 < 声明容差） | 对照实验原始数据 |
| 稳定性 | 长时间积分/扰动敏感性/能量行为 | 稳定性实验数据 |
| 计算效率 | 单位精度成本（时间/核时/内存） | 计时日志 |
| 可复现性 | 第三方按公开配置复现成功率 | 独立复现记录 |
| 适用范围 | 声明边界 + 越界行为 | 适用性实验 |

**裁决规则**：
1. 六维全表填齐（缺维须声明原因）才可比；
2. 胜负由证据定：任一维显著劣化须显式列出，不得以局部指标掩盖整体退化（SPEC v1.2 §7.1 规则 4 精神）；
3. 平局 → 设计区分实验（回到 ABM-01 R5），不得按 PR 先后/代码量/完成时间定胜负；
4. 落选路线的失败分析进失败知识库（ABM-06 §2），标注「已证无效路径」。

## 4. 协作协议

1. **交接**：角色间交接必须经工件（登记条目/工件路径），不靠对话上下文传递结论。
2. **黑板**：共享状态（问题树状态、假设登记、六维表）落平台数据结构，append-only 优先。
3. **冲突升级**：角色间无法裁决的分歧 → 机制 D 动态升级（ABM-06 §4）：请求更强 Agent/领域专家/重分配。
4. **知识包差异化**：六支架按角色差异化配发（总纲 §6）——专业知识包/标准攻关流程/专业工具/
   专家示范案例（优秀+失败各带分析）/独立质量审查/组织知识库。
