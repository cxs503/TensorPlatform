# ABM-04 · 实验与证据规范（假设登记 × 预测盲 × 证据五元链）

> 规范族 ABM 第 4 件。上位文件：`ABM-00_总纲.md` §3.3（假设驱动）/ §5 机制 B（证据驱动）。
> 本件规定：假设登记的字段、预测盲规则、证据五元链的结构化落库。
> 配套：假设五件套语义见 `ABM-01` §4；证据等级 E0-E4 定义引 SPEC v1.2 §6.2，不重定义。

## 1. 假设登记字段

每个假设一条登记（结构化实体，落平台数据结构，append-only）。字段：

| 字段 | 类型 | 要求 |
|---|---|---|
| hypothesis_id | string | `<任务ID>-H<序号>`，唯一 |
| statement | text | 假设陈述（可证伪句式：「若 X 则 Y，否则 Z」） |
| theory_basis | text+ref | 理论/文献依据（引出处）；探索性猜测显式标注 |
| code_location | text | 文件/函数 或 新增模块契约 |
| falsification_design | text | 证伪实验设计：什么结果证伪（可判定失败判据） |
| prediction_before | number/text | 修改前预测值 |
| prediction_after | number/text | 修改后预测值 |
| registered_at | timestamp | **登记时间戳（必须早于实验启动时间）** |
| experiment_ref | ref | 实验配置/运行 ID |
| raw_result_ref | ref | 原始计算结果工件路径 |
| verdict | enum | 证实 / 证伪 / 部分 / 未裁决 |
| verdict_data | ref | 裁决数据指针（零手抄，SQL/工件溯源） |
| registered_by | agent | 登记者 |

**完整性规则**：`registered_at < experiment_start` 不满足 → 该假设按「未 prereg」处理，
其证据等级上限 E1（只能作候选，不得支撑 S≥S2 申报）。

## 2. 预测盲规则

1. **先登记后实验**：预测（prediction_before/after）必须在实验启动前登记；
   先例：EX-1 水池锚 prereg（总纲 §10）。
2. **盲序**：独立验证者/挑战者接触结果时优先盲序（不知作者结论与路线归属）；
   既有资产：复现官 m591（盲序/append-only/strike）、E5 盲序复算。
3. **append-only**：登记条目只增不改；事后改预测 = 证据链断裂，该假设 verdict 强制「未裁决」
   并记 strike（沿用 m591 机制）。
4. **通用化**：本规则适用于一切「修改前后对照」实验，不限于水池锚场景。
5. **违反后果**：事后补登记/改预测 → 该假设相关结论证据降级 + 申报诚实度入信用档案
   （SPEC v1.2 §7.1）。

## 3. 证据五元链

每个关键结论必须可追溯到五元（缺一元 = 结论不可登记，最多 E1）：

| 元 | 内容 | 来源 | 落库位置 |
|---|---|---|---|
| 1 理论或文献依据 | 该结论依赖的理论/文献 | 文献条目/理论推导工件 | 假设登记 theory_basis |
| 2 代码版本 | 产生结果的代码版本 | git commit SHA | 实验配置 |
| 3 实验配置 | 参数/网格/边界/求解器设置 | 配置文件（可复现） | 实验配置工件 |
| 4 原始计算结果 | 未加工的原始输出 | 运行日志/数据文件 | runs/ 工件（sha256 入 provenance） |
| 5 分析报告 | 从原始结果到结论的推导 | 报告（判据数字程序化注入） | 报告工件 |

**链完整性检查**（机器可裁）：
- 五元 ref 全非空；
- 第 4 元工件 sha256 与 provenance 一致；
- 第 5 元报告中每个关键数字可回指第 4 元（零手抄纪律）。

## 4. 证据等级（引 SPEC v1.2 §6.2，不重定义）

| 级 | 语义 | 数值仿真领域示例 |
|---|---|---|
| E0 | 纯声明 | 任务描述层，不足以登记任何 S 级 |
| E1 | 可检查 | 有制品/日志/来源，未充分验证 |
| E2 | 工程验证 | 回归测试与收敛性检查通过 |
| E3 | 结果验证 | 对独立来源解析解/实验锚在声明容差内 |
| E4 | 可复现推广 | 第三方按公开配置独立复现成功 |

**S×E 合法组合**（SPEC v1.2 §7.1 规则 8/9）：任何等级登记须 E≥1；S4 须 E≥2 且附对照基线；
S5 须 E≥3 方为已确认成果；非法组合（如 S4/E1）只计候选，不计入成果统计。

## 5. 与证据门的接口

- 证据门（既有资产，总纲 §10）：结论过门时校验五元链完整性；
- 缺口（总纲 §10）：五元链结构化落库 = plan 143 A3 节点交付物，本件即其规范依据。
