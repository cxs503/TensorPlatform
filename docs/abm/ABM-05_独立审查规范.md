# ABM-05 · 独立审查规范（S3+ 即 L3+ 强制独立审查，不同模型族）

> 规范族 ABM 第 5 件。上位文件：`ABM-00_总纲.md` §5 机制 C（独立审查）/ §4（L≡S 标尺统一）。
> 本件规定：独立审查的适用范围、模型族隔离、审查流程与硬门。
> 配套：S×E 定义引 SPEC v1.2 §6.2/§7.1，不重定义；分级映射见 `ABM-07`。

## 1. 适用范围

| 成果等级 | 独立审查要求 |
|---|---|
| S1（L1） | 执行前检查 + 事后复核（抽检） |
| S2（L2） | Execution Audit 必做（尽量自动化）；须对照基线 |
| **S3+（L3+）** | **强制独立审查**（本件硬门）；四类审查全做（SPEC v1.2 §7.1） |
| S4/S5（L4/L5） | 双独立评审 + 盲序 + 新颖性检索记录 |

**执行 Agent 不得自批自己的成果**（机制 C，总纲 §5）：申报 Agent 与审查 Agent 必须不同实例，
且不得共享凭据互评（SPEC v1.2 §18 红队攻击路径之一）。

## 2. 不同模型族（S3+ 强制）

1. **定义**：模型族 = 同一基座模型及其微调/同厂商同代系。不同模型族 = 不同基座
   （如不同厂商/不同代际的基座）。
2. **强制**：S3+（=L3+）成果的独立审查必须由**与执行 Agent 不同模型族**的 Agent 执行。
   同族审查只能作辅助意见，不能替代。
3. **理由**：同族模型共享盲区（同一训练分布的同类错误）；不同模型族提供真正的认知多样性
   （总纲 §6：组织一百个相互补充、相互质疑的认知单元）。
4. **登记**：审查记录必须写明审查者模型族标识；缺标识 = 审查无效，成果不得登记。
5. **既有资产**：复现官 m591（盲序/append-only/strike）、红队 D/E（§18）、E5 盲序复算
   （总纲 §10）——本件将其常设化为 S3+ 硬门（plan 143 A5）。

## 3. 审查流程

**输入**（审查者拿到且只拿到这些）：
- 五元链（ABM-04 §3）：理论依据/代码版本/实验配置/原始结果/分析报告；
- S×E 申报（申报等级 + grade_reason 草稿）；
- 对照基线（S2+）/ 突破声明（S4）/ 新颖性检索范围（S5）。

**审查动作**：
1. 链完整性：五元 ref 全非空、sha256 一致、数字可回指原始结果；
2. 判据核对：关键量 vs 基准误差逐项核对，显式回答「是否 < 声明容差」；
3. 定级核对：申报 S 级与证据是否匹配（S2 有比较依据？S3 能力真实可用 + Delta 登记？
   S4 说清突破了什么？S5 新在哪里？）；
4. 独立复现（S3+ 必做）：按公开配置复跑关键实验，结果与申报一致。

**输出**：
- verdict：通过 / 打回（回 R3/R4/R5）/ 降级（S 级下调）；
- grade_reason：**必须引具体数字/工件路径**，空话 = 降级（评价纪律，owner 2026-11-07 令）；
- 审查者模型族标识 + 审查时间戳。

## 4. 硬门（机器可裁）

- S3+ 成果登记时校验：存在独立审查记录 ∧ 审查者模型族 ≠ 执行者模型族 ∧ grade_reason 含数字/路径；
- 不满足 → 成果停留在「候选」，不计入成果统计（SPEC v1.2 §7.1 规则 9 精神）；
- 门必须可失败：无法被红队击穿的恒真门视为未实现（SPEC v1.2 §18）。

## 5. 审查者激励与保护

- 审查者发现申报虚高 → 计入缺陷发现率（ABM-06 §3），不算低产出；
- 审查者误判（放行了后被证伪）→ 记入审查质量统计，不追溯惩罚单次误判，
  但系统性失察触发机制 D 动态升级（换审查者/补知识）。
