# ABM-06 · 能力成长规范（三资产 × 失败知识库 × 七指标 × 动态升级 × 二期预留）

> 规范族 ABM 第 6 件。上位文件：`ABM-00_总纲.md` §3.6（失败分析）/ §3.8（知识复用）/
> §5 机制 D（动态升级）/ §5 机制 E（能力评价）/ §7（强弱传递，二期）。
> 本件规定：知识沉淀的三资产、失败知识库字段、七指标口径、动态升级触发条件、二期强弱传递预留。

## 1. 三资产（每次攻关必沉淀，全进平台，不留对话上下文）

| 资产 | 内容 | 格式要求 | 落库位置 |
|---|---|---|---|
| 知识资产 | 理论/方法/规律（含适用边界） | 陈述 + 依据（文献/推导工件）+ 边界声明 | 组织知识库（PLAYBOOK 判例/战史官 chronicle 既有面） |
| 工具资产 | 代码/测试/验证器 | 可运行 + 测试过 + 契约文档 | 领域仓（对应 Tensor* 仓）+ 能力台账 |
| 经验资产 | 成功路径/失败案例/判断规则 | 成功路径=可复用步骤序列；判断规则=「若…则…」句式 | 组织知识库 + 失败知识库（§2） |

**登记要求**：资产条目带来源任务 ID、证据等级、复用计数（被后续任务引用时 +1，
S-N 被引用计入复用统计，SPEC v1.2 §7.1）。

## 2. 失败知识库字段

失败记录结构化（总纲 §3.6），字段：

| 字段 | 要求 |
|---|---|
| failure_id | `<任务ID>-F<序号>` |
| initial_hypothesis | 最初假设（引 hypothesis_id） |
| what_failed | 哪个不成立（假设/前提/边界条件） |
| which_stage | 哪环节（七环 R1-R7 定位） |
| error_class | 理论错 / 实现错 / 实验设计错（三选一，可多选须说明） |
| ruled_out_paths | 已证无效路径（后来者直接跳过） |
| avoid_next | 后续避免什么（可执行建议） |
| evidence_ref | 裁决数据指针（零手抄） |
| reusable | 是否可复用为注入知识（bool + 说明） |

**纪律**：honest FAIL 不可覆盖（append-only）；失败探索可形成 S-N 否定性成果
（SPEC v1.2 §7.1），计入 §15 Productivity 维度，不惩罚诚实。

## 3. 七指标（机制 E 口径）

| 指标 | 口径 | 防作弊说明 |
|---|---|---|
| 首次解决率 | 首次尝试即通过验收的任务占比 | 防挑简单任务：按任务难度分层统计 |
| 结果有效率 | 产出通过验收（S≥S1 且 E≥1）的占比 | 未完成项如实申报不扣分 |
| 假设命中率 | verdict=证实 的假设占比 | 证伪假设不计负分（证伪是成果） |
| 缺陷发现率 | 发现真实缺陷（被确认）数 | 缺陷发现者不算低产出 |
| 复现成功率 | 独立复现成功 / 复现尝试 | 复现失败如实登记 |
| 知识贡献率 | 沉淀三资产被后续任务复用次数 | 复用计数机器统计 |
| 攻关贡献度 | 对 S3+ 成果的实质贡献（独立审查确认） | 不评代码量/PR 数/完成率 |

**禁止**：① 评代码量/PR 数/完成率；② 七指标加权成单一排名（SPEC v1.2 §7.2：
不得将 S1-S5 加权成单一 Agent 排名或直接绑定个人奖惩）。

## 4. 动态升级（机制 D）

触发条件（任一）：多次失败（同假设族 ≥2 次证伪）/ 无法解释的异常 / 缺专业知识。
动作（按序）：请求更强 Agent → 请求领域专家 → 重分配任务 → 补知识（知识包）→ 换技术路线。
**不许无限重复**同一路线；升级请求与处理结果落事件流（campaign events）。

## 5. 二期预留：强弱 Agent 能力传递（G25 过门后播种）

三层循环（总纲 §7）：
- 强推理层：问题抽象/理论/战略/关键路线；
- 大规模执行层：调查/实现/实验/独立验证；
- 组织知识层：验证过的知识/失败记录/工具/能力模型。

循环：推理指导执行 → 执行产证据 → 证据修正推理 → 沉淀提下一轮。
理想态：强模型建初始框架 → Agent 学框架并执行 → 困难时主动暴露 → 强模型只攻关键瓶颈 →
指导蒸馏为方法工具 → **逐步不依赖强模型持续干预**（能力蒸馏与组织学习）。

**预留接口**（一期不实现，仅留接口位）：
- 能力模型条目：Agent × 能力域 × 置信度（供强推理层调度）；
- 蒸馏工件：强模型指导 → 方法/工具工件（进工具资产）；
- 依赖度指标：强模型干预次数/任务（趋势应下降）。
