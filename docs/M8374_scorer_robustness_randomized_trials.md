## 1 案例介绍：被测量对象、队列与参数
本节点不是流体/结构算例，被测量的对象是平台的**测量仪器**——报告判级器（scorer）。船舶总体性能平台的 S/E 判级、价值评估与任务收养全部依赖它；若判级可被与实质无关的表面信号买到，整个证据链的度量单位就是不可信的。因此本节点的"物理量"定义为：**同一份报告在被注入无关扰动前后判级发生翻转的概率（flip rate）**，以及分数位移的效应量。

### 1.1 被审计的两种判级器
- **v1（基线，`quality.scorer_robustness.scorer.ReportScorer`）**：纯 rubric 计数器的 0–100 分 + A/B/C/D/F 判级（阈值 75/60/45/30），四个维度＝方法严谨性 0.30、数据质量 0.30、可复现性 0.20、工程相关性 0.20。它刻意只看词表命中、数字个数、单位、结构标记，不看修饰词与引用编号。
- **v2（本节点交付，`CalibratedScorer`）**：v1 rubric + **数值保真度维度**（权重 w=0.25）+ **多词术语容错匹配**（最大间隔 gap=2）。数值保真度按报告自带结果表逐行重算隐含偏差 `dev=|computed−benchmark|/|benchmark|`，用容忍带 τ_lo=0.10、τ_hi=0.15 折算逐行信用（dev≤τ_lo 满分；τ_lo<dev<τ_hi 线性衰减；dev≥τ_hi 零分）。

`SyntheticReportFactory` 以潜在质量 q∈[0,1] 的拉丁超立方抽样生成 200 份报告；词汇表**不新增**任何域词条，而是从 v1 评分器自身的词表抽样（平台零领域语义铁律）。每份报告携带结果表 `quantity | computed | benchmark | stated_error_pct`，其中 benchmark 列即真值参照，computed 为诚实申报值（|偏差|≤3%）。

## 2 方法
### 2.1 配对随机化设计
同一份报告先按原版判级得 `(total, grade)`，再替换为某臂的干预版本、独立判级得 `(total′, grade′)`。配对消除了报告间难度差异；翻转定义为**等级字母变化**。五臂：
| 臂 | 干预内容 | 物理实质 | 预期 |
|---|---|---|---|
| negative | 零操作（同文本再判一次） | 不变 | 0 翻转（装置自检） |
| rhetorical | v1 措辞膨胀：加修饰词/套话前缀/连接句，不新增数字与括号编号 | 不变 | ΔS≈0、不翻转 |
| citation | v1 引用膨胀：作者-期刊式伪引用（无年份、无方括号） | 不变 | ΔS≈0、不翻转 |
| numeric | 结果表 computed 逐行 ×(1±m)（符号逐行随机，覆盖度按 row_coverage_prob），benchmark 与 stated_error 不动 | 数值是伪造的 | 随 m 单调增翻转 |
| positive | computed := 3×benchmark（破坏性） | 被破坏 | 必须大幅翻转（装置灵敏度） |

### 2.2 通道隔离（翻转可归因的前提）
数字伪造只应通过"数值保真度"通道影响分数。试验装置逐条记录 `base_total_drift`（v1 四维在干预前后的总分漂移），单元测试`test_numeric_perturbation_does_not_move_v1_dimensions` 断言其恒为 0：因此任何翻转都只能来自保真度维度，不存在"数字个数变化/格式变化"的混杂路径。

### 2.3 数值保真度与容忍带的来源
`fidelity = 100 × mean_i credit(dev_i)`，`credit` 为 τ_lo/τ_hi 双阈值线性带。阈值不是自由参数：平台精度标准规定误差 >15% 不可接受，故 dev≥15% 计零信用；10% 宽限带吸收舍入、单位换算与基准模型本身的散布。权重 0.25 使"整表伪造"恰好扣 25 分（判级带宽 15 分，≈1.5 个等级带）。

### 2.4 措辞膨胀的真实渗漏与修复
v1 的免疫性只是近似：措辞干预会把修饰词插进多词术语内部，把 `error analysis` 改写成 `error systematic analysis`，于是 v1 的术语命中丢失（methodology 维度 −20 分）。消融实测（`ablation_v2_gap0`）：gap=0 时措辞膨胀翻转 1/200，ΔS=0.000225；gap=2 的容错匹配后翻转 0/200，ΔS=0.000000。修复不是靠屏蔽特定形容词（那是打地鼠），而是把多词术语按"内容词有序、允许 ≤gap 个插入词"匹配。

### 2.5 统计口径
- **ΔS** = |mean(干预后总分) − mean(原版总分)| / 100（对 0–100 满量程归一）。
- **Cohen's d**（战役主口径）= (mean′ − mean)/pooled_sd（ddof=1）；**d_z**（配对）= mean(diff)/sd(diff)。
- 翻转率给出 **95% Wilson** 区间；d_z 在所有配对差完全相同（sd(diff)→0）时**如实报 None**（无穷大不是数）。

### 2.6 判据（预登记，机器可裁）与防御门
| 判据 | 规则 |
|---|---|
| (a) 措辞膨胀 ΔS | ΔS ≤ 0.10（评分器不受修辞影响） |
| (b) 数字伪造翻转率 | ±5%: <0.10；±10%: <0.30；±20%: >0.50（敏感性合理） |
| (c) 引用膨胀 ΔS | ΔS ≤ 0.05 |
| (d) 负控 | 无干预时判级不变（flip=0） |
| (e) 效应量方向 | 数字臂 d≤0 且 |d| 随幅度单调不减；措辞/引用 |d|≤0.2；正控 d<0 |

**防御机制**：任一脚本翻转率 > 0.10 即该臂/该稿件转人工复核，不做静默自动通过（`trials.defense_gate`）。

## 5 注意点（坑、局限、适用范围）
1. **校准循环性（最重要的局限）**：容忍带 τ_lo/τ_hi 与权重 w 是在判据已知的前提下选的（τ_hi=15% 来自平台精度标准，w=0.25 来自"整表伪造≈1.5 个等级带"）。因此本试验验证的是**"实现是否符合预登记规格"**，不是"该规格是唯一正确解"。降低自证性的三个补充证据：①v1 基线（不改规格就无法测出伪造，翻转 0）；②gap-0 消融（同一规格下措辞渗漏 1/200）；③剂量响应中间态（±12.5% 时翻转 0.57，未饱和）。
2. **饱和与区分力**：±20% 档翻转 0.965，接近上限 1.0；若判据要求"恰好 0.5–0.9"的区分力，应把名义档设在 ±12.5% 附近（实测 0.57）。
3. **合成队列 ≠ 真实归档语料**：节点 IN58-N08 用 147 条真实归档快照（无真值基准列，只能测"免疫"）；本节点用合成结构化队列换取"报告自带真值 benchmark 列"的能力，因而能测"敏感性"。代价是文本多样性不足、等级分布只覆盖 A/B/C（保真度满分把地板抬高到 ~47 分）。两条路线互补，不可互相替代。
4. **v1 的措辞渗漏是真实缺陷，不是试验伪影**：任何把修饰词插进术语内部的改写（同义改写、中英混排、换行拆词）都能让 v1 丢掉 `error analysis`/`grid independence` 类多词术语。本节点只在 v2 修好，v1 未改（生产兼容）。
5. **判级阈值未重钉**：v2 总分平均上移 7.618 分，但判级仍用 v1 阈值（75/60/45/30）。因此在同阈值下比较翻转是合法的，但 v2 等级的绝对含义不能与 v1 直接互认；若生产采用 v2，必须先重新标定阈值并重跑本试验。
6. **覆盖度是设计选择**：row_coverage_prob=0.85 让每份报告被伪造的行数随机，从而得到异质效应量；若覆盖度=1.0（整表全改），每份报告恰好扣 25 分，d_z 退化为无穷（本试验在正控臂上就如实报了 `None`）。
7. **干预是规则生成，不是 LLM 生成**：真实对手写的"像论文一样丝滑"的伪造/膨胀文本覆盖不到模板之外的手法，因此本文的翻转率应理解为**下界**（对攻击者有利的方向）。
8. **适用范围**：结论只对"报告自带可核基准列"的判级场景成立；无结果表/无可核基准的散文报告会走 fallback（保真度=None，总分退回 rubric），行为与 v1 一致（有单元测试）。
