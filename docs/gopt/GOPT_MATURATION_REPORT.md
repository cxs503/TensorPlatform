## 1. 案例介绍

### 1.1 任务与物理背景

本节点要求把平台的优化库（G-OPT）从「脚本级工具」升级为**可复用、可验证的优化内核**：
①梯度-free 的 CMA-ES（非凸/噪声目标）；②需要梯度回调的 SLSQP（光滑约束）；
③**伴随法接口协议**（solver → 梯度函数 → 优化器），供 LBM/FVM/FEM/BEM 求解器接入；
④以一个回转体（细长体）线型为基准，在**固定排水体积**约束下扫掠长宽比 L/B∈[5,9]，
以阻力系数 C_D 为目标，检验最优 L/B 是否与文献/经验一致。

物理对象为轴对称细长体（水下航行器裸艇体量级），排水体积是设计约束（浮力平衡），
因此「L/B 变化」只能通过**直径反向收缩**实现——这一约束是本案例全部结论的关键。

### 1.2 几何与参数表

几何族取**长球体（prolate spheroid）**，闭式给出湿面积与排水体积，使固定排水量约束可精确施加：

```
V = pi/6 * L * D^2                (固定)
L(lambda) = (6 V lambda^2/pi)^(1/3), lambda = L/D
S = 2 pi b^2 (1 + (a/(b e)) asin e),  a=L/2, b=D/2, e=sqrt(1-(b/a)^2)
```

| 参数 | 值 | 来源/说明 |
|---|---|---|
| 基准主尺度 L, D | 4.356 m, 0.508 m | 参考艇体主尺度（族在该点的基准，非形状复制） |
| 已发表湿面积 | 5.42 m² | 正典基准数据集 |
| 族基准点湿面积 | 5.4938 m²（偏差 1.36%） | 本工作计算 |
| 固定排水体积 V | 0.58859 m³ | 由基准主尺度按长球体闭式反算 |
| 方形系数 Cb（相对外切圆柱） | 0.6667 | 长球体恒等于 2/3；Cauchy–Schwarz 下界 0.6078 |
| 设计航速 | 3.0 m/s | 取已发表最低速工况（Fr≈0.459），使全扫掠处于模型标定包线内 |
| 流体 | rho=1025.0 kg/m³, nu=1.004e-06 m²/s | 正典数据集一致 |
| 设计变量 | L/B ∈ [5.0, 9.0] | 任务给定 |

### 1.3 阻力模型（平台单一真源）

阻力值一律调用平台既有求解器 `backend/api/domain/resistance_core.solve_resistance`
（ITTC-57 摩擦线 + SUBOFF 标定的 Froude 残差拟合），本工作**不新造阻力公式**；
为得到机器精度导数，本地以 numpy 复数安全形式**镜像**同两条公式（仅用于求导），
并由回归测试把镜像钉在平台实现上（全扫掠最大偏差 < 1e-6，见 3.3）。

## 5. 注意点（踩坑与局限）

### 5.1 CMA-ES 的三个易错点

1. `h_sigma` 归一化必须用**代数计数 g**（`1-(1-c_s)^(2(g+1))`），用评估计数除以种群数会差一代，破坏 ‖ps‖ 的 E‖N(0,I)‖ 归一，导致步长长期偏小；
2. TolFun 用「历史最优」的极差会在多峰问题**过早终止**：必须用逐代种群最优序列 + 种群内离散度双条件；即使如此，多峰问题上收敛终止应视为**单次运行的正常结束**并触发重启（IPOP），而不是全局收敛；
3. 越界修复用 clip 会改变采样分布：本实现保留 clip（确定性、可复现），但记录越界比例作为诊断量，上限触发时能得到解释而不是静默偏差。

### 5.2 SLSQP 的两个易错点

1. QP 子问题的**乘子符号约定**必须与罚函数一致（本库约定 c_ineq≥0、μ≥0、`Bp+g=Aᵀν+A_actᵀμ`），符号弄反会让线搜索的罚参数取错、迭代停滞；
2. 线性化约束可能不相容（QP 不可行），因此 QP 先用罚-Newton 找到邻域、再 exact active-set 打磨，并把 KKT 残差作为证书输出（`QPResult.kkt_residual`），不可行时 `exact=False` 可见。

### 5.3 目标函数选择：为什么 C_D 在固定排水量下不适合作设计目标

固定排水体积时，L/D 增大 ⇒ 湿面积 S 增大（V 固定下 S ∝ λ^{1/3}），而 C_D 是以 S 为参考面积的系数，
**参考面积本身在变**：C_F 随 Re 缓慢下降、C_R 随 Fr 快速下降，二者压倒 S 的增长，于是 C_D 单调下降，
最优解落在区间上界——这不是设计结论，而是「系数与面积耦合」的假象。
物理上正确的设计目标应是**总阻力 R_t**（或 C_D·S/V^{2/3} 这类面积归一化系数）。
这一点正是本案例最有价值的发现：任务给定的目标函数在约束下**不产生内部最优**，
因此单看「最优 L/B = 9」会得出错误的工程结论（本工作如实报告而非粉饰）。

### 5.4 模型局限（已在数字上量化）

1. 平台阻力模型**不含粘性形状因子 (1+k)**：因此平台原样目标的 R_t 随 L/D 单调**上升**（越短越好），
   与含形状因子的结论方向相反。案例级引入 Hoerner 长细比形状因子 `1+k = 1 + 1.5 (D/L)^1.5 + 7 (D/L)^3`（文献相关式，非平台求解器的一部分）后结论翻转。
2. 长球体几何族在基准点复现已发表湿面积到 1.36%，但**不是**真实艇体型线（无平行中体、无尾部收缩），
   且 Cb 恒为 2/3；因此本案例验证的是「在固定排水量 + 细长体近似下的趋势」，
   不能替代带型线库（TensorCAD/型值表）的优化。
3. 波阻项沿用平台的 Fn^2.5 拟合，在 Fr>0.62 过预测（3.5 节量化）；
   案例把航速限制在包线内，但这意味着结论只覆盖**低速**工况。
4. 文献带 4.5–5.0 与工程实践带 7.0–8.5 的证据等级均为 WITHHELD（离线无法复核原始文献/单一实验），
   仅作一致性带使用；本工作没有用它们去校准模型（否则就是为目标值调参）。
