## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理背景

耐波性（Seakeeping）研究船舶在波浪中的六自由度运动响应。平台核心模块 `backend/services/seakeeping.py` 实现单自由度线性频域响应模型：

$$
(M + A)\ddot{\eta} + B\dot{\eta} + C\eta = F(t)
$$

其中：
- **恢复力 C**：来自静水力（C33 = ρgAw, C55 = ρg∇GML, C44 = mgGMT），小角度下精确
- **附加质量 A** 和 **阻尼 B**：参数化输入（默认值为常规量级，非拟合）
- **激励力**：Froude-Krylov + Smith 修正 e^{-kT} + 船长方向相位因子 Γ(u)

### 1.2 验证基准

不依赖实验数据，而是对以下闭式解析量进行机器精度验证：

| 锚点 | 闭式 | 物理意义 |
|---|---|---|
| 色散关系 | k = ω²/g | 深水波数-频率关系 |
| 遭遇频率 | ωe = ω + kU cosβ | 船速/航向对频率的 Doppler 偏移 |
| 长波极限 | ω→0 ⇒ RAO→1 | 波长→∞时船体跟随水面运动 |
| 共振峰 | r_peak = √(1-2ζ²), H_peak = 1/(2ζ√(1-ζ²)) | SDOF 传递函数共振 |
| 高频衰减 | ω→∞ ⇒ RAO ~ C/((M+A)ωe²) | 对数斜率 -2 |
| 谱矩 | m₀, m₂ (ITTC 双参数谱闭式) | 波浪统计量 |

### 1.3 基线船型参数

|---|---|

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 证据等级声明

- **REAL（模型）**：SDOF 频域模型中所有闭式量（色散、遭遇频率、长波极限、共振峰、高频衰减、谱矩）均通过机器精度验证。
- **WITHHELD（实验精度）**：附加质量 A 和阻尼 B 为参数化输入（默认值为常规量级，非拟合），绝对 RAO 精度**未对标实验数据**。模块文档明确声明："absolute RAO accuracy against model tests is NOT verified — no tank data is bundled."

### 5.2 已知局限

1. **2D 剖面水动力系数存在形状盲缺陷**（m1797 量化）：零频附加质量 A33(0) 的构式 f_a(ν) = 1 - 0.25ν²/(1+ν²) 只依赖 ν，不含剖面形状信息，导致宽浅型船（BARGE60）误差达 -47.9%。此缺陷在 STF 切片理论内核（`seakeeping_physics.py`）中，不影响 SDOF 参考核心（`services/seakeeping.py`）。
2. **单自由度解耦**：当前模型为单自由度线性响应，未实现垂荡-纵摇耦合。
3. **线性假设**：小振幅波、小角度运动，不适用于大幅运动或非线性效应显著的场景。

### 5.3 适用范围

- ✅ 频域线性响应分析（RAO、谱分析）
- ✅ 闭式锚点验证（色散、遭遇频率、长波极限等）
- ⚠️ 工程设计初筛（精度依赖附加质量/阻尼参数选取）
- ❌ 大幅运动、非线性效应、耦合响应
- ❌ 实验精度对标（无水池数据）
