## ① 案例介绍（物理背景/几何/参数表）

**物理背景。** 船舶稳性计算的完整链路为：船体型线 → 静水力积分（∇, Cb, KB, BM, Aw）→ 初稳性高 GM = KB + BM - KG → 复原力臂 GZ(φ)。
平台 `calc.stability` 能力（REAL）接受 GM 作为输入参数，但**从几何到 GM 的推导链**此前从未被独立裁决——
这是本单的验证欠账。

**被测模块：** `backend/services/ship_hydrostatics.py`（Simpson 积分器 + 船型偏移表 → 静水力结果）

**验证算例：**

| 算例 | 船型 | L (m) | B (m) | T (m) | KG (m) | 参考来源 |
|---|---|---|---|---|---|---|
| 1 | 箱型驳船 | 100.0 | 20.0 | 8.0 | 6.0 | 教科书闭式解 |
| 2 | Wigley III 抛物线船型 | 100.0 | 15.0 | 6.0 | 4.0 | 解析积分闭式解 |

**闭式参考值（精确，无经验数据）：**

箱型驳船：
- ∇ = B·L·T = 16000 m³, Cb = 1
- Aw = B·L = 2000 m², KB = T/2 = 4.0 m
- BM_T = B²/(12T) = 4.167 m, BM_L = L²/(12T) = 104.167 m
- S = L·(B+2T) = 3600 m²

Wigley III: y(x,z) = (B/2)·(1-(2x/L)²)·(1-(1-z/T)²)
- ∇ = 4BLT/9 = 2666.667 m³, Cb = 4/9
- Aw = 2BL/3 = 1000 m², KB = 5T/8 = 3.75 m
- BM_T = 3B²/(35T) = 1.929 m, BM_L = 3L²/(40T) = 18.75 m
- Cm = 2/3, Cp = 2/3, Cw = 2/3

## ② 怎么做的（方法/流程/关键设置/工具链）

1. **独立参考器**：手写闭式解函数（`box_barge_exact`, `wigley_exact`），**不复制**被测模块代码，
   确保参考值独立于实现。
2. **双船型验证**：箱型驳船（14 个字段）+ Wigley III（13 个字段），逐项比对相对误差。
3. **湿表面积专项**：箱型驳船 S = L(B+2T) 闭式 vs Simpson 积分近似，容差 1%。
4. **网格收敛性**：Wigley III 在 11→21→41→81→161 站数下，体积/KB/BM 误差单调递减。
5. **精细网格精度**：161 站时所有字段误差 < 0.01%。
6. **工具链**：Python 3.11 + pytest（30 项测试）+ 纯数值计算（无重算力）。

## ⑤ 注意点（踩过的坑/局限/适用范围）

1. **湿表面积近似**：Wigley 船型的湿表面积无简单闭式解，模块采用横向剖面周长沿船长 Simpson 积分，
   对箱型驳船可精确复现 S = L(B+2T)，但对曲率大的船型存在离散化误差。
2. **Simpson 积分要求奇数个节点**：模块内部自动处理，但调用者需注意 n_stations 和 n_waterlines 应为奇数。
3. **Cb 物理门**：模块内置 Cb ∈ [0.15, 1.0] 物理门，超出范围报 GeometryError。
4. **GM ≤ 0 不报错**：模块如实返回负 GM 并附注"negative initial stability"，这是正确行为（非 bug）。
5. **本验证仅覆盖两种理想船型**：实际船型（带球鼻艏、方尾、舭龙骨等）的静水力精度需额外验证。
