# 物理信息神经算子（FNO）船体阻力/耐波实时代理模型（P284W3-N09）

## 1. 案例介绍

### 1.1 物理背景
船体总阻力 `R_T` 与六自由度运动响应幅值（垂荡 `RAO_z`、横摇 `RAO_φ`）是总体性能设计迭代内环
的核心量。传统手段（CFD／模型试验）单点计算量级为小时—天，无法用于优化循环；本节点训练一个
**Fourier 神经算子（FNO）代理**，把「船体几何场 + 工况」映射到「阻力／运动响应」，目标为
CPU 单点推理 <10 ms。

### 1.2 数据源（验证内核，非本节点新造）
标签一律由平台**既有 REAL 内核**现算，代码哈希入审计链：

| 标签 | 内核 | 方法与证据等级 | 源码 sha256（前 12 位） |
|---|---|---|---|
| `C_T, R_T` | `backend/api/domain/resistance_holtrop.py` | Holtrop-Mennen 1982/1984 + ITTC-1957 + ITTC-1978（回归式，对常规单体排水型船自述 ±5–10%） | `27ba0a9b2664` |
| `RAO_φ, RAO_z` | `backend/api/seakeeping_physics.py` | STF strip theory, 20 stations, analytic 2D coefficient factors（2D 系数为解析频率因子近似，非 Ursell–Tasai 全解） | `307afd4d2f65` |

数据集：`artifacts/p284w3_n09_fno/dataset.npz`（sha256 `a778060b577942ed`），训练域
`2000` 样本（Fr≤0.40、β≤60°），外推域 `400` 样本
（Fr>0.40 或 β>60°）。**几何先验已先行校验**：`∫(A/(B·T))dx = C_b` 最大偏差
`3.3e-16`（浮力守恒），Cb·L·B·T 与排水量自洽。

### 1.3 船型/工况参数表（采样域）

| 参数 | 范围 | 参数 | 范围 |
|---|---|---|---|
| L | 60–320 m（对数均匀） | Fr | 0.08–0.40（外推 0.40–0.55） |
| L/B | 4.5–7.5 | β（浪向） | 0–60°（外推 60–180°） |
| B/T | 2.6–5.5 | GM/B | 0.02–0.10 |
| Cb | 0.45–0.85 | KG/T | 0.50–0.80 |
| Cwp | Cwp(Cb)±0.05，且 Cwp≥Cb+0.03 | λ/L（波长船长比） | 0.25–3.0 |

### 1.4 算符形式
输入场 `u(x,z)`（24 通道，网格 16×4）：逐站剖面面积比 `A(x)/(B·T)`、淹没掩膜、半宽比
`2b(x)/B`、船体纵向斜率、湿周密度，以及 18 个无因次工况量（Fr、log Re、Cb、Cwp、B/T、L/B、
L/T、GM/B、KG/T、`ω_e√(L/g)`、`kL`、`kL·cosβ`、`ω_e/ω_33`、`ω_e/ω_44`、GM_L/B、|sinβ|、cosβ、
`ω√(L/g)`）。输出场 `v(x,z)`：阻力密度场 `r(x,z)` + 辅助速度场 `(u_x,u_z)` + 两条空间调制场，
经泛函读出得到 `(R_T, RAO_z, RAO_φ)`。

## 2. 方法

### 2.1 架构
FNO（`src/neural_operators/field_operator.py`）：lift → ×4（SpectralConv2d +
逐点线性 + GELU）→ project，模态 `k=(16, 4)`（纵向
`k=16`），隐藏通道 16。输出经**泛函读出**：
`C_T = ∫ r dA`（归一化面积权）、`RAO = exp(⟨log 场⟩)`。
另设**全局分支**（输入场全局平均池化 → MLP(24→32→32→3)）给出响应的整体量级，FNO 场分量提供
零均值空间调制与辅助速度场——DeepONet/FNO 混合结构，域不变量、无领域词条。

### 2.2 物理约束
**硬约束（按构造精确成立）**
1. 非负：`r∝exp(·)>0` ⇒ `C_T>0, R_T>0`；
2. 守恒构造：`C_T` 精确等于阻力密度场的归一化积分（无自由标量头）；
3. 对称性：`RAO_φ ∝ |sin β|`（β=0/180° 恒为 0，float64 计算后残差 <1e-12）；
4. 量纲一致性：`R_T = ½ρV²S·C_T`（ρ、V、S 逐样本来自输入）。

**软物理项** `L_phys = λ_div·‖∇·u‖² + λ_mom·[(∫u(1−u)dA − ∫r dA)/(|·|+|·|)]² + λ_bc·⟨(u_x(0)−1)²⟩`
（不可压弱形式 / 尾流动量守恒 / 入口自由流），权重
λ_div=0.001, λ_mom=0.1, λ_bc=0.01。

### 2.3 训练与不确定度
AdamW（lr=0.006, wd=0.0001）+ cosine，batch 64，epochs
60，**2 成员深度集成**（对数空间均值 + 成员标准差 σ）；
split-conformal 标定（域内 val 集 / 外推标定集两套 `q`），名义 90% 区间。训练墙钟
1302.0 s（本地 CPU，宿主机 load ≫ 核数，非最优算力）。

### 2.4 误差口径（显式声明）
`mape_pct = mean |Δ|/max(|truth|, floor)×100`，`floor = 0.02 × 训练集中位数`
（低于该量级视为数值零，避免近零响应把相对误差放大）；同时报告严格口径 `strict_mape_pct`。

## 5. 注意点与局限

1. **量纲错误（本节点踩到并修正）**：无因次频率必须是 `ω·√(L/g)`，不是 `ω/√(gL)`。
   后者隐含 1/L 依赖，直接破坏 Froude 相似性，使 RAO 分支不可学习（实测：修正前 RAO 测试
   误差 ~100%，修正后降至 61% 量级）。
   回归防护：`test_input_tensor_channels_and_mask` + 数据集清单登记特征定义。
2. **RAO 的"点值"是强非线性量**：|RAO(ω)| 在反共振处穿过零点（量级从 1e-4 到 3.4 跨 4.5 个
   十倍程），点位相对误差对频率参数的微小偏差极敏感；工程上应以谱平均/峰值口径评价。
3. **插值极限（关键局限）**：输入为 ≥10 维无因次群，千级样本在 10 维空间里仍属稀疏——对照
   实验（§3.3 表）显示：训练残差（RMS log 0.17–0.33）远小于测试误差量级（10–50%），
   且样本量翻 2.5 倍仅把误差乘到 0.6–0.76，据此标度外推达判据需 1e5–1e6 量级样本或更强
   物理结构先验。
4. **训练标签是回归/切片理论内核**（Holtrop ±5–10%；STF 2D 系数为解析近似），因此本代理的
   精度上限受内核可信度限制；对实验的真值误差另需独立基准（本节点未做实验对标）。
5. **算力**：本地宿主机 load ≫ 核数（共享），训练墙钟 1302.0 s；
   集群作业排队未派发。更大规模训练应上集群。
