# geometry.hydro_curves 能力验证报告

## 1. 案例介绍

### 物理背景
静水力曲线（Hydrostatic Curves）是船舶设计的基础工具，描述排水量、浮心、稳心等静水力参数随吃水变化的关系。本验证使用**合成箱形驳船**（rectangular barge / box hull）作为测试对象，因其具有闭式解析解，可作为零误差基准。

### 几何参数表
| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 垂线间长 | L | 80.0 | m |
| 型宽 | B | 20.0 | m |
| 型深 | D | 12.0 | m |
| 吃水扫描范围 | T | 2.0 ~ 10.0 | m |
| 吃水步长 | ΔT | 0.5 | m |
| 水密度 | ρ | 1025.0 | kg/m³ |
| 扫描点数 | N | 17 | — |

### 解析基准公式（箱形驳船 Cb=1）
| 量 | 公式 | 说明 |
|----|------|------|
| 排水体积 | ∇ = L·B·T | 精确 |
| 浮心垂向 | KB = T/2 | 精确（梯形剖面形心） |
| 横稳心半径 | BM_T = B²/(12·T) | 精确（I_T = L·B³/12） |
| 纵稳心半径 | BM_L = L²/(12·T) | 精确（I_L = L³·B/12） |
| 横稳心高 | KM_T = KB + BM_T | 精确 |
| 水线面面积 | Aw = L·B | 常数 |
| 方形系数 | Cb = 1.0 | 精确 |

## 2. 方法

### 实现路径
1. **端点实现**：在 `backend/api/calculations.py` 新增 `POST /calculations/hydro_curves` 端点
2. **几何生成**：使用 `barge_offsets()` 在各吃水下生成箱形驳船型值表
3. **静水力积分**：调用 `compute_hydrostatics()` 对每个吃水进行 Simpson 积分
4. **参考解**：独立闭式公式 `box_ref()` 计算理论值
5. **误差对比**：逐项计算相对误差，判定是否 <3%

### 工具链
- FastAPI TestClient（端点调用）
- pytest 64 项测试（C1-C6 全覆盖）
- matplotlib 曲线图生成
- 零手抄：所有数字由程序化注入

## 5. 注意点

### 适用范围
- 本验证使用箱形驳船（Cb=1），是静水力积分的最简情形
- 端点同时支持 `hull="table"` 模式，可接受任意型值表
- Simpson 积分在均匀网格上对多项式精确，对箱形驳船达到机器精度

### 湿表面积说明
- 端点返回的湿表面积基于剖面周长积分（girth method），对箱形驳船给出 L·(B+2T)
- 该值不含首尾端面积，与完整湿表面积 L·B + 2T·(L+B) 有约 4% 差异
- 这是静水力模块的设计选择（沿船长积分剖面），非错误

### 局限性
- 本验证仅覆盖箱形驳船（Cb=1），未覆盖 Wigley 船型或其他复杂船型
- 未覆盖大倾角稳性（GZ 曲线）
- 未覆盖自由液面修正
