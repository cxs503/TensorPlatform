**独立性分级**（本单自定，写进注册表 docstring）：
`field-recompute`（自写后处理从原始场/时程重新取量，最强）> `error-recompute`（只重算案例已报标量的误差）
> `baseline-audit`（只复核解析基线本身是否正确）。

## ② 怎么做的（方法 / 流程 / 工具链）

1. **基准落地**（`lbm_reference_registry.py`）：把 4 族基准的数值与出处钉死在源码里，逐条给
   provenance（论文/表号/口径）。Ghia 三张 17 点表 + u_min 极值有测试钉死（−0.21090/−0.32726/−0.38289），
   M&M 表有单调性与端点测试，Ku 1987 与 Ghia 的 3D 修正区间（20%–35%）也有测试——**基准自己先被测**。
2. **判级口径**：`rel_error=|v−ref|/|ref|`，`classify` 三分档（≤3% PASS、≤15% MARGINAL、>15% FAIL、
   NaN → INDETERMINATE）。曲线比对**只在仿真区间内插值，绝不外推**（`curve_errors`），
   同时给 L∞ / RMS / 均值与逐点表。
3. **独立复算**（`independent_recheck.py`）：
   - 腔体：从 npz 全场取三条候选中心线，按"内部极小值最负者"选壁法向中心线；**字段是否已无量纲化**
     用 `max|u| > 5·u_lid` 自动判别（实测该 npz 的 `u_lid=0.06` 但场已归一，若盲除会得到 −4.52 的荒谬值）；
     展向对称轴不预设，三轴遍历取镜像残差最小者（实测 x 轴 1.4×10⁻⁵，且 uz 反对称残差同量级）。
   - 溃坝：直接读时程 CSV 的 `T_MM`/`X_toe`，对 M&M 14 点插值比对；同一时程**换到旧轴 `T_code=t√(g/a)`**
     再算一遍，定量给出时标约定错误的代价，并用 `√2` 恒等式核对内核口径。
   - Forchheimer：逐行重算 `|R_sim−R_ref|/R_ref`，与案例自报 `err_A` 求算术差（抓分母/阈值错），
     并把 Stokes 截距 `y0_f_form` 对 Sangani-Acrivos f(0.40)=217.89 做基线审计。
   - Poiseuille：从 `(Δρ, cs², nx, H_eff, ν)` 重推 `u_max=GH²/(8ν)`、`u_mean=2/3 u_max`，
     并核对半程反弹的 `H_eff = ny − 2` 记账。
4. **出图**：`independent_recheck_figures.py` 只读 `recheck.json` + 原始工件，3 张图零手抄。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **归一化陷阱（真踩到）**：`case_643.npz` 里 `u_lid=0.06`（格点单位）但 `ux` 已是 `u/u_lid≈1` 的无量纲场；
   首版盲除 `u_lid` 得出 u_min=−4.52（误差 1544%），判级直接爆表。现改为自动判别并写进测试
   （`test_check_cavity_3d_handles_dimensional_field`）。**教训：复核工具自己的单位假设也是被测对象**。
2. **展向轴不预设**：首版假定 z 轴是展向，算出"镜像残差 0.50"的假对称性告警；三轴遍历后真实展向轴是
   **x 轴**（残差 1.4×10⁻⁵），说明该 npz 的存储序不是 (x,y,z)。已改为数据驱动。
3. **`classify` 首版写错**（`err != math.isnan(err)` 恒真 → 全判 INDETERMINATE）——被实跑立刻抓出，
   现阈值测试 8 个边界点钉死（0.03 含入 PASS、0.15 含入 MARGINAL）。
4. **溃坝基准的独立性有限**：M&M 1952 的 14 点表是**案例自带数字化的转录**（Lethe 例程口径），
   不是我从原论文重新数字化。所以 `dam_break_sc` 的绝对误差判定应读作"案例 vs 它自己的参考转录"；
   本单真正独立的部分是**复算方式**（从时程 CSV 重取量、逐点插值、时标恒等式）。
   这一点在 `recheck.json` 的 `provenance.independence` 字段里显式标注。
5. **`X_toe` 与 M&M `Z` 的定义可能不同**（趾点 vs 最远点），晚期 20% 的偏差里有多少来自定义差异、
   多少来自物理（2D vs 3D、壁面摩阻），本单**无法分离**——需要原始论文的取点定义或 3D 算例。
   因此该 FAIL 只能定位"未达标"，不能直接归因给求解器。
6. **只复核了 4 个案例**：`pending/` 下还有 30+ 案例未纳入（多数缺原始场工件或参考表不在离线可得范围）。
   工具的 `run()` 对缺失工件是 skip-with-reason，不会假通过。
7. **容量纪律**：开工 `load15=122.76`（nproc 128）→ 全程只做轻量活（读工件 + 后处理 + 出图），
   未起任何仿真。全套复算 + 出图墙钟 < 10 s。

## ⑥ 误差判定（关键量 vs 基准，逐项；显式回答「是否 <3%」）

| 关键量 | 基准 | 结果 | 相对误差 | 是否 <3% |
|---|---|---|---|---|

| `cavity_3d_full` 3D 修正量 | Ghia 2D −0.38289 | −29.11% | 与案例自报 29.11% 差 <0.01pp | ✅ 是（物理一致性检查，非精度指标） |
| `cavity_3d_full` 展向对称 | 镜像恒等 | 残差 1.4×10⁻⁵ | 1.4×10⁻³%（相对 O(1) 场） | ✅ 是 |

| `forchheimer` 中位误差 | 同上 | 0.0263 | 2.63% | ✅ 是（中位达标，最差行越界） |
| `forchheimer` Stokes 截距 | Sangani-Acrivos 217.89 | 见逐行 y0 | 最大 1.53% | ✅ 是 |
| `poiseuille_2d` u_max_ana 重推 | 解析解 GH²/(8ν) | 0.040000 | **0.00e+00%** | ✅ 是（舍入级） |
| `poiseuille_2d` H_eff | ny−2 | 60 vs 60 | 0（布尔判据） | ✅ 是 |

**诚实结论**：本单**没有**证明溃坝案例达标——恰恰相反，独立复算**独立复现**了它的 FAIL
（L∞ ≈ 19%–20%，且误差随 T 单调增长，晚期前缘系统性落后于 M&M 约 20%），
并额外证明"时标 √2 修正"只是把 L∞ 从 33.4% 降到 19.9%、**不足以清偿该欠账**——
这与 `guide_tracker_state.json` 里 `dam_break_sc` 处于 escalated（连败）状态相互印证，
且本轮证据类型从"案例自述"升级为"第二套代码路径 + 逐点表"。
Forchheimer 最差行 3.06% 越界 → 本单判 **MARGINAL**，但**必须注意判级轴不同**：案例自判是 **FAIL**，
其驱动条款是"三档误差对分辨率 d 无收敛趋势 + 严格单调条款三档全破"，而本单只复核了"误差量级 vs 文献"
这一条（1.86%–3.06%，与案例 err_A 复算差 4.5×10⁻¹⁷）。故本单的 MARGINAL **不是**给该案例翻案——
它范围更窄，只说明"误差量级本身处在 3% 边缘，越界点定位在 d=416/Re≈103.6"。
Cavity 与 Poiseuille 两案例通过独立复核（1.34% / 0%），**自判未发现粉饰**。
