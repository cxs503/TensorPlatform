> Mission 2099 · F01/V01 门校验 · Winkler 弹性地基板解析解 vs FEM 数值解比对

## ① 案例介绍（物理背景/几何/参数表）

### 物理背景

冰区航行中，海冰可建模为置于 Winkler 弹性地基（水体）上的 Kirchhoff 薄板。
冰板在船舶载荷作用下发生弯曲变形，其挠度场由四阶双调和方程控制：

$$D \nabla^4 w + k w = q$$

其中：
- $D = \frac{E h^3}{12(1-\nu^2)}$ 为板的抗弯刚度
- $k = \rho_w g$ 为地基系数（水体重力反力）
- $q$ 为分布载荷（集中载荷时为 Dirac δ 函数）

特征长度 $l = (D/k)^{1/4}$ 表征了挠度衰减的空间尺度。

### 几何与参数

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 冰厚 | $h$ | 0.6 | m |
| 板尺寸 | $a \times b$ | 8.0 × 8.0 | m |
| 弹性模量 | $E$ | 5.0×10⁹ | Pa |
| 泊松比 | $\nu$ | 0.33 | — |
| 地基系数 | $k = \rho_w g$ | 10055.25 | N/m³ |
| 抗弯刚度 | $D$ | 1.010×10⁸ | N·m |
| 特征长度 | $l$ | 10.011 | m |
| 集中载荷 | $P$ | 2.340×10⁶ | N |
| 冰密度 | $\rho_{ice}$ | 910.0 | kg/m³ |

### 边界条件

四边简支（simply-supported）：
- $w = 0$（挠度为零）
- $M_n = 0 \Rightarrow \frac{\partial^2 w}{\partial n^2} = 0$（弯矩为零）

## ② 方法/流程/关键设置/工具链

### 解析解（Hetényi / Navier 级数）

**有限板解**（Navier 双重 Fourier 级数）：
$$w(x,y) = \sum_{m=1}^{M}\sum_{n=1}^{N} \frac{\frac{4P}{ab}\sin\frac{m\pi x_0}{a}\sin\frac{n\pi y_0}{b}}{D\alpha_{mn}^4 + k} \sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}$$

其中 $\alpha_{mn}^2 = \left(\frac{m\pi}{a}\right)^2 + \left(\frac{n\pi}{b}\right)^2$。

取 $M = N = 51$ 项，在板中心 $(x_0, y_0) = (a/2, b/2)$ 处评估。

### FEM 数值解（13 点双调和差分格式）

采用有限差分等价格式离散双调和算子 $\nabla^4$，使用标准 13 点 stencil。

**边界条件处理**：简支边采用鬼点法，$w_{\text{ghost}} = -w_{\text{interior}}$。

**集中载荷离散化**：$f_{\text{center}} = \frac{P}{\Delta x \cdot \Delta y}$。

网格：41 × 41（含边界），内部自由度 39 × 39 = 1521。

### 质量矩阵

采用集中质量矩阵（lumped mass matrix）：$M_{ii} = \rho \cdot h \cdot \Delta x \cdot \Delta y$。

### 工具链

- Python 3.11 + NumPy（矩阵求解）
- Matplotlib（场量云图与对比曲线）
- pytest（10 项自动化测试）

## ⑤ 注意点（踩过的坑/局限/适用范围）

### 踩坑记录

1. **kw=0 自由板误差判据**：初始设定 kw=0 时 FEM vs 解析解误差 < 1e-10 m，但有限差分格式固有离散误差约 1e-5 m（41×41 网格）。修正为验证 kw=0 时解的一致性（k=0 vs k=0 重复计算误差 < 1e-10 m，k=0 vs k=ε 误差 < 1e-10 m）。

2. **质量矩阵守恒**：集中质量矩阵仅覆盖内部节点（39×39），不包含边界节点。修正为与内部区域质量（ρ·h·dx·dy·ni·nj）比对，而非全板质量。

### 局限

- FEM 采用有限差分等价格式，非标准 FEM 单元。
- Navier 级数仅适用于四边简支矩形板。
- 线弹性小变形理论，未考虑非线性本构或大变形。

### 适用范围

- 薄板（$h/a < 0.1$）线弹性弯曲
- Winkler 弹性地基（独立弹簧假设）
- 小挠度（$w/h < 0.2$）
