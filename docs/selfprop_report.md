# 自航点反解与推进效率链分析报告（m21817）

## 1. 案例介绍

**物理背景**：船舶自航试验中，螺旋桨转速 n 需满足推力平衡方程 T(1-t) = R_T，
其中 R_T 为总阻力，t 为推力减额。推进效率链 eta_D = eta_H * eta_R * eta_0 中，
相对旋转效率 eta_R 传统上被错误地设为常数 1.0（m21514 实测偏差 121.1%）。

**船型参数**（中速船系列，Cb 变化）：

| 参数 | 值 |
|------|-----|
| 垂线间长 Lpp | 200.0 m |
| 型宽 B | 30.0 m |
| 吃水 T | 9.5 m |
| 方形系数 Cb | 0.700-0.740（11 状态） |
| 螺旋桨直径 D | 7.0 m |

## 2. 方法

**自航点反解**：
1. 由 R_T（只读 calc.resistance 现值）与 t 求所需推力 T_req = R_T/(1-t)
2. 用 BEMT 敞水求解器（叶元动量理论，Prandtl 梢部损失）反解 n 使 T(n) = T_req
3. 二分法求解，收敛容差 1e-12

**eta_R 计算**（Holtrop 1984 表 4）：

    eta_R = 1.0 + 0.044*(iE - 10) - 0.012*(B/T) + 0.004*(Lpp/B) - 0.002*(Cb - 0.6)^2

其中 iE 为半进流角，由 Holtrop 回归式计算。

**适用域**（Holtrop 1984 Sec.1）：Cb in [0.50, 0.90]，L/B in [3.9, 14.0]，B/T in [2.1, 4.0]
越域状态判 WITHHELD，不得 pass。

**非平凡性断言**：eta_D = eta_H * eta_R * eta_0 任一因子方差为 0 -> 判「不可用于诊断」并 fail。

## 5. 注意点

1. **Holtrop eta_R 公式适用域**：Cb in [0.50, 0.90]，L/B in [3.9, 14.0]，B/T in [2.1, 4.0]。
   越域时 eta_R 返回 None，对应状态判 WITHHELD，不得 pass。
2. **eta_R 物理窗**：工程上 eta_R 通常在 [0.90, 1.10] 范围内。超出此窗的状态判 OUT_OF_WINDOW。
3. **非平凡性断言**：若 eta_R、eta_0 或 eta_H 任一因子方差为 0（恒等），则 eta_D 乘性恒等
   「不可用于诊断」，直接 fail。这防止了用恒等值伪装推进效率链健康的假阳性。
4. **BEMT 求解器**：使用叶元动量理论（BEMT）+ Prandtl 梢部损失，天然满足致动盘
   效率上界 eta_I = 2/(1+sqrt(1+C_T))，不会出现 eta_0 > 1 的非物理结果。
5. **阻力模块只读**：R_T 沿用 calc.resistance 现值，不修改阻力模块。
