## ① 案例介绍（物理背景/几何/参数表）

### 物理背景

船舶总阻力系数 $C_T$ 是船舶阻力性能的核心无量纲参数，定义为：

$$C_T = \frac{R_T}{\frac{1}{2}\rho S V^2}$$

其中 $R_T$ 为总阻力，$\rho$ 为水密度，$S$ 为湿表面积，$V$ 为航速。

ITTC'78 方法是国际拖曳水池会议推荐的全尺度阻力预报标准流程，包含：
- ITTC-1957 摩擦阻力系数公式：$C_f = 0.075 / (\log_{10} Re - 2)^2$
- Holtrop-1982/1984 剩余阻力回归模型
- 粗糙度补贴 $\Delta C_f$（等效砂粒粗糙度 $k_s = 150\ \mu m$）

## ② 怎么做的（方法/流程/关键设置/工具链）

### 测试流程

1. **定义基准算例**: 从公开文献提取 3 个船型共 10 个工况点的主尺度、航速、实验 Ct 值
2. **调用 API**: 对每个算例调用 `POST /api/v1/calculations/resistance`，传入船型、航速、主尺度、排水量、湿面积
3. **提取预测值**: 从 API 响应提取 `ct`、`cf`、`cr`、`wetted_surface` 等字段
4. **计算误差**: $Error\% = |C_{T,calc} - C_{T,exp}| / C_{T,exp} \times 100\%$
5. **判定**: 误差 <5% 为 PASS，否则为 FAIL

### 关键设置

- API 使用 Holtrop-1982/1984 方法，自动计算湿面积（忽略传入的 `wetted_surface_m2`）
- 粗糙度 $k_s = 150\ \mu m$（ITTC-78 标准值）
- 默认中剖面系数 $C_m = 0.98$，水线面系数 $C_{wp} = (1+2C_b)/3$
- 无球鼻艏声明（ABT=0），无艉封板声明（AT=0）

### 工具链

- Python 3 + urllib（API 调用）
- matplotlib（图表生成）
- 所有数字由程序计算，零手抄

## ⑤ 注意点（踩过的坑/局限/适用范围）

### 已知局限

1. **Holtrop 方法不适用于轴对称回转体**: SUBOFF 是潜艇标准模型（body of revolution），Holtrop-1982/1984 是为常规排水型单体船开发的经验回归模型。将 Holtrop 应用于 SUBOFF 属于方法误用，预期误差极大（实测 194-258%）。API 响应中也明确标注了 "Holtrop 回归域" 警告。

2. **湿面积计算差异**: API 使用 Holtrop-1984 回归式自动计算湿面积，忽略调用方传入的 `wetted_surface_m2`。对 DTMB-5415，API 计算 S=2982 m² vs 文献值 3800 m²（偏差 22%）；对 KVLCC2，API 计算 S=26627 m² vs 文献值 27194 m²（偏差 2%）。湿面积差异直接影响 Ct 计算基准。

3. **低速区兴波回归坍缩**: API 响应明确指出 "兴波回归处于坍缩区"（exp 自变量=-13.75），在 Fr<0.20 的高 Cb 区，Holtrop 的兴波项不提供残差量级保证。这解释了 KVLCC2 在 Fr=0.13-0.15 区间的系统性低估。

4. **球鼻艏未声明**: KVLCC2 作为现代 VLCC 通常带有球鼻艏，但 API 调用时未声明 ABT 参数，导致 c2=1（兴波上界），可能高估兴波阻力约 26%。但实际兴波项本身已坍缩，故此影响有限。

5. **实验 Ct 基准的不确定性**: 全尺度外推 Ct 值本身有 3-5% 的不确定度（来自模型试验测量误差、尺度效应外推不确定性等）。本报告的误差计算未扣除此不确定度。

### 适用范围

- Holtrop 方法适用于 Fr = 0.1–0.35 的常规排水型单体船
- 不适用于：轴对称回转体（潜艇）、高速滑行艇、多体船、小水线面双体船等
- 对高 Cb 船型（Cb > 0.75）在低 Fr 区（Fr < 0.15）的兴波预报可靠性有限

## ⑥ 误差判定

### 关键量 vs 基准误差逐项列出

| 船型 | 指标 | 误差范围 | 是否 <5% |
|------|------|---------|---------|
| DTMB-5415 | Ct | 0.2% – 25.4% | ❌ 否（仅 25 kn 工况达标） |
| KVLCC2 | Ct | 23.9% – 27.4% | ❌ 否 |
| SUBOFF | Ct | 194.1% – 257.6% | ❌ 否（方法不适用） |

### 显式回答

**是否 <5%？**

- DTMB-5415: **否**。4 个工况中仅 1 个（25 kn, Fr=0.338）误差 <5%，其余 3 个误差 13-25%。
- KVLCC2: **否**。3 个工况误差均 >23%，系统性低估。
- SUBOFF: **否**。Holtrop 方法不适用于轴对称回转体，误差 194-258% 属预期行为。

**验收判据（≥2/3 船型 Ct 误差 <5%）: FAIL（0/3 船型通过）**

### 误差原因分析

1. **DTMB-5415 误差来源**:
   - 湿面积低估 22%（API 用 Holtrop 公式 vs 文献值）
   - 中高速区（Fr>0.27）兴波阻力预报改善，25 kn 时吻合
   - 低速区剩余阻力低估

2. **KVLCC2 误差来源**:
   - 兴波回归在 Fr<0.15 区坍缩，剩余阻力系统性低估
   - 粗糙度补贴 dcf=0.000176 偏低（ITTC-78 对 320m 船通常取 0.0004）
   - 球鼻艏未声明导致兴波项口径偏差

3. **SUBOFF 误差来源**:
   - Holtrop 方法根本不适用于轴对称回转体
   - 回转体的阻力机理（黏压阻力主导）与单体船（兴波+摩擦）完全不同
   - 属方法误用，非模型精度问题

### 改进建议

1. 对 SUBOFF 等轴对称体，应使用专用阻力预报方法（如 Gertler 潜艇阻力公式或 CFD）
2. 对 KVLCC2 等肥大型船，需校准低 Fr 区兴波回归系数或引入修正项
3. 湿面积计算应允许调用方传入经几何验证的 S 值，而非强制使用 Holtrop 估算
4. 粗糙度补贴 $\Delta C_f$ 应按船长查表（ITTC-78 推荐值），而非固定 ks=150 µm
