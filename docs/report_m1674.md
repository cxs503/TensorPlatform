## ① 案例介绍（物理背景 / 几何 / 参数表）

### 物理问题

平台有**四条**独立代码路径都在回答同一个物理问题——"这条船的静水总阻力是多少"：

| 路径 | 模块 | 声称方法 | 证据等级 |
|---|---|---|---|
| A | `backend/services/holtrop_mennen.py` | Holtrop-Mennen 1982（m2 波形拟合）+ 1984 增补 | 自称完整 HM |
| B | `backend/services/ship_resistance.py` | 轴对称湿表面积 + `Cr=0.002(1+2Cb)Fn^2.5` | 端点标 REAL |
| C | `backend/services/digital_twin/models/resistance.py` | HM 1984（m4 拟合），Cm/Cwp 回归 | 自称 HM |
| D | `backend/services/polar/resistance.py` | HM 1984（m4），Cm=0.98 固定 | 极地航路优化生产路径 |

四条路径理应在各自适用域内给出相近答案。审计目标：用跨路径一致性作为独立判据，
检验每条路径的转写正确性。

### 审计船型（三档，覆盖细长/肥大/超肥大）

| 船型 | L [m] | B [m] | T [m] | Cb | L/B | Fn 范围 |
|---|---|---|---|---|---|---|
| KCS 集装箱船 | 230.0 | 32.2 | 10.8 | 0.6505 | 7.14 | 0.084–0.295 |
| 散货船 (BULKER) | 180.0 | 30.0 | 11.0 | 0.830 | 6.00 | 0.119–0.309 |
| VLCC 油轮 (TANKER) | 320.0 | 58.0 | 20.8 | 0.8098 | 5.52 | 0.125–0.295 |

环境参数：ρ = 1025 kg/m³，ν = 1.188×10⁻⁶ m²/s，均为实船尺度。

## ② 怎么做（方法 / 流程 / 关键设置 / 工具链）

### 方法论

1. **四路径同船同速直接求值**（`artifacts/m1674/probe_paths.py`）：
   用 `importlib` 按文件路径加载模块，不复制公式、不经过 HTTP，测的是线上实现本身。

2. **逐项消融归因**（`artifacts/m1674/ablation.py`）：
   把每个可疑项单独换回/换成发布式，于是每个百分数都是实测差，不是估计。
   存在的可疑项：
   - A 的 `c7` 分支归属（细长/肥大两支是否对调）
   - A、D 的 `c15` 分带（`L³/∇ < 512` 一段是否缺失）
   - D 的 `iE` 第五因子用 `(L/T)` 还是 `(LR/B)`
   - C 的湿表面积乘 `sqrt(Cb)` 还是 `sqrt(Cm)`
   - A 的 1982 m2 波形拟合 vs C/D 的 1984 m4 波形拟合

3. **c7 归属的独立判据（纯数学，不依赖外部数值）**：
   发布式必须在两个断点连续：
   - B/L=0.11：下支 `0.229577·0.11^(1/3) = 0.11000`，中支 `B/L = 0.11` → 连续
   - B/L=0.25：中支 `0.25`，上支 `0.5 − 0.0625·4 = 0.25` → 连续
   
   两个断点同时命中连续的概率可忽略；而**修前**的归属在 B/L=0.11 处跳变 **99%**。

4. **域内自洽判据**：模块自己声明有效域 `3.9 ≤ L/B ≤ 9.5`；
   修前的中支在 `L/B ≥ 8` 给出 `c7 ≤ 0`，即在自己宣称的域内给出非物理系数。

5. **修复后重新量测四路径分歧**，并把结果钉成回归守卫
   （`backend/tests/test_m1674_resistance_conformance.py`，10 个用例）。

### 工具链

- Python 3 + importlib（直接加载模块文件）
- pytest（81 项测试：conformance + holtrop + digital twin + polar）
- matplotlib（`fig1_paths_and_fix_effect.png`）
- 全在本机执行（load15 ≥ 100, nproc=128），纯解析求值，未起任何重算力进程

## ⑤ 注意点（坑 / 局限 / 适用范围）

### 踩过的坑

1. **"文档写了公式"不是证据。** `holtrop_mennen.py` 的模块 docstring 把 c7 的两支写反了，
   还附带一句"发布式在 B/L=0.11 不连续"的自证——错误转写会生成自己的合理性叙事。
   判据必须来自数学性质（连续、域内为正、量级），不能来自注释。

2. **量级放大效应**：c₁ ∝ c₇^3.78613，所以 c7 一支之差错 2.6 倍 → 兴波阻力差 **38 倍**。
   系数表里"看着差不多"的数字，进入乘方与指数后不可忽略。

3. **两条波形拟合版本共存是合法的，但必须声明**：A 用 1982 m2 型，C/D 用 1984 m4 型；
   在 Fn ≤ 0.22 两者差异被其他项掩盖，Fn ≥ 0.25 时分离
   （VLCC Fn=0.268 处 A=20.1 MN、D=22.4 MN）。
   平台目前**没有任何字段告诉调用方**它拿到的是哪一版。

### 局限

4. **端点 B 不是 HM**：`calc.resistance` 标 REAL 成立（它确实在算 ITTC-57 + 经验剩余阻力），
   但把它当"商船阻力预报"引用会差 71%。m1384 已在文档里注明，
   但 API 响应里没有 method 字段，消费方无从判断。

5. **只有 A 有适用域门**（`domain_warnings`/`in_domain`）。B/C/D 在 SUBOFF
   （B/T=1、Cb=0.54、Fn=0.46）这种完全域外输入上静默返回数值。
   已用测试把这个不对称钉住。

6. **未做**：
   - (a) 没有把 B/C/D 统一到 A 的单一实现（跨 3 个模块的重构，超出单席范围，建议派单）
   - (b) 未与任何试验数据集做精度对标——见 ⑥ 的原因
   - (c) 未覆盖自航因子链路

### 适用范围

- 本单结论仅适用于静水阻力预报；波浪增阻、风力、浅水效应未覆盖
- 三处修复针对 Holtrop-Mennen 方法族；其他经验方法（如 KVLCC2 系列、SUBOFF）不受影响
- 回归守卫钉住的是当前实现，未来重构需保持 10 个 conformance 用例通过

## ⑥ 误差判定（逐项回答"是否 <3%"）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| c7 在两个断点的连续性 | 分段式自身（解析） | 跳变 < 1e-4%（修前 99%） | **是** |
| c15 三带边界 | 发布式（解析） | 精确（0%） | **是** |
| A 分量求和恒等式 `RT=ΣRᵢ`、`Ct=RT/(½ρSV²)` | 代数恒等式 | ≤1e-12 相对 | **是** |
| D 分量恒等式 `total=viscous+wave+correlation` | 代数恒等式 | ≤1e-12 相对 | **是** |
| C 湿表面积 vs `sqrt(Cm)` 回归式 | 解析 | 0%（修前 3.5%—用 sqrt(Cb)） | **是** |
| A vs D（三船型全扫描） | 互为独立实现 | 最大 19.5% | **否** |
| A vs C（三船型全扫描） | 互为独立实现 | 最大 31.5% | **否** |
| A vs C（KCS 12 m/s 设计点） | 互为独立实现 | 10.9% | **否** |
| 端点 B vs HM | 方法互比 | 最大 70.6% | **否** |
| A 的 Ct vs canon v3.0 KVLCC2 列值 | 平台参考数据集（`rt_status=WITHHELD`，m1561 判不可作判据） | −30% | **否**，且**基准本身不可用** |

### 为什么没有 <3% 的试验对标

本单是**实现一致性 + 数学性质**审计，不是精度验证。
"是否 <3%"在这里只对代数恒等式与分段式连续性成立；三条 HM 路径之间、以及端点 B 与 HM 之间
都存在两位数百分比差异，这本身就是本单的结论（需要单一真源，不能四处各算一套）。

平台 canon v3.0 里唯一带船体阻力量值的 KVLCC2 行被 m1561 判为 `WITHHELD`
（不允许参与 15% 判决），因此本单**不作**试验精度声明。

**后续建议**：需单独派单做试验对标（如 KCS、KVLCC2 东京水池试验数据），
才能回答"Holtrop-Mennen 方法在本平台实现是否 <3% 精度"的问题。
