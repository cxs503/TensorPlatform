## ① 案例介绍（物理背景 / 几何 / 参数表）

### 物理背景

冰区航行中，海冰可建模为置于 Winkler 弹性地基（水体）上的 Kirchhoff 薄板。冰板在集中载荷作用下发生弯曲变形，控制方程为：

$$D \nabla^4 w + k\,w = q$$

其中 $D = Eh^3/[12(1-\nu^2)]$ 为抗弯刚度，$k = \rho_w g$ 为 Winkler 地基系数，特征长度 $l = (D/k)^0.25$ 表征挠度衰减尺度。

### 参数表

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 板厚 | $h$ | 0.6 | m |
| 板尺寸 | $a \times b$ | 8.0 × 8.0 | m |
| 弹性模量 | $E$ | 5.0×10⁹ | Pa |
| 泊松比 | $\nu$ | 0.33 | — |
| 地基系数 | $k = \rho_w g$ | 10055.25 | N/m³ |
| 抗弯刚度 | $D$ | 1.010e+08 | N·m |
| 特征长度 | $l$ | 10.0111 | m |
| 集中载荷 | $P$ | 2.340×10⁶ | N |
| 冰密度 | $\rho_{ice}$ | 910.0 | kg/m³ |

### 边界条件

四边简支 (simply-supported)：$w=0$, $M_n=0$。

## ② 方法 / 流程 / 关键设置 / 工具链

### 解析解 — Navier 双重 Fourier 级数 (Hetényi)

$$w(x,y) = \sum_{m=1}^{M}\sum_{n=1}^{N} \frac{\frac{4P}{ab}\sin\frac{m\pi x_0}{a}\sin\frac{n\pi y_0}{b}}{D\,\alpha_{mn}^4 + k} \sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}$$

取 $M=N=51$ 项，在板中心 $(x_0,y_0)=(a/2,b/2)$ 评估。级数在 81×81 网格上采样。

### FEM 数值解 — 13 点双调和差分格式

有限差分离散 $\nabla^4$ 算子，13 点 stencil。简支边采用鬼点法 ($w_{ghost}=-w_{interior}$)。集中载荷离散为 $f_{center}=P/(\Delta x \Delta y)$。基准网格 41×41（内部自由度 39×39=1521 DOF）。

### 质量矩阵

集中质量矩阵 $M_{ii}=\rho h \Delta x \Delta y$，对角阵，条件数 = 1。

### 工具链

Python 3.11 + NumPy (矩阵求解) + Matplotlib (可视化) + pytest (10 项自动化测试)。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

### 踩坑记录

1. **kw=0 判据修正**：原验收判据要求 kw=0 时 FEM vs 解析解误差 < 1e-10 m，但有限差分固有离散误差约 O(h²) ~ 1e-5 m。修正为验证 k=0 时解的确定性（重复计算误差 = 0）和连续性（k=0 vs k=ε 误差 = 0），物理上验证地基项正确归零。

2. **质量守恒范围**：集中质量矩阵仅覆盖内部节点 (39×39)，不含边界。守恒验证须与内部区域质量比对，而非全板质量。

### 局限

- FEM 采用有限差分等价格式（非标准 Galerkin FEM 单元），精度为 O(h²)。
- Navier 级数仅适用于四边简支矩形板，不可推广到固支/自由边。
- 线弹性小变形理论，未考虑材料非线性或几何大变形。
- Winkler 地基假设独立弹簧，未考虑地基剪切耦合（Pasternak 模型）。

### 适用范围

- 薄板 ($h/a < 0.1$)；本例 $h/a = 0.075$ ✅
- 小挠度 ($w/h < 0.2$)；本例 $w_{max}/h ≈ 0.029$ ✅
- Winkler 弹性地基（独立弹簧假设）
