### 方法

1. **提案池扫描**：遍历 `/root/tp-agent/proposals/` 下所有子目录，统计 JSON 提案文件数量与分布
2. **报告端点查询**：GET `/api/v1/tensor/reports?limit=20`，提取各报告"局限/待办"节

### 工具链

- `os.walk()` + `json.load()` 程序化统计
- `urllib.request` / `curl` 调用 API
- `python3 -c` 内联解析 JSON

### 关键设置

- 只读操作，不修改任何业务数据
- 提案计数以 `.json` 文件为单元
- 报告取最近 20 条（limit=20）
