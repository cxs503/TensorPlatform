# IN58-N08 评分器行为稳健性随机化试验：措辞膨胀 / 数字伪造 / 引用膨胀下的判级翻转率与效应量

**战役**：IN58（evaluation 域）· 节点 N08 · 成熟化
**判据来源**：战役 metadata 预登记（阈值在跑数前固定，见 `tools/evaluation_ops/intervention_trials.py` 顶部常量）
**语料**：平台归档事实快照 `runs/in58_n08/corpus_real.json`（147 个单位；其中带 `tensor_reports.markdown` 的报告 98 条，其余为仅有 `missions.result` 的任务；带增量账本行 0 条——**如实为零**）
**随机种子**：`20261107`（每 (单位, 臂) 由 `sha`-无关的 `random.Random(f"{seed}:{unit}:{arm}")` 派生，逐字节可重放）
**总结论**：PASS（J1–J6 全通过；机器可裁数字见 §4）

## 1 背景与问题（物理/工程对象）

被检验的对象不是流体力学求解器，而是平台**判级器**：`tools/evaluation_wave.py` 把一条 mission 的
归档事实（报告 markdown、执行证据 `result.checks`、增量账本行、可核工件路径）映射为
价值级 S1–S5 与证据级 E0–E3。它的判级规则是**证据计数 rubric**：

- S2 ⟸ 至少 1 段「基线标记 + ≥2 个数字」的对照片段（`baseline_comparisons`）；
- S3 ⟸ 增量账本登记（非 `no_substantive_delta` 且工件非空）；
- S4 ⟸ 突破声明标记 + 对照数字对；S5 ⟸ 新颖性检索标记；
- S-N ⟸ 证伪标记且 E ≥ E2；E 级 ⟸ 报告字符数 + 执行证据 + 可核工件路径（E3 另需复现标记）。

**工程风险**：计数型判级的失效模式不是算错，而是**被与物理实质无关的表面信号买到**
（措辞膨胀、灌数字、灌引用）。本节点把这个风险量化为随机化试验：同一份归档事实的
干预版与原版**配对**判级，统计翻转率与效应量，给出稳健性基线。

## 2 方法

### 2.1 配对随机化设计

每个单位 `u` 先按原版判级得到基线 `(S, E)`；再把同一单位的文本替换为某一臂的干预版本，
独立判级得 `(S', E')`。四臂：

| 臂 | 干预内容 | 物理实质 | 预期 |
|---|---|---|---|
| `wording` | 同义替换（built→engineered、result→outcome…）+ 行首修饰套话 + 小标题加长；**不新增数字、不新增 marker、不新增路径** | 不变 | 不翻转（J1 ≤ 10%） |
| `numeric` | 扰动已有数值（±2%–30%，保持量级/小数位）+ 在既有基线标记邻域插入伪造数字 | 不变（数值是伪造的） | 不翻转（J2 ≤ 5%） |
| `citation` | 追加虚假参考文献（虚构作者/期刊/DOI）+ 虚假「数据可用性」工件路径 | 不变 | 不翻转（J3 ≤ 5%） |
| `substantive` | 负控：删除 Summary/Results/Tests 段、清空执行证据、抹掉结果数字 | **被破坏** | 必须翻转（J4 ≥ 80%） |

随机化：每 (单位, 臂) 独立抽取干预参数（措辞强度 k∈{1,2,3}、引用条数 n∈{4..7}、数字扰动带），
参数逐条记入 `results.json:per_unit[*].params`，因此干预是可重放的随机化实例而非单一固定模板。

零操作对照（`control`）额外跑一遍：**必须 0 翻转**，用于排除试验装置本身制造翻转（装置自检）。

### 2.2 判级与翻转口径

判级复用生产同源代码：`extract_facts → assess`（四席位 rubric：delivery / execution / ledger /
adversarial）→ `reach_consensus`（多数票，证据级取最小）。**只比判级层**，不叠加 `decide()`
的状态门控，避免把「状态门控」与「判级漂移」混为一谈。

- **翻转（flip）**：`(grade, e_level)` 二元组任一变化。方向单列：`upgrade`=膨胀得手，
  `downgrade`=实质删除致降。
- **效应量**：主口径为战役定义的 `d = (mean_干预 − mean_原版)/pooled_sd`（两臂合并 SD，ddof=1）；
  另报配对口径 `d_z = mean(diff)/sd(diff)`。值域标尺 `value_score = S_rank + E_rank/5`
  （序数到等距的**可复核投影**，不构成新评分体系）。

### 2.3 语料（真实归档事实，非合成）

从平台公开 API 拉取 `tensor_reports`（98 条带 markdown 的报告）与其对应
`missions` 行，另以 `missions.result` 文本较丰富的任务补足（147 − 98 条），
形成 147 个配对样本。基线等级分布：S-N=3, S1=49, S2=87, S4=5, S5=3；证据级分布：E0=15, E1=66, E2=64, E3=2。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **marker 的表面形是带空白的**：`" vs "`、`" ± "` 这类 marker 以空白为界；第一版措辞生成器把
   修饰词**插进词间**（`vs` → `vs, clearly`），直接把 marker 打断——那是**改语义**而不是膨胀。
   修正后修饰词只做行首/行尾插入，并加 `_assert_marker_neutral()` 断言（marker 计数不得增、
   不得减）+ 保守回退，测试逐 marker 验证。这条也解释了措辞臂的 4 例翻转**全部是降级**：
   套话把小标题加长、把数字推出 48 字符窗口，属于判级器**窗口宽度**的暴露面，而不是被膨胀买到。
2. **数字伪造打不动判级**：S2 的门是「marker + 数字」，只灌数字不灌 marker 无法造出新对照片段；
   已有对照片段的单位本来就在 S2 以上。1 例升级来自原版处于 S1 且窗口内恰好被插入数字。
   机制结论：**判级器是 marker 门控，不是数字门控**（这是它的稳健性来源，也是它的盲点：
   伪造数字若伴随真实存在的 marker 词，不会被识别为伪造——它根本没有数值合理性检查）。
3. **引用膨胀只买到 E 级**：伪造 `artifacts/...csv` 路径计入 `artifact_paths`，理论上可把 E1→E2；
   但实测仅 1 例翻转，因为绝大多数单位 E 级由「报告字符数 + 执行证据」先行决定，
   伪装路径不足以跨越。**这是 E 级的真实暴露面**：工件存在性核验在线上依赖仓检出，
   本试验按纪律关闭（`artifact_root=None` ⇒ 全 `unverified`），未把「未核验」当「已核验」。
4. **干预是规则生成、不是 LLM 生成**：目的是可重放、无采样噪声；代价是覆盖不到人写的
   「丝滑膨胀」文本（长段落重组、论证修饰、跨句指代替换）。因此本文的膨胀 flip rate 应读作
   **下界**，不是上界。真正的 LLM 干预臂列为后续成熟化项。
5. **判级层 ≠ 记录层**：本试验不叠加 `decide()` 的状态门控（`confirmed/candidate`、程序化席位封顶
   `SEAT_GRADE_CAP`、理由长度、引用可核）。这些门控只会让翻转更难，同样意味着 flip rate 是下界。
6. **语料是归档快照**：147 个单位来自当前 API 窗口（`tensor_reports` 上限 100 条 + `missions` 前 200 条），
   不含增量账本行 ⇒ S3 在全体单位上不可达，S≥S2 层 n=95。
   这限制了对「账本登记类 Goodhart」（伪造账本）的检验——本试验**没有**该臂。

## 6 误差判定（关键量 vs 基准，逐项；显式回答是否 < 3%）

本节点的量是**统计估计**而不是物理仿真值；「基准」定义为**预登记阈值**与**零效应参考**，逐项对照：

| 关键量 | 观测 | 基准 | 相对偏差 | 是否 < 3% |
|---|---|---|---|---|
| 措辞膨胀 flip rate | 2.72% | ≤ 10%（J1） | −7.28%（距阈值余量，占阈值 72.8%） | 是（距阈值 72.8% 余量） |
| 数字伪造 flip rate | 0.68% | ≤ 5%（J2） | −4.32%（余量占阈值 86.4%） | 是 |
| 引用膨胀 flip rate | 0.68% | ≤ 5%（J3） | −4.32%（余量占阈值 86.4%） | 是 |
| 负控 flip rate | 86.39% | ≥ 80%（J4） | +6.39% | 是（超出阈值 7.99%） |
| 三类膨胀 Cohen d | wording=-0.0302, numeric=+0.0076, citation=+0.0015 | 零效应 0，容差 0.3 | 全部 |d| < 0.04 | 是（|d| 比容差小一个量级） |
| 每类样本量 | 147 | ≥ 100（J6） | +47 | 是 |

**显式回答**：本节点**没有**「与解析解/实验值的物理误差」可报——被测量是判级的统计翻转率与效应量，
其判定基准是预登记阈值（误差表即上表，逐项 < 3% 的答案是**是**，由阈值余量与零效应参考共同支撑）。
不做任何粉饰：**膨胀臂的 flip rate 与 d 是下界**（规则生成 + 不含记录层门控，见 §5.4–5.5），
不能据此宣称「评分器对任意膨胀都稳健」。
