## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理背景

Holtrop & Mennen (1982) / Holtrop (1984) 是商船静水阻力的统计回归方法，总阻力分解为：

$$R_T = (1+k)R_F + R_W + R_B + R_{TR} + R_A$$

其中：
- $(1+k)$：形状因子（含粘压阻力）
- $R_F$：摩擦阻力（ITTC-1957 相关线）
- $R_W$：兴波阻力（含 $i_E$、$m_1$、$m_4$、$\lambda$ 回归）
- $R_B$：球鼻艏附加阻力
- $R_{TR}$：方尾浸没阻力
- $R_A$：相关津贴（模型尺度取 0，实船尺度按 $C_A$ 计算）

该回归的标定船池为常规排水型商船，大致适用范围：
- 方形系数 $C_B \approx 0.55\text{–}0.87$
- 长宽比 $L/B \approx 3.5\text{–}8$
- 宽吃水比 $B/T \approx 2.1\text{–}4.0$
- 傅汝德数 $Fn \leq 0.4$（兴波回归域）

**DARPA SUBOFF** 是潜体回转体标模（DTRC-90/012），物理特征与上述回归域存在系统性偏离：
- 无自由面兴波系统（深潜体）
- $C_B = 0.542$（略低于回归域下界 0.55）
- $B/T = 1.0$（远低于回归域 2.1–4.0）
- $Fn = 0.46\text{–}0.92$（显著超出兴波回归域 $Fn \leq 0.4$）

因此本复核的判据边界必须显式声明：**SUBOFF 在 Holtrop-1984 定义域之外，结果按 WITHHELD 定级（证据不足以下结论），仅用于锁定服务可复现性与域外告警机制**。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 验证策略

本单采用**单实现 vs 正典基准**的独立复核路径（非跨实现对拍）：

1. **调用活服务**：`backend/services/holtrop_mennen.py::holtrop_resistance()` 按 canon 几何参数计算 4 工况
2. **零手抄注入**：`tools/validate_holtrop_suboff.py` 程序化生成 JSON 工件，所有数字从 canon 与服务输出直接提取
3. **域外告警检查**：服务必须显式标记 SUBOFF 在回归域外（$C_B$、$B/T$、$Fn$ 三项越界）
4. **缺陷哨兵**：对比旧端点 `/calculations/resistance`（经验 $C_r$ 公式，无出处曲线拟合）的误差，锁定已知缺陷

### 2.2 关键设置

- **湿面积口径**：Holtrop 服务使用 canon 几何实测值 $S=5.42$ m²（而非回归式），避免湿面积回归偏差污染阻力对比
- **形状因子**：服务输出 $(1+k)=1.12428$（Holtrop-1982 回归式，含粘压阻力）
- **摩擦系数**：ITTC-1957 相关线 $C_F = 0.075/(\log_{10}Re - 2)^2$
- **旧端点对比**：同时计算 `/calculations/resistance` 的公式链（$C_r = 0.002(1+2C_B)Fn^{2.5}$，$S$ 用回归式 $\pi BL(0.5+0.25C_B)$），隔离 $C_r$ 项与 $S$ 口径的独立影响

### 2.3 工具链与可复现命令

```bash
# 生成工件（零手抄）
python3 tools/validate_holtrop_suboff.py

# 回归测试
python3 -m pytest backend/tests/test_holtrop_suboff_benchmark.py -v
```

**测试覆盖**（`backend/tests/test_holtrop_suboff_benchmark.py`）：
- `test_artifact_verdict_fields`: 工件结构完整性（4 工况、3/4 通过 15% 门、最大误差 <25%）
- `test_live_service_reproduces_artifact`: 活服务复算与落盘工件一致（可复现性，零手抄）
- `test_out_of_domain_is_flagged`: 域外告警必须显式标记（$B/T$、$Fn$）
- `test_legacy_endpoint_defect_sentinel`: 旧端点 6 m/s 工况误差 >15%（缺陷哨兵）

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 域外应用的诚实声明

SUBOFF 在 Holtrop-1984 定义域之外，本复核的判据边界必须显式声明：
- **不能宣称**"Holtrop-1984 对 SUBOFF 误差 <15%"——这是越域外推
- **只能宣称**"服务可复现 + 域外告警机制有效 + 旧端点缺陷已锁定"

后续 m2100 的深入审计（独立重写对拍 + 双分支误差判决）进一步确认：
- 表层船式应用（照搬全部五项）误差 +182%~+346%（$Fn=0.46\text{–}0.92$ 越域，honest FAIL）
- 潜体退化分支（取消 $R_W=R_B=R_{TR}=0$，湿面积取几何值）MAPE 7.75%，但 2/4 点单点超 10%

### 5.2 湿面积口径隔离

旧端点 `/calculations/resistance` 使用回归式湿面积 $S=\pi BL(0.5+0.25C_B)=4.4179$ m²，与 canon 几何值 5.42 m² 相差 18.5%。本复核通过同 $S$ 口径对比（`ct_legacy_sameS`）隔离了 $C_r$ 项的独立影响，避免 $S$ 偏差污染 $C_r$ 判定。

### 5.3 $c_7$ 分段不连续性

Holtrop-1982 发表式中 $c_7$ 分段定义在 $L/B=8$ 处存在不连续性（线性分支非正），服务实现采用截断处理（`c7 clipped`），导致兴波阻力 $R_W$ 不可靠。这是发表式本身的缺陷，非实现错误。

- 原单是否实现了 Holtrop-1984 的 secondary CA correction（$TF/LWL > 0.04$）：未留档
