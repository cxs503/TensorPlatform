## 1. 物理背景与问题形状

在 ABM（Agent-Based Modeling）攻关编排协议中，六维评价表（正确性/精度/稳定性/效率/可复现性/适用范围）
长期存在一个**结构性缺陷**：「优于对照」的结论靠叙事而非统计判决。本节点把「优于对照」从叙事
升级为**带第一类错误控制的统计判决**——六维各定义效应量（Cohen's d 或配对差中位数）、
配对设计（同任务谱系同一 seat 的两路线成对）、置换检验 10^4 次 + Bonferroni-Holm FWER 控制、
MDE(n) 曲线与样本量反解、A/A 空对照校准、以及 P1/P2 既有产物的回溯性功效。

## 2. 方法

### 2.1 核心引擎（`tools/abm/six_dim_power.py`）

| 函数 | 定义 |
|---|---|
| `cohens_d(control, treatment)` | 配对设计 Cohen's d = mean(diff)/std(diff) |
| `paired_median_diff(control, treatment)` | 配对差中位数（非参数、抗异常值） |
| `permutation_test_six_dim(...)` | 六维逐一配对置换检验 + Bonferroni-Holm / Bonferroni / none |
| `mde_curve(...)` / `solve_n_for_mde(...)` | MDE(n) 曲线与样本量反解（含解析对照） |
| `aa_false_positive_rate(...)` | A/A 空对照误报率（检验程序自身校准） |
| `retrospective_power(...)` | 既有实验数据的回溯性功效 |
| `six_dim_power_gate(...)` | 顶层判决：`pass` / `fail` / `inconclusive` |
| `six_dim_advantage(...)` | **族判决**：≥`min_dims` 维在 Holm 校正后显著更好 |
| `null_family_sim(...)` / `aa_null_control(...)` | 零效应族模拟 / A/A 空对照（族级 FWER） |
| `power_positive_control(...)` | 功效正控：已知合成效应下的实测检出率 |
| `family_decision_power_curve(...)` | 族判决功效随 n 的曲线 |
| `required_n_for_family_decision(...)` | 从曲线反解「判出 ≥k 维优势所需配对对数」 |

### 2.2 判决规则 G25（预声明）

> 六维中**至少 k 维（默认 2）**在 Holm(α=0.05) 校正后仍显著为实验组更好（方向性备择 `greater`）。

方向性备择是预声明的——命题本身是「优于」而非「不同」；双侧变体在 `aa_null_control` /
`power_vs_rho` 中一并报告作为稳健性行，不改主判据。

## 4. 误差判定（逐项回答「是否 <3%」）

| 关键量 vs 基准 | 误差 | <3%？ |
|---|---|---|
| 功效正控检出率 0.870 vs 解析 0.876 | 0.31% | **是** |
| MDE(n) n=20 vs 解析 2.80σ/√n | 6.6% | **否**（在 10% 判据内；小 n 由 t 分位修正主导） |
| MDE(n) n=60 vs 解析 | 2.1% | **是** |
| A/A 族误报率 0.010 vs α=0.05 | 点估计远低于 α | 估计量本身在 CI 内 |

## 5. 注意点与局限

1. **置换 p 值分辨率下限**：Holm 校正下最小可达 p = 1/(1+B) 必须 ≤ α/m；α=0.05、m=6 时
   B ≥ 119。`min_perm_for_holm()` 给出该值，`six_dim_advantage` / `null_family_sim` /
   `family_decision_power_curve` 都回写 `n_perm_resolution_ok`。
2. **n 小时 p 值离散**：等幅配对下双侧最小 p = 2/2^n（n=5 → 6.25% 拒绝不了）；
   `MIN_TESTABLE_PAIRS=9` 是设计下限。
3. **配对设计要求**：control 与 treatment 必须一一对应（同一 (lineage, seat) 的两臂测量）；
   独立双样本需改独立置换检验（本模块未实现，明确不支持）。
4. **rho 是设计假设**：配对收益取决于两臂相关；rho=0 行是保守下界，必须与主结果同报。
5. **P1/P2 回溯**：本节点用合成数据模拟 P1/P2 典型规模（n=8/12）；若实际产物有不同规模，
   需用实际数据重跑 `retrospective_power`。
6. **不替代物理判据**：统计显著 ≠ 物理重要。本模块只回答「差异是否可靠」，物理意义由领域判据决定。
