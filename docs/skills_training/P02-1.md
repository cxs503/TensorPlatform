# Work Breakdown：认证导出端点（API / 存储 / 文档 / 测试，≤4 agent）

> 本文档是 problem-decomposition 技能的 Required artifact（Work Breakdown）。
> 练习目标：规划一个认证导出端点，横跨 API、存储、文档、测试，至多 4 个 agent 分工。
> 标注约定（技能 Quality note 要求）：**[F]**=事实（可追溯到源码/命令输出）、**[I]**=推断、**[A]**=假设、**U**=未知。未执行的检查一律标 `not_run`，不标 passed。

---

## 1. 父目标（Parent goal）

在 TensorPlatform 后端（FastAPI + SQLAlchemy + Alembic，`backend/`）新增**认证数据导出端点**：
已认证用户可请求导出自己的数据（CSV/JSON）、查询导出状态、下载导出文件；
未认证/越权请求被拒绝。工作横跨四个域：**API、存储、文档、测试**，执行者 **≤4 个 agent**。

本单交付物是**规划本身**（本文件 + 机器可读依赖图 + 校验脚本），不实现生产代码。

## 2. 问题契约（Procedure 1：无契约则先建契约）

| 项 | 内容 |
|---|---|
| 目标 | 认证导出端点 v1：请求 → 状态 → 下载，全链路鉴权 |
| 范围内 | HTTP 路由与 schema；导出记录持久化 + 文件存储；OpenAPI/用户文档；测试（含负向授权测试） |
| 范围外 | 前端 UI；异步任务队列（v1 同步小导出）；新认证提供方；多租户隔离加固 [A] |
| 约束 | ≤4 agent；不修改共享认证模块 `backend/auth.py`（只读）；不触碰他人模块 |
| 成功判据 | 端到端验收矩阵（§14）全绿 + 安全评审签字 |

**[F] 仓库事实基线**（2026-11-08，`ls`/`head` 观察）：
- `backend/auth.py` 已提供 JWT 生成/验证与 `OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login")`；
- `backend/api/` 为路由目录（既有 `report.py`、`tensor_reports.py` 等路由可参照）；
- `backend/alembic/` 为迁移目录；`tests/` 为测试目录。

## 3. 最小端到端成果（Procedure 2）

最小可证切片（synchronous small export）：

1. `POST /api/v1/exports`（Bearer JWT）→ `202 {export_id, status_url}`
2. `GET /api/v1/exports/{id}` → `200 {status: pending|ready|failed}`
3. `GET /api/v1/exports/{id}/download` → `200` 文件字节流
4. 负向：无 token → `401`；他人 token → `403`；未知 id → `404`；过期 → `410`

该切片同时验证鉴权链与存储链，是"有用进展"的最小单元；异步队列留作后续版本 [I]。

## 5. 工作包（Procedure 4-5：按可独立验证的成果切分）

### WP0 接口契约冻结（owner: A1）
- **目标**：冻结 HTTP 契约 + 存储接口 + 错误码表（内容见 §6）。
- **输入**：§2 契约；`backend/auth.py`（只读）。
- **输出**：`contracts/exports.v1.md`（版本化，变更须集成负责人批准）。
- **验收**：4 个 agent 全部签认；契约含显式请求/响应 schema、状态码表、存储接口签名。
- **依赖**：无（首节点）。
- **风险**：契约漂移 → 版本化 + 变更走集成负责人。
- **权限**：仅写 `contracts/exports.v1.md`。
- **工作量**：0.5 人日。

### WP1 API 实现（owner: A1）
- **目标**：按契约实现 3 个端点，复用既有 JWT 依赖，路由内做资源级 owner 校验。
- **输入**：冻结契约 v1；存储接口（WP0 冻结）。
- **输出**：`backend/api/exports.py` + schema；应用装配。
- **验收**：契约一致性测试（A4 套件）通过；401/403/404/410 路径全部被断言。
- **依赖**：WP0（与 WP2 并行，因存储接口已在 WP0 冻结）。
- **风险**：既有依赖只给身份、不给资源级校验 → 提前 spike（§10 S1）。
- **权限**：仅写 `backend/api/exports.py` 与导出 schema。
- **工作量**：1.5 人日。

### WP2 存储实现（owner: A2）
- **目标**：导出记录模型 + 迁移 + 原子文件写 + 保留期清理。
- **输入**：冻结契约（存储接口签名）。
- **输出**：模型 + alembic 迁移（up/down）+ 仓储实现 + 文件写入器。
- **验收**：scratch DB 上迁移 up/down 通过；仓储单测（create/get/mark_ready/mark_failed/retention）全绿；文件经 tmp+`os.replace` 原子落盘。
- **依赖**：WP0。
- **风险**：大文件阻塞 worker → v1 限 10 MB [A]，spike S3 验证。
- **权限**：仅写 `backend/crud/export_repo.py`、导出模型、自己的 alembic 版本文件。
- **工作量**：1.5 人日。

### WP3 文档（owner: A3）
- **目标**：OpenAPI 片段 + 用户指南 + curl 示例。
- **输入**：冻结契约（**不依赖实现进度**）。
- **输出**：`docs/api/exports.md`；发布的 openapi 片段。
- **验收**：docs 构建通过；示例与契约逐字一致（diff 检查）；spec 通过 OpenAPI 3.1 校验。
- **依赖**：WP0。
- **风险**：spec 与实现漂移 → spec 文件单一 owner + CI diff 检查。
- **权限**：仅写 `docs/api/exports.md` 与 openapi 片段。

### WP4 测试（owner: A4）
- **目标**：测试套件 = 快乐路径 E2E + **负向授权测试** + 契约一致性 + 回归护栏。
- **输入**：冻结契约；E2E 部分依赖 WP1+WP2。
- **输出**：`tests/api/test_exports_authz.py`、`tests/api/test_exports_e2e.py`、fixtures。
- **验收**：套件本地全绿；负向测试显式断言 401/403/404/410；验收矩阵（§14）覆盖 100%。

- **风险**：共享 DB fixture 抖动 → 每测试事务回滚隔离。

## 6. 接口契约（Procedure 7：并行实现前先定契约）

### 6.1 HTTP 契约 v1
| 端点 | 方法 | 请求 | 成功 | 错误 |
|---|---|---|---|---|
| `/api/v1/exports` | POST | `{dataset: str, format: "csv"\|"json", max_rows?: int}` | `202 {export_id, status_url}` | 401/413/429 |
| `/api/v1/exports/{export_id}` | GET | — | `200 {export_id, status, created_at, url?}` | 401/403/404 |
| `/api/v1/exports/{export_id}/download` | GET | — | `200 application/octet-stream`（Content-Disposition） | 401/403/404/410 |

- 认证：`Authorization: Bearer <JWT>`，复用既有 `OAuth2PasswordBearer` [F]。
- 错误码表：`401` 缺失/无效 token；`403` token 有效但 `user_id != export.owner_id`；`404` 未知 id；`410` 已过期；`413` 超限；`429` 限流。

### 6.2 存储接口（Python 签名，冻结）
```python
class ExportRepository:
    def create(self, owner_id: str, dataset: str, format: str) -> str: ...
    def get(self, export_id: str) -> ExportRecord | None: ...
    def mark_ready(self, export_id: str, path: str, size: int) -> None: ...
    def mark_failed(self, export_id: str, reason: str) -> None: ...
```
- 文件布局：`data/exports/{owner_id}/{export_id}.{ext}`；原子写（tmp + `os.replace`）。
- 保留期：7 天 [A]；清理方式 [U]（cron 是否存在未知，缺省读时惰性清理）。

### 6.3 版本假设
Python 3.11、FastAPI、SQLAlchemy 2.x、Alembic、Postgres（均为仓库既有栈 [F]）；OpenAPI 3.1。
