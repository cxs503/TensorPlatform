> 本文件是练习中**由作者（同一模型/同一会话）预先自拟**的设计文档，属于评审对象的一部分，
> 不是独立需求来源。写作顺序：设计文档 → 测试清单 → 候选实现 → 评审报告（`../P07-1.md`）。
> 之所以保留这一顺序，是为了让评审能检验「实现是否满足其自述契约」，而不是只检验「测试是否绿」。

## 1. 背景与目标

平台数据集管理需要让用户把 CSV / Excel 原始数据上传到某个数据集上，随后由清洗、训练、
脱敏等下游模块统一按 UTF-8 CSV 读取。本端点负责第一步：接收文件、落盘、做最小可解析性检查、
更新数据集元数据。

## 2. 接口契约

| 方法 | 路径 | 认证 | 说明 |
|---|---|---|---|
| POST | `/api/v1/datasets` | Bearer | 创建数据集，`{"name": str}` → `{"dataset_id": int}` |
| POST | `/api/v1/datasets/{dataset_id}/upload` | Bearer | multipart `file` 字段上传，返回 `{dataset_id, bytes, rows, stored_name}` |
| GET | `/api/v1/datasets/{dataset_id}/download` | Bearer | 下载当前文件 |
| GET | `/api/v1/datasets/{dataset_id}/meta` | Bearer | 读取元数据 |

认证：`Authorization: Bearer <token>`，token 映射到用户名；用户名即租户主体。
错误码约定：401 未认证 / 404 资源不存在 / 403 越权 / 422 内容不可接受 / 413 超限。

## 3. 接受标准（Acceptance Criteria）

- **AC-1** 合法 CSV（含表头，≥1 数据行）上传返回 200，`bytes` 与请求体长度一致，`rows` 为数据行数。
- **AC-2** 上传后 `GET /download` 返回与上传字节完全一致的内容（sha256 相同）。
- **AC-3** 多租户隔离：写操作只能由 `dataset.owner` 执行，非属主返回 403；读操作同样要求属主或显式授权。
- **AC-4** 尺寸上限：单文件 ≤ 100 MiB，超限在**读取请求体之前**返回 413（依据 `Content-Length`，流式校验兜底）。
- **AC-5** 原子性：解析失败或中断时，数据集原版本必须保持不变（写临时文件 + `os.replace` + 元数据同事务）。
- **AC-6** 中断续传：客户端可带 `Content-Range`/偏移重新提交未完成的分片，服务端按偏移拼接；
  未声明完整的分片不得被登记为「当前完整版本」。
- **AC-7** 路径安全：落盘文件名由服务端生成，客户端提供的 `filename` 只作为展示名，不参与路径拼接。
- **AC-8** 内容校验：`Content-Type` 与扩展名一致性校验，二进制误标为 `.csv` 必须 422。

## 4. 非功能约定

- 单次上传并发上限：同一 `dataset_id` 同时只允许一个写事务（否则以 409 拒绝）。
- 资源：单进程 RSS 增长应与文件尺寸无关（流式落盘）。
- 可观测：失败写入需记录结构化日志（dataset_id、主体、字节数、失败原因），不留残留文件。
