# P06-2 诊断练习：分页 off-by-one 缺陷（玩具服务）

> 训练单产物。玩具服务与测试位于 `docs/skills_training/p06_2_toy/`，
> 全部 stdlib + pytest，无第三方依赖。本练习不使用平台技能库，方法自定。

## 1. 案例介绍

**系统**：`p06_2_toy/` 下的最小分页服务（Python 3.11，仅标准库）。

| 组件 | 文件 | 职责 |
|---|---|---|
| 核心分页逻辑 | `paginate.py` | `paginate(items, page, per_page) -> (rows, total, total_pages)`，1-based 页码 |
| HTTP 服务 | `service.py` | `GET /entries?page=N&per_page=M`，越界页返回 404 |
| 复现器 | `reproduce.py` | 起服务→逐页遍历→校验并集=全集，退出码 0/1 |
| 回归测试 | `test_pagination.py` | 5 个用例（含防过修守卫） |
| 单页探针 | `probe_page4.py` | 直接取第 4 页，打印状态码与响应体 |

**数据/参数**：10 条记录（id 1..10），`per_page=3`，理论页数 = ceil(10/3) = **4**（3+3+3+1）。

**埋设缺陷**（`paginate.py` 一行）：

```python
total_pages = total // per_page          # 埋设：floor 除法
```

**症状**：第 4 页（含最后 1 条记录）被 404 拒绝，最后一条记录不可达。

## 2. 方法（复现器 → 竞争假设 → 定位 → 因果解释 → 红→绿回归 → 最小修复）

### 2.1 复现器（先有可机器判定的判据）

`reproduce.py` 的判据：逐页抓取直到服务自报 `total_pages` 用尽，
断言「所有页的并集 == 全集 且 无重复」。退出码 0=覆盖完整，1=有缺失/重复。
修复前运行即稳定复现（见 §3 命令 [1]）。

### 2.2 竞争假设

| # | 假设 | 可区分预测 |
|---|---|---|
| H1 | 切片窗口错位（start/end off-by-one） | 页内条目会**重复或跨页漂移** |
| H2 | `total_pages` 用 floor 而非 ceil | 仅当 `total % per_page != 0` 时**末页整体消失**，页内内容正确 |
| H3 | 边界比较符错（`>` vs `>=`） | 恰好 `page == total_pages` 的页被拒，但 `total_pages` 数值本身正确 |
| H4 | 上游数据丢失（分页前 items 已少） | 服务返回的 `total` 字段 < 10 |

### 2.3 定位（逐假设探针）

1. **H4 排除**：page 1 响应 `total=10`，上游数据完整。
2. **H1 排除**：直接调用 `paginate(ITEMS, 4, 3)` 的切片 `items[9:12]` 正确给出 `[10]`；
   且复现器报告 `duplicates=0`、页内条目连续无漂移。
3. **H3 排除**：`total_pages` 自报为 3，而 10 条/每页 3 条需要 4 页——
   是**数值**错了，不是比较符错了（比较符 `page > total_pages` 语义正确）。
4. **H2 证实**：`10 // 3 = 3 ≠ ceil(10/3) = 4`；且 `1 // 3 = 0` 解释了
   单条数据集合报 0 页的伴生症状（`test_single_item` 红）。

### 2.4 因果解释

floor 除法丢弃余数：当 `total % per_page != 0` 时，合法页码上界被截短一页；
边界检查 `page > total_pages` 语义正确，却忠实地拒绝了本应存在的末页。
缺陷只在「非整除」时显形——整除场景（12/3）完全正常，这正是它难被发现的原因。

### 2.5 回归测试（先失败后通过）

- 修复前：`3 failed, 2 passed`（exit=1）——
  `test_all_items_reachable_across_pages`（缺 id=10）、
  `test_total_pages_is_ceil`（assert 3 == 4）、
  `test_single_item`（PageOutOfRange: page 1 out of range 1..0）。
- 修复后：`5 passed`（exit=0）。
- 防过修守卫：`test_exact_multiple_no_extra_page`（12/3→恰好 4 页，第 5 页必须 404）
  与 `test_empty_collection` 在修复前后均绿，防止「ceil+1」式过度修复。

### 2.6 最小修复（1 行）

```diff
-    total_pages = total // per_page  # PLANTED DEFECT: floor, not ceil
+    total_pages = (total + per_page - 1) // per_page  # FIX: ceil division
```

整数 ceil，无浮点。未动边界检查、切片、服务层。

## 5. 注意点与局限

- 缺陷只在**非整除**时显形：整除场景（12/3）行为完全正常，常规冒烟测试抓不到；
  回归测试必须显式覆盖「非整除 + 单条 + 空集 + 整除」四象限。
- off-by-one 同族：floor/ceil 混用、0/1-based 页码混用、闭/开区间端点。
  本例的通用教训：**页数是「覆盖全部数据所需页数」，必须 ceil**。
- 局限：玩具服务无并发/持久化，缺陷面刻意收窄到单一 off-by-one，
  以保证因果链可被单元探针逐条排除。
