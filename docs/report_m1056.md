## 5 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 踩过的坑

1. **`proposal_src` 字段语义**：存的是**任务 id 而非提案 id**（任务书原文即如此要求），一度按提案 id 解析导致溯源审计全面误判 0/18；修正为"任务级合规 + 提案级重建"双轨后才可核
2. **字符相似度阈值**：节点标题被改写为通用物理描述后，与原提案标题的字符二元组相似度骤降到 0.06–0.27 区间；阈值设 0.10 是**证据与误判的折中**，不能当作"归因正确"的强证据
3. **plan 状态时变**：播种后 plan 状态会由战役控制器从 `draft` 推进为 `active`；报告若照抄播种时点状态，审计时即出现"自述过期"（F3）
4. **中文 JSON 截断**：审计中 `cut -c` 截断中文 JSON 会破坏多字节编码；取数须整列 JSON 落文件再解析

### 5.2 局限

- 提案级溯源重建依赖字符相似度，对同源同域提案（如同一提案者的 6 条都在冰区）区分力有限；阈值附近的判定只能算旁证
- 审计对象为 DB + 提案池工件，未审计三位提案者内部推理质量（其 `why_frontier` 的新颖性主张未独立核实）
- 未归因的 7 条提案在战役层被**丢弃**，原始提案未记录丢弃理由，属流程缺口（本报告只能如实标注其存在）

### 5.3 适用范围

- 本返工仅针对报告 832 的结构性缺陷（D1/D2/D3），**未改业务代码**
- 审计脚本可复用于后续 Wave 播种任务的报告质检
- 误差判定节的"布尔/计数项无基准"声明模式可推广至其他规划类报告

## 6 误差判定（显式回答「是否 <3%」）

### 6.1 关键量的性质声明

本报告为**战役规划（seed）文档**：关键量全部是**布尔校验项与整数计数**（机器门 10 项、溯源归因数、记账平衡），**不存在连续数值量**（无阻力、无功率、无运动响应、无应力），因此**没有可与实验/文献/解析解逐项比对的数值基准**。

精度纪律中「相对误差 >15% 不可接受」「关键量 vs 基准误差 <3%」两条判据，其定义域为物理连续量；对布尔/计数项，相对误差**不成立（分母无物理意义）**。

### 6.2 逐项误差判定

| 关键量 | 判据 | 实测 | 量纲 | 数值基准 |
|---|---|---|---|---|
| 节点数 | 5 ≤ n ≤ 12 | 10 | 整数计数，判据为区间包含 | 无连续基准 |
| ext_id 唯一性 | 重复=0 | 0 | 布尔 | 无连续基准 |
| 仓库白名单 | 越界=0 | 0 | 布尔 | 无连续基准 |
| DAG 无环 | 拓扑残留=0 | 0 | 布尔（Kahn） | 无连续基准 |
| 依赖闭包 | 越界=0 | 0 | 布尔 | 无连续基准 |
| 里程碑覆盖 | min≥1 | 3 | 整数计数 | 无连续基准 |
| 成熟化单 | ≥2 | 3 | 整数计数 | 无连续基准 |
| goal 长度 | ≥80 字 | 0 不达标 | 布尔 | 无连续基准 |
| 验收判据非空 | 空=0 | 0 空 | 布尔 | 无连续基准 |
| 必填字段 | 缺=0 | 0 缺 | 布尔 | 无连续基准 |
| 提案级溯源 | ≥阈值 0.10 才证实 | 11/18 证实 | 相似度阈值判定（非物理量） | 阈值 0.10 为方法设定，非实测基准 |
| 报告自述 vs 实测（归因） | 逐条一致 | 11/13 条归因一致 | 一致性计数 | 无连续基准 |
| 报告自述 vs 实测（计数） | 逐项一致 | 3 项不一致 / 5 项受检 | 一致性计数 | 无连续基准 |

### 6.3 结论（显式回答）

- **是否 <3%？** —— **不适用（N/A）**：本报告关键量均为布尔/计数项，无数值基准，相对误差不成立；本报告不作"<3% 达标"的虚假主张。
- **等价替代判据**：报告自述 vs 独立复算的**不一致项 = 3 / 5 项受检**（merged_groups：自述 `2` vs 实测 `3`；plan_status：自述 `draft` vs 实测 `active`；complementary_kept：自述 `16` vs 实测 `14`），均在 §5.4 以 F2/F3 如实披露；其余 10/10 项机器门、11/13 条归因、3/3 里程碑归属、4 项种子元数据**完全一致（偏差 0）**。
- **数值基准将于何处出现**：Wave 6 的物理节点（如 W6-N08 冰区阻力精度闸门"≥3 条入仓基线盲算 ≤10% 实测"、W6-N05 吊舱推进"直航推力误差<3%"）自带参考值与误差门槛，届时按 15%/3% 纪律逐项判定；本规划报告不对其作任何精度承诺。
