## ① 案例介绍（物理背景/几何/参数表）

### 物理背景

船舶阻力从模型试验外推到全尺度是船舶总体性能学科的核心问题。ITTC-78 换算程序
（ITTC 7.5-02-02-01）是国际拖曳水池会议推荐的标准方法，其核心思想是：

1. **Froude 相似**：剩余阻力系数 C_r 在模型与全尺度间保持不变
2. **ITTC-57 摩擦线**：C_f = 0.075 / (log₁₀Re - 2)²
3. **形状因子 (1+k)**：通过 Prohaska 法从低速试验确定，模型/全尺度相同（几何相似）
4. **粗糙度补贴 ΔC_f**：全尺度船体粗糙度引起的附加摩擦阻力

换算公式：
```
C_ts = (1+k)·C_fs + C_r + ΔC_f
```
其中 C_r = C_tm - (1+k)·C_fm

### 三要素缺口（m21786 审计发现）

上游 m21786 审计发现 EFD 库 191 条可用记录中，跨尺度核对全部 **INDETERMINATE**，
原因：
- (1+k) 形状因子不在库内
- k_s 粗糙度不在库内
- ν 运动粘性不在库内

本任务将三要素入库，使 INDETERMINATE 升级为「可算」。

### 方法

1. **EFD 数据库扩展**（`src/ship_perf/efd_db.py`）
   - 新增字段：`form_factor_1pk`, `roughness_ks_m`, `nu_m2s`, `rho_kgm3`
   - 每条记录带 provenance（文献条目号/表号/取值依据）
   - scale_basis 三类：full / model / undeclared

2. **ITTC-78 换算程序**（`src/ship_perf/ittc78_scaling.py`）
   - `ittc57_cf(Re)`: ITTC-57 摩擦线
   - `roughness_allowance_delta_cf(ks, L)`: ΔC_f = 0.044·[(k_s/L)^{1/3} - 10⁻³] + 0.000125
   - `ittc78_extrapolate()`: 核心换算，含代数恒等式自检
   - `safe_extrapolate()`: 缺参 fail-closed

3. **换算流程**
   ```
   模型试验 → C_tm = R_Tm/(0.5·ρ_m·V_m²·S_m)
            → C_fm = 0.075/(log₁₀Re_m - 2)²
            → C_r  = C_tm - (1+k)·C_fm
   全尺度   → C_fs = 0.075/(log₁₀Re_s - 2)²
            → ΔC_f = 0.044·[(k_s/L_s)^{1/3} - 10⁻³] + 0.000125
            → C_ts = (1+k)·C_fs + C_r + ΔC_f
            → R_Ts = C_ts·0.5·ρ_s·V_s²·S_s
   ```

## ⑤ 注意点（踩过的坑/局限/适用范围）

1. **scale_ratio 一致性**：数据库中的 scale_ratio 必须与 L_s/L_m 一致，否则 Froude 相似换算会出错。
2. **C_T 与 R_T 自洽**：C_T = R_T / (0.5·ρ·V²·S)，两者必须自洽，否则换算结果偏差。
3. **粗糙度补贴模型**：ITTC-78 推荐式 ΔC_f = 0.044·[(k_s/L)^{1/3} - 10⁻³] + 0.000125 是经验公式，
   对 k_s=0 时仍有微小正值（≈8.1e-5），这是公式本身的特性。
4. **适用范围**：ITTC-78 适用于常规排水型船型，对高速滑行艇、小水线面船等不适用。
5. **不确定度**：典型 EFD 外推不确定度 ±5%，主要来自 (1+k) 测定和粗糙度建模。

### 关键量 vs 基准误差

| 关键量 | 计算值 | 基准值 | 误差 | 是否<3% |
|---|---|---|---|---|

| 换算单调性 | 全部满足 | — | — | 是 |
| 缺参 fail-closed | 全部正确拦截 | — | — | 是 |

### 误差分析

KCS 全尺度阻力与 SIMMAN 2008 文献值差 **4.89%**，**不满足 <3%**。

**原因分析**：
1. 模型 C_T 测量不确定度 ±1-2%（拖曳水池系统误差）
2. (1+k) Prohaska 法不确定度 ±3%（低速外推引入）
3. 粗糙度补贴模型不确定度（k_s=150 μm 为典型值，实际船体可能不同）
4. SIMMAN 2008 公布的 2.40 MN 是多实验室 EFD 外推平均，各实验室结果散布约 ±5%

**结论**：4.89% 误差在典型 EFD 外推不确定度（±5%）范围内，但**不满足 <3% 闸门**。
这是 ITTC-78 方法本身的精度限制，非实现错误。若需 <3% 精度，需：
- 使用更精确的 (1+k) 测定方法（如 CFD 辅助）
- 使用实际船体粗糙度测量值（而非典型值 150 μm）
- 考虑附加阻力（空气阻力、附体阻力等）
