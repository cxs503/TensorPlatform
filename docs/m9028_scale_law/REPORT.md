# 尺度效应/外推相似律成熟化：ITTC-1957 / ITTC-1978 + 低 Re 过渡区（m9028 / p234w2-n02）

**结论先行**：仓库此前**没有任何**模型-实船外推机制（无形状因子、无 ΔC_F、无相关津贴、无螺旋桨尺度修正），且 ITTC-1957 摩擦线在 `backend/` 下有 **10 份重复私有实现**。本节点新建单一可信内核 `backend/api/domain/scale_effect.py`（22 条 pytest 用例全绿），并给出「三尺度外推到同一实船」的机器可裁验证面：**推荐通路的实船阻力误差 0.552 %（100 m Wigley）/ 1.454 %（10 m 无人艇），三尺度互差 0.569 % / 0.847 %**；而平台现用的「两侧都用 ITTC-57」通路在最苛刻工况下偏差 123.0 %（外推出的实船阻力甚至为负）。

## ① 案例介绍

**物理背景**。水池模型试验只能用缩尺模型（Froude 相似）测总阻力，实船阻力必须靠相似律外推。标准做法有两支：ITTC-1978 三因次法（形状因子 1+k、余阻力 Froude 相似、相关津贴 C_A）与 ΔC_F 二因次法。二者在 k=0、C_A=0 时代数等价（本报告给出机器证明）。难点在于**模型侧摩擦闭合**：模型雷诺数 Re_M 常落在层流-湍流过渡区（甚至层流区），而 ITTC-1957 是**相关线**（服务于实船相关津贴），把它当模型侧物理摩擦律在 Re_M<10^6 时会有数十个百分点偏差——这正是无人艇/小尺度船模（Re<10^6）的核心风险面。

**几何**（Wigley 抛物型，解析可验）：

## ② 怎么做的

1. **新建内核** `backend/api/domain/scale_effect.py`（纯函数、无 I/O、无拟合到平台的常数）：水物性（Kell 密度多项式 + Vogel 粘温方程 + 盐度线性项，锚定 ITTC 15 °C/35 ppt 的 ν=1.1883e-6）；摩擦线族（ITTC-1957 / Schoenherr 隐式解（二分）/ Prandtl-Schlichting / Blasius / Schlichting 过渡修正 / 过渡感知复合线）；相似律（Froude 速度、`Re_S/Re_M = Λ^1.5·ν_M/ν_S`）；外推（ITTC-1978 三因次 + ΔC_F 二因次，模型侧与实船侧摩擦线可独立选择）；螺旋桨尺度效应（ITTC-1978 剖面阻力 C_D 与 ΔK_T）。

2. **参考真值（非自证）**：实船总阻力用**三套独立闭合**搭建——Schoenherr/ATTC-1947 隐式摩擦线（与平台外推所用的 ITTC-57 无关）+ Michell 薄船兴波阻力（`docs/verification_debt/wigley_michell`，θ 积分与二维数值两路，Richardson 收敛）+ ITTC-1978 相关津贴 C_A。实船侧摩擦线差异即误差的非循环成分：classical_wigley_L100 的 Schoenherr vs ITTC-57 差 -0.06…+0.04 %；usv_wigley_L10 的 Schoenherr vs ITTC-57 差 -1.69…-1.07 %。

3. **合成水池试验**：模型总阻力由「几何相似模型的 Michell 兴波（Froude 相似使其严格可缩放）+ 形状因子 × 过渡感知摩擦（`low_re_friction_cf`）」生成，叠加 ±0.3 % 确定性扰动模拟测量不确定度。同一套数据分别喂给四条通路：(i) 平台基线 ITTC-57 两侧同用；(ii) Re_M<10^6 切换物理线；(iii) **推荐**：模型侧恒用物理线（过渡感知/P-S）、实船侧 ITTC-57；(iv) 任务书字面 +ΔC_F 式（反例）；外加「湍流激发（tripped）」数据做敏感性。

4. **参考值↔外推的双向核对**：兴波项在 Froude 相似下 R_wS/R_wM 应严格等于 (ρ_S/ρ_M)(V_S/V_M)²(S_S/S_M)，逐点核对（表 ③ 的 `rwratio`），θ 求积的 Richardson 残差 ≤ 7.1e-14。

5. **工具链**：纯 Python + numpy + matplotlib；驱动脚本 `docs/m9028_scale_law/run_validation.py`，结果 `results.json`（唯一数字源），报告由 `post_report_m9028.py` 程序化注入。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **ITTC-1957 是相关线，不是摩擦律。** 它在 Re=10^5 比物理平板值高 98 %，在 Re=10^6 高 6 %，与 Schoenherr 的差随 Re 增大才收敛（1e9 处 0.02 %）。把它当作模型侧物理闭合，是小尺度模型的头号误差源；平台 10 份重复实现全都只提供相关线，因此本节点把它降级为「实船侧约定」。
2. **任务书给的 ΔC_F 公式符号写错。** 船更大→C_F 更小→外推阻力应小于 R_M·λ³ 缩放，取正号会产生 +70.3 % 系统性高估（表 ③.3 最右列）；按自主权「方法自主」以物理正确符号实现，并把字面式固化为 pytest 反例，偏差与理由已在模块 docstring 声明。
3. **过渡带 C_F 不单调。** 平板平均摩擦系数在过渡区**上升**（层流→湍流），Re∈[3e5,1e6] 内先降后升；任何「Cf 随 Re 单调下降」的断言都会在 Re≈5e5 处失效。pytest 已改为三区间行为断言。
4. **C_A 对小船越界。** ITTC-1978 的 C_A=0.006(L+100)^-0.16-0.00205 拟合于 L≥50 m 海船；L=10 m 时给 7.783e-04（并非小量，且是外推公式而非拟合值），本报告基线取 C_A=0 并做 0→1e-3 扫描，未将其当作已验证值。
5. **螺旋桨剖面阻力公式有硬边界。** C_D 在 Re_co<1.29e4 变负（公式符号翻转），推荐带是 2e5…1e7；10 m 无人艇的缩尺桨 Re_co,M 只有 2e4/5e3/2e3 → 一律 OUT_OF_RANGE。结论：**小艇的螺旋桨尺度效应无法靠缩尺试验确立**，须实船试航或高 Re 设施/CFD；平台不应盲用 ITTC 修正。
6. **ΔK_Q 无公认式**，本节点只给两个声明边界（相对同步 / 仅推力），两者 Δη₀≤0；经典的「实船效率略高」需要 ΔK_Q 降得更快，标 WITHHELD 而非编造。
7. **参考值仍是解析类，不是 RANS/EFD。** 兴波用 Michell 薄船理论（无粘、薄体假设），粘性用经验线，故本报告不宣称「对标 CFD/试验」；外部锚定标 WITHHELD，并给出闭合敏感性带（③.3 里 Schoenherr↔ITTC-57 的差）。
8. **合成数据是构造式的。** 推荐通路的残差≈注入扰动（构造性一致），真正有信息量的是「基线 vs 推荐」的差（5.45 %→0.55 %；123 %→1.45 %）与「模型线选择 vs 湍流状态」的耦合——不是推荐通路「又绿了一次」。
