## ① 案例介绍

六维评价（correctness/accuracy/stability/efficiency/reproducibility/applicability）把「优于对照」从叙事升级为带 FWER 控制的判决，其**设计期**量纲（解析 MDE、所需样本对 n、置信区间半宽、Holm 调整 p、A/A 族级误报率）全部经由一条 t 分位数实现汇聚。量纲错一分，判决书上的数字就假一分——本探针就是这条链的红/绿体检器。

被审对象两处（详见 P143W2-N06 §1）：

- **D1** `_t_ppf`：旧实现为一阶 Cornish-Fisher 展开 `z+(z^3+z)/(4df)`，却在 docstring 自述「df≥5 误差 <0.5%」；现实现为不完全贝塔（Lentz 连分式）+ Newton/二分混合求根。
- **D2** `_bonferroni_holm`：旧实现在首个不显著之后把后续调整 p 一律写成 `1.0`，与同模块 `holm_adjust` 的教科书定义矛盾。

## ② 怎么做的

1. **独立基准**：`_ref_t_ppf` 只在 df∈{1,2} 用解析闭式（Cauchy 与 df=2 的精确分位数），其余用**自适应 Simpson 积分 t 密度 + Newton 求根**，全程不复用被审模块的 `_betai`——因此不是自证。环境有 scipy 时并列一列 `scipy.stats.t.ppf` 互校。
   - 基准自身可信度：参考值与 scipy 的最大相对差 = `4.744e-11`（scipy 可用=True）。
2. **基线复刻**：旧版两处公式按源码口径逐字复刻为 `legacy_t_ppf_cf` / `legacy_holm`，与现模块**跑同一条探针命令**，红/绿同源可比（避免拿不同口径的数字对比）。
3. **网格**：t 分位数 df∈[1,30]∪{40,50,75,100,250,500,1000,2500,5000} × p∈{0.90,0.95,0.975,0.995}，共 156 个点；Holm 随机矩阵 2000 组（族大小 ∈{2,3,6}，两种 p 抽样口径）；CI 覆盖率 蒙特卡洛 4000 次/档。
4. **锁定**：`tests/abm/test_m8719_accuracy_evidence.py` 重跑同一探针并断言判据，同时校验本文件里的数字与 `docs/m8719_evidence_summary.json` 逐字一致（文档数字漂移即红）。

## ⑤ 注意点 / 局限

- **Holm 不一致率的绝对值依赖抽样口径**：原文档记 50.05%（其随机源未入库，不可逐位复现）；本轮两种口径测得 67.40%（p~U(0,1)）与 73.55%（混入 1e-3…1 量级因子）。方向与量级一致（数十个百分点），但**不该**把本轮数字当作原数字的复现。
- **CI 覆盖率是蒙特卡洛量**：4000 次/档的标准误约 0.1pp，故 n=15 处与原文档（94.975%→95.050%）差 0.2pp 属 MC 噪声，不构成新缺陷。
- **判决语义未变**：D2 只改 `adjusted_p` 的报告值，`significant`/`six_dim_advantage` 的拒绝集合逐维不变（`test_decisions_unchanged_vs_sequential_rule` 固定该不变式）；D1 只影响 n<20 的设计期量。
- 探针全量跑（含 2×2000 组 Holm 扫描 + 8000 次覆盖率 MC）约 16 s，测试内用缩小档位跑约 3 s。
- 未动：`binom_ci` 无 scipy 时的 Wilson 退化口径、`mde_curve` 的二分搜索分辨率——仍无证据越界，不做无证据改动。
