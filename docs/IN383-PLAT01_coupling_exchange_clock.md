# IN383-PLAT01 —— 多求解器耦合的保守场交换与时钟语义机制（平台共性设施）

> 结论：平台首次具备**可裁的交换与时钟基础设施**——三种守恒重映射算子共用同一接口、四条守恒性质门、四类显式时钟语义（出域 fail-closed）、合成两场孪生一致性门，全部判据 C1–C9 机器通过。零领域语义（域词表扫描 0 命中）。

## ① 案例介绍

**问题背景。** 平台上的多求解器耦合此前各自实现边界量传递：谁插值、谁缩放、在哪个时刻交换，都散落在调用方的代码里。ECOSYSTEM-MAP/PANORAMA 记录的跨库契约缺口正是这一层：交换不守恒无从证明、时钟不显式（子循环步数靠约定）、出域（请求落在样本窗口外）往往被静默地取最近值。本节点把这层做成平台共性机制，供任何领域仓按适配器接入。

**验证算例（合成域，零领域语义）。** 单位方形域上的两组网格：粗网格 `n_coarse=6`（每维 6 格）、细网格 `refinement=2`（每维 12 格，严格嵌套）；场量为高斯团块密度（合成，非物理）；另有 half-cell 偏移的非嵌套网格作为“网格不匹配”对照。耦合环：细网格侧每个主步走 `k=2` 个子步（零通量扩散算子，步长 `dt_sub=dt_master/2`），每子步发布一个时间样本，主步刻度交换一次，粗网格侧走 1 个主步后回传。

**参数表（全部来自 acceptance.json 的 spec）：**

| 参数 | 值 | 说明 |
|---|---|---|
| `n_coarse` / `refinement` | 6 / 2 | 粗网格 6×6，细网格 12×12（嵌套） |
| `dt_master` / `dt_sub` / `k` | 0.02 / 0.01 / 2 | 子循环契约 dt_master = k·dt_sub |
| `cycles` | 40 | 主步数（耦合交换 40 次） |
| 扩散系数 D | 1e-3 | 零通量守恒扩散（环内的“物理”步） |
| 算子 | overlap-L2 / RBF+守恒缩放 / 最近邻+缩放 | 后两者各带“关闭守恒修正”负控 |
| 时钟模式 | SYNC / LINEAR_INTERPOLATION / ONE_STEP_EXTRAPOLATION / EVENT_TRIGGERED | 四类显式语义 |

## ② 怎么做的

**模块（`tools/coupling/`，纯平台代码）。**

| 模块 | 职责 |
|---|---|
| `mesh.py` | `BoxMesh`（轴对齐盒元胞、含体积）、`Field`（值 + 网格 + `QuantityKind`：`density` 体积密度 / `extensive` 单元总量） |
| `remap.py` | 统一接口 `remap(src_field, src_mesh, dst_mesh, quantity_kind)`；overlap-L2 体积重叠投影、RBF 插值 + 全局守恒缩放、最近邻 + 缩放；边界约束质量修正 `bounded_mass_fix` |
| `conservation.py` | 守恒门：ΣF 残差、一阶矩残差、非负性、极值不增（各自独立阈值） |
| `clock.py` | `ClockContract`（dt_master = k·dt_sub 整数比校验）+ `TimeSeriesExchange`（四种模式，越界即抛 `ClockContractViolation`） |
| `twin.py` | 合成两场耦合环 + 端到端残差/表示一致性/往返误差 |
| `provenance.py` | 规范化 SHA-256 摘要（浮点走 `float.hex`）+ 哈希链交换台账 |
| `acceptance.py` / `figures.py` / `report.py` | 判据驱动、出图、出报告（数字程序化注入） |

**守恒的机制。** overlap-L2 投影把源元胞常数场按体积权重投到目标元胞（分区单位分解 ⇒ 目标域被完整覆盖时精确守恒）；RBF 与最近邻本身不守恒，由“全局守恒缩放 + 可选有界质量修正”补齐——有界质量修正在 `[lo, hi]` 内按可用余量分配质量误差，因此**非负性/极值不增与总量精确可同时成立**。

**时钟的机制。** 契约在构造时校验整数子循环比与步长合法性；样本必须落在子步网格上且严格单调；`SYNC` 只回答恰有样本的时刻，`LINEAR_INTERPOLATION` 只在样本窗口内插值（不外推），`ONE_STEP_EXTRAPOLATION` 只允许声明的步数并显式标记 `extrapolated=True`，`EVENT_TRIGGERED` 在事件间隔内返回并标记 `stale=True`，超出陈旧上限即抛异常。每一次存储/请求都写入哈希链台账（`seq/prev_digest/digest`）。

**判据先于实验。** 阈值在实现前写死：C1 ≤1e-12、C3 ≤1e-12、C4 ≤1e-10、C5 关闭修正后漂移 ≥1 %、C9 测试数 ≥20；一阶矩守恒作为**诊断量**而非判据，因为只有仿射一致的映射（嵌套 overlap/最近邻）才可能精确保矩——这一条在实现后由数据确认（见 ③），未回改阈值。

## ⑤ 注意点（踩过的坑与适用范围）

1. **overlap 投影的分母陷阱。** 首版用“重叠体积和”作分母再乘元胞体积，等于把体积算了两遍，总量偏差达 2×；守恒门在第一次运行就把它抓出来（残差 75 %），改回 `Σ|A∩B|ρ / |B|` 即归零。
2. **体积盲的扩散步会在非均匀网格上漏质量。** 孪生环首轮在 half-cell 偏移网格上每主步丢 2.3e-4 质量，根因是离散拉普拉斯和为零但乘以不同元胞体积后不再为零；改为按元胞体积归一（`·V̄/V_i`）后降到 1e-16。这条是**门自己发现的**，正说明端到端门不能省。
3. **一阶矩不能当普适判据。** 插值与 half-cell 装入会把质心平移 O(h)（实测最坏 2.297e-03），这是离散化性质而非守恒缺陷；因此一阶矩只作为诊断（以“元胞宽度数”表示，上限半个元胞），嵌套仿射映射实测 2.303e-16 精确。
4. **patch test 要看表示形式。** 元胞常数表示下，线性场的逐点复现**不可能**精确（跨元胞边界的目标元胞是相邻元胞值的加权平均）；正确的判据是常数复现、嵌套复现、线性场**单元积分**精确与往返恒等，四者实测均 ≤2e-16。首版按“逐点复现线性场”写测试，得到 4.7e-2 的错误结论。
5. **RBF 无约束会过冲/欠冲。** 阶跃场实测 min=-0.128、max=1.127，启用 `positivity+enforce_bounds` 后有界质量修正把 min 抬到 6.45e-03、max 压到 1.0000 且总量仍精确——但这是**主动投影**，会令插值精度下降；报告中两者都给出，不合并成单一说法。
6. **适用范围。** 仅轴对齐盒网格（1/2/3 维）；不处理曲面/非结构网格与移动网格；RBF 求解为稠密 O(N³)，只适合中规模界面交换；无并行/GPU 路径；未做墙钟性能基准。时钟机制与既有 `backend/services/coupling_clock_sync.py` 尚未合并（后者带域语义，按“零领域语义”纪律留在后端，接入由领域仓适配器完成）。
7. **判据可被伪造的风险已处理。** 负控（关闭守恒修正）在单次重映射与孪生环上都给出 ≥1 % 漂移，因此 C1/C4 不是自证；若某天负控不再漂移，说明算子被改成了隐式缩放，门会失去意义。

## ⑥ 误差判定

| 关键量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| 总量守恒残差（C1） | 解析守恒（Σsrc=Σdst） | 2.315e-16 | 是（≈机器精度） |
| patch test（C3） | 常数/嵌套/积分/往返解析恒等 | 1.868e-16 | 是 |
| 孪生端到端（C4） | 初始总质量 | 1.104e-14 | 是（≈机器精度） |
| 重映射场误差（n=24，overlap） | 解析高斯场 L1 | 0.827 % of 幅值 | 是 |
| 重映射场误差（n=24，RBF） | 解析高斯场 L1 | 0.011 % of 幅值 | 是 |
| 守恒修正关闭后的漂移（C5 负控） | 精确守恒 | 6.003 % | **否（有意为之）**：这是被设计的坏基线，用以证明修正步骤必要 |

**判定：** 本节点的“基准”不是实验值而是解析恒等式（守恒、patch test、往返），因此误差判据是机器精度级别的 ≤1e-12/≤1e-10，全部关键量在阈值内 4 个数量级以上；唯一超过 3 % 的量是 C5 负控（6.0 %），它是**故意保留的不守恒基线**，用来证明门不是自证——不作为精度缺陷处理。

**局限（诚实声明）。** (a) 未接入任何领域求解器，跨库契约缺口只完成“机制 + 门 + 记录”这一段，适配器接入仍是后续节点工作；(b) 孪生环里的“物理”是合成扩散，不代表任何真实耦合稳定性；(c) 时钟四模式只做了单元级与合成环级验证，未做长时程（>10⁴ 步）累积误差研究；(d) 未与既有 clock-sync 实现做性能/正确性对照。
