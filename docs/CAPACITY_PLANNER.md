### 4.1 模型失效域（(c, ρ) 网格）

网格 64 点，偏差 ≤10% 的格子 40（占 0.625）；适用带内最大 |偏差|=0.098453；最坏点 c=16, ρ=0.3 → 65.762603。

失效域要点：
- ρ→1 时 Erlang-C 与近似式同时失真且对 S 的高阶矩敏感；容量规划建议承诺 ρ≤0.9
- c≥12 且 ρ≤0.6 时 Allen–Cunneen 通常高估 Wq（保守方向），不用于承诺 SLA 上限
- c=1 时两者退化为同一式（M/G/1 的 P-K 形式），偏差为 0

### 5.1 到达过程口径（非齐次 Poisson）——模型失效域检验

## 8. 注意点与局限

- service_start 由 session 内 claim/plan 事件按时间序配对重建（claim payload 不带 mission_id），这是数据面唯一假设；若某 session 的 claim 与 plan 数不齐，配对会错位（表现为负等待，已计数丢弃）
- seat 数 c 是训练期标定出的"有效并行容量"，与观测并发会话数并不等同：平台无准入控制时并发会话数可远超有效容量，排队模型只刻画等效服务能力
- Erlang-C 假定指数服务；实测服务时间重尾（见 service_stats.scv），故以 Kingman/Allen–Cunneen 带 SCV 校正的版本作为规划口径，Erlang-C 仅作互裁参照
- P(Wq>t) 与 p90 等待由 Erlang-C 尾概率形式近似外推，属近似量，报告同时给出 DES 复核
- (c,ρ) 网格上最大偏差出现在 c=16, ρ=0.3：+6576.3%（超出 ±10% 的格子即模型失效域）
