## 1. 案例介绍

### 1.1 物理背景

耐波性（Seakeeping）研究船舶在波浪中的六自由度运动响应。平台 `services/seakeeping.py` 实现了**线性单自由度（SDOF）频域响应模型**：

$$
(M + A) \ddot{\eta} + B \dot{\eta} + C \eta = F(t)
$$

其中：
- **恢复力** C：水静力学精确值（C33=ρgA_w, C55=ρg∇GM_L, C44=mgGM_T）
- **附加质量** A：参数化输入（κ₃₃=0.80, κ₅₅=0.25, κ₄₄=0.35）
- **阻尼** B：参数化阻尼比（ζ₃₃=0.20, ζ₅₅=0.12, ζ₄₄=0.10）
- **激励力**：Froude-Krylov + Smith 修正 e^{-kT} + 纵向相位因子 Γ(u)

## 2. 怎么做的

### 2.1 工具链

- **语言**：Python 3.11 + NumPy
- **被测模块**：`backend/services/seakeeping.py`（SeakeepingModel 数据类）

- **验证脚本**：`tools/verify/seakeeping_analytic_check.py`

### 2.2 验证流程

1. **几何门检**：验证 Cb/L/B/T 闭合（∇/(Cb·L·B·T) - 1 < 5%）
2. **水静力学计算**：从几何参数推导 A_w, I_L, BM_L, GM_L, C33, C55, C44
3. **模态参数**：计算固有频率 ω₃, ω₅, ω₄ 及对应自然周期
4. **解析极限检验**：
   - 长波极限：ω→0 时 RAO→1（对任意 κ/ζ 成立）
   - 高频衰减：ω→∞ 时 RAO ~ C/((M+A)ω²)（log-log 斜率 -2）
   - 共振峰：|H|_peak = 1/(2ζ√(1-ζ²)) at r=√(1-2ζ²)
5. **对称性检验**：横摇 RAO 在顶浪(180°)/顺浪(0°)时 → 0
6. **遭遇频率检验**：与解析公式 ωe = ω - kU cosβ 精确对比

### 2.3 关键设置

- 深水色散关系：k = ω²/g（精确）
- 纵向相位因子：Γ(u) = 3(sin u - u cos u)/u³（抛物线水线面精确解）
- Smith 修正：e^{-kT}（等吃水近似）
- 阻尼模型：线性粘性，ζ 为输入参数

## 5. 注意点

### 5.1 局限与适用范围

1. **线性理论**：仅适用于小振幅波（波陡 ka < 0.1），不适用于砰击、甲板上浪等非线性事件。
2. **深水假设**：色散关系 k=ω²/g 仅适用于深水 (d/L > 0.5)，浅水效应未计。
3. **前航速影响**：Fn < 0.3 时前航速对水动力系数的影响未计（多普勒修正仅在遭遇频率中体现）。
4. **横摇阻尼**：采用固定阻尼比 ζ=0.10，实际横摇阻尼强烈依赖于舭龙骨、船型、振幅（非线性）。
5. **参数化附加质量**：κ 值为经验输入（非回归拟合），绝对精度依赖参数选取。
