## 1. 案例介绍（物理背景与目标）

### 1.1 问题陈述

在 TensorPlatform 平台中，复算漂移（reproduction drift）是影响科研可信度的核心问题。
本节点的目标是将 `repro_rate`（可复现率）从基线 **0.667** 提升至 **≥0.95**，
同时建立完整的根因分析→修复→复测→敏感性分析→集成验证→知识图谱→BP 对齐的成熟化闭环。

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 踩过的坑

1. **知识图谱构建器输入突变**: 初始版本 `_build_nodes` 直接修改输入列表，导致负控测试失败。修复为创建副本后再填充。
2. **分母口径定义**: 不同分母定义对 repro_rate 的影响需要仔细区分——blocked 节点是否计入分母是关键分歧点。
3. **根因分类置信度**: 基于模式匹配的置信度计算需要平衡灵敏度和特异度，当前使用 0.3 基础分 + 证据加成。

### 5.2 局限

1. **合成数据**: 当前测试使用合成夹具，真实环境下的 repro_rate 可能因实际依赖冲突而更低。
2. **修复模拟**: `_simulate_rerun` 是启发式模拟，真实修复需要实际重新运行测试。
3. **BP 对齐**: 当前 BP 条款匹配基于预定义规则，实际对齐需要人工审核。

### 5.3 适用范围

- 本平台复算漂移清偿闭环机制
- 适用于任何有 pytest 测试和 JSON 工件的仓库
- 不依赖特定领域语义（符合平台铁律）
