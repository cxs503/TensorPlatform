## 1. 案例介绍（物理背景与目标）

### 1.1 物理问题

冰区航行船舶在碎冰场中运动时，船-冰-水三者强耦合：
- **LBM（格子玻尔兹曼）**：捕获自由面与流体细节（水相流场、压力分布）
- **FEM（有限元）**：求解冰板弯曲/断裂（连续介质力学）
- **DEM（离散元）**：模拟碎冰颗粒运动与接触（离散颗粒系统）
- **刚体运动**：船舶六自由度运动（受冰-水合力驱动）

七腿闭环 = LBM → FEM → DEM → 刚体运动 → 回 LBM，形成完整流-固-颗粒-刚体耦合链。

### 1.2 目标

- **G4 七腿 SIR 闭环**：验证 LBM→FEM→DEM→刚体→LBM 全链贯通
- **能量守恒判据**：`full_chain_energy_conservation < 0.05`（相对误差）
- **集成层验证**：L3_integration 层，风险 high

### 1.3 验收标准（原单声明）

| 判据 | 阈值 | 说明 |
|---|---|---|
| `full_chain_energy_conservation` | < 0.05 | 全链能量守恒相对误差 |
| 七腿闭环贯通 | 全链可执行 | LBM→FEM→DEM→刚体→LBM 无断链 |
