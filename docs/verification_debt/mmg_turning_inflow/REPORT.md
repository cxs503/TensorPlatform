## ① 案例介绍

操纵性域的全部平台判决都压在 `mmg_reference.py` 这一颗「参考核」上
（`docs/verifier/MANEUVERING_REVIEW.md` 记录：平台 6 个操纵端点无一个 REAL，
判据只能对这个核）。

证据链在 m1816 之后停在这里：**积分器与舵导数的转写已被精确线性解钉到 $10^{-4}$**
（A 级），但 35° 全回转的横向指标对口径敏感 **1.7 倍**（ITTC 口径 2.973 L 在文献带内、
稳态圆口径 5.001 L 高出带上沿 39%），于是 `MANEUVERING_REVIEW` 维持 WITHHELD，
理由被改写为「指标定义敏感 + 航向不稳定」，而**「比文献高 64%」这一具体数字被记为未复现**。

`race` 旁注（本单预警）：m1816 未触及 `race` 一项，而它是尾流里唯一不能由几何推出的
经验放大因子，舵法向力 $\propto u_R^2$，故该项误差被平方放大。

**算例参数（KVLCC2 油轮，Yasukawa & Yoshimura 2015 导数组，核内既有）**

| 量 | 值 | 量 | 值 |
|---|---|---|---|
| L / B / d | 320 / 58 / 20.8 m | Cb / ∇ | 0.8098 / 312 622 m³ |
| U / Fn | 7.97 m/s / **0.1423** | D_p / A_R | 9.86 m² / 112.5 m² |
| 自航点 n' | **70.2390**（$J=0.2772$，$K_T=0.2061$） | δ | 35°（阶跃） |
| 积分 | RK4，Δτ=0.01，τ≤400（$t'=tU/L$） | 定常窗起点 | τ=250 |

控制方程（MMG 标准，核内已实现）：$(m+m_x)(\dot u-vr)=X$，$(m+m_y)(\dot v+ur)=Y$，
$(I_{zz}+J_{zz})\dot r=N$；舵法向力 $F_N=A_R'\ U_R^2 f_\alpha\sin\alpha_R$，
$u_R=\varepsilon(1-w_{P0})u\cdot b$，$b$ 即本单审计的**尾流加速因子**。

## ② 怎么做的（方法/流程/关键设置）

三个动作，均为离线、可复跑、与平台端点无关：

1. **结构审计（量纲/公式层面，不需要文献）**：把 $b$ 当成待审计对象，在 $u'\in[0.30,1.00]$
   上扫描各候选转写，报告「$b$ 对航速的散布」。物理上
   $J=u'(1-w_{P0})/(n'D')\propto u'$，故 $1+8K_T/(\pi J^2)$ 在 $J\to0$ 时必须发散；
   **任何与 $J$ 无关的转写都不是该公式**。同时用恒等式
   $b_{\text{as\_shipped}}=\sqrt{1+16K_T/\pi}$ 逐点核对转写等价性（$10^{-12}$）。
2. **与积分器无关的 A 类基准**：对每个候选写 **3 元 Newton 定常平衡解**
   （$X+(m'+m_y)vr=0$，$Y-(m'+m_x)ur=0$，$N=0$，阻尼 Newton，残差目标 $10^{-13}$），
   半径取**路径半径** $R=|\mathbf V|/r$（含横漂 $v'$，不用 $u'/r$）。
3. **回转圆几何恒等式自证**（模型无关，纯几何，且**旋转不变**）：
   * I1 闭合：$|P(\psi_0+2\pi)-P(\psi_0)|/R\to0$
   * I2 直径弦：$|P(\psi_0+\pi)-P(\psi_0)|=2R$
   * I3 直角弦：$|P(\psi_0+\pi/2)-P(\psi_0)|=\sqrt2 R$
   * I4 定常起步：从 Newton 平衡态出发积分，$|y|@180°$ **必须等于 $D=2R$**
   （第一版用「$\Delta y$ 分量 = 2R」做判据是错的——弦与坐标轴夹角随 $\psi_0$ 变，见 ⑤ 坑 1）

文献对照用 `maneuvering_audit.BAND`（B 类，SIMMAN 2008 KVLCC2 提交集引用的带，
非本仓重新数字化）：Td 2.90–3.60 L、advance 2.70–3.40 L、transfer 1.20–1.90 L、
20/10 齐格扎超调 4–18° / 2–16°。**四条转写变体**：`as_shipped`（被检核原式）、
`half`（指数 1/2）、`quarter`（指数 1/4）、`none`（无尾流加速）。

|---|---|---|---|
| `as_shipped` | 1.4317 | **7.26%** | 近乎与航速无关 ⇒ 不是 $\sqrt{1+8K_T/(\pi J^2)}$ |
| `half` | 2.7981 | 129.84% | $J$ 依赖正确但量级过大 |
| `quarter` | 1.6728 | 64.90% | $J$ 依赖正确 |
| `none` | 1.0000 | 0% | 对照组 |

转写恒等式核对：$b_{\text{as\_shipped}}=\sqrt{1+16K_T/\pi}$，逐点相对偏差
$<10^{-12}$ ⇒ 原式在无量纲化时把 $1+8K_T/(\pi J^2)$ 的 $J^{-2}$ 丢掉了

| 判据 | `as_shipped` | `quarter` | 判定 |
|---|---|---|---|
| Newton 定常平衡残差 | **0.0**（5 次迭代） | **0.0**（5 次） | ✅ 机器零 |

| I2 直径弦相对误差 | **1.81e-07** | **3.62e-08** | ✅ 积分器无缺陷 |

| I4 定常起步 $\|y\|@180/D-1$ | **4.87e-03** | 7.20e-03 | ✅ |

I2 到 $10^{-7}$ 意味着：**这条轨迹就是一条几何意义上的定常圆**，所以后文所有差异
只能来自物理模型，不可能来自数值。

### 3.4 缺陷 D2：战术直径被乘了 2（口径缺陷，非物理）

从定常态起步的 I4 给出 $\|y\|@180°/D = 1.00487$ ⇒ 横向偏移**就是**圆直径 $D$；
而 `turning_indices` 的口径是 $2\|y\|@180°$，实测比值 $=1.9903\;(=2)$。
即：核报出的 `tactical_diameter` 是同一艘船稳态圆直径的 **2 倍**。

对 `as_shipped`：$D/L=5.025$，`tactical_diameter`$/L=5.92$（后者 > 前者，物理上不成立）。
m1460 的「$T_d/L=5.92$，比文献高 64%」正是这个 2 倍；用圆自洽口径重算为
$\|y\|@180°=2.961$ L，**落在 SIMMAN 带内（2.90–3.60）**。

### 3.5 缺陷 D3：齐格扎超调记在了航向的另一侧

phase 1 取 `max`（恢复侧）而非 `min`（真实超调峰），故 20/10 超调被记成
**0.08°**（m1460/m1816 引用的数字）。轨迹实测峰值为 −48.07°（执行角 −10°），
正确超调 **38.07°**；phase 2 同样是取错侧（旧 0.01° → 实测 58.37°）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **旋转不变的判据只能用弦长**：第一版用「$\Delta y@180°=2R$」判直径，得到
   79% 的假误差——平面上相距 180° 航向的两点连线是直径，但其 $y$ 分量是
   $2R\cos\psi_0$，与起点航向有关。改用弦长/弦长的旋转不变形式后误差降到 $10^{-7}$。
2. **本单改了核的两处记账**（`turning_indices` 增键、`zigzag_indices` 极值取侧），
   但**没有改任何默认物理**：`rudder_inflow` 默认 `as_shipped`，RK4 轨迹与既有
   index 逐位不变（对 δ=0/±35°、τ=200 用 `numpy.array_equal` 核过，max diff = 0）。
3. **一次参数改动不能把四项指标同时送进带内**：`quarter` 把 $D/L$ 从 5.025 拉到
   2.785（带下沿 2.90 外侧 −4%），但 advance 2.467、transfer 0.962 反而跌到带外。
   说明残差不是「一个 $J^2$」能解释的全部，核的结构误差还有别的来源
   （首要嫌疑：船体阻力项被写成常数 $R_0'$、与 $u'$ 无关，导致 $u'$ 掉到 0.41、
   舵力 $\propto u_R^2$ 随速度平方塌陷）。**本单不据此改物理。**
4. **$D/L$ 与 $\|y\|@180°$ 在核内差 70%（5.03 vs 2.96）本身是物理可疑信号**：
   实船回转测得的战术直径与稳态圆直径通常相差几个百分点，而这里差 70%，
   根因是航速在回转过程中从 $u'=1$ 掉到 0.41、偏航率随之衰减一半——
   这也是「口径敏感 1.7 倍」的真正机制（m1816 记录的敏感度由此得到解释）。
5. 局限：文献带是**引用值**（B 类，未在本仓重新数字化）；未做 SIMMAN 轨迹级
   对齐（需要数字化参考轨迹，超出本单范围）；未覆盖尺度效应、舵角速率限幅、
   伴流场的纵荡耦合。故本单只清偿「核自身缺陷」，不宣布核已可用于验收。
