## 1. 案例介绍（物理背景与参数）

### 1.1 学科背景

船舶振动噪声域的设计控制问题，本质上是一个**激励–响应–限值**三段式：

1. **激励**：螺旋桨叶频 `f_b = n·Z/60`（n 转速 rpm，Z 叶数）、主机不平衡力、波浪激励；
2. **响应**：船体梁整体振动（两节点垂向/水平弯曲、一节点扭转）+ 上层建筑与舱室局部板格振动；
3. **限值**：舒适性与结构疲劳限值（ISO / 船级社规范），以及**共振裕度**判据。

其中**船体梁两节点垂向固有频率 `f2v`** 是该域的第一个、也是最基本的可校核量：它必须与叶频
（及其 ½ 阶、2 阶）保持足够裕度，否则全船振动水平不可控。因此本件把 `f2v` 作为参考基准的主量。

### 1.2 被测端点的实际实现（一句话）

`api/vibration.py` 全文 7 行，函数体为：

```python
@router.post("/predict")
async def predict_vibration(ship_id: str):
    return {"acceleration": 0.15, "noise_level": 65.0, "status": "合格"}
```

三个返回字段**全部为字面常量**，`ship_id` 仅作形参接收、未参与任何计算。这决定了本件的判决方向。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 参考实现（REAL）的物理与数学

均匀 free-free 欧拉-伯努利梁的第 1 阶弯曲模态即船体梁两节点垂向模态，频率方程
`cos λ · cosh λ = 1` 的最小非零根 `λ₁ = 4.7300408`，闭式精确解：

```
f2v = λ₁² / (2π) · sqrt( E·I / (m' · L⁴) )
```

- `E = 2.06e11 Pa`（钢）；
- `I` 由 **IACS UR S7** 最小中剖面模数反推：`W_min = C·L²·B·(Cb+0.7)·1e-6 [m³]`，
  `C = 10.75 − ((300−L)/100)^1.5`（90 ≤ L ≤ 300，L > 300 取 10.75），`I = W_min · D/2`；
- `m' = 1.25 · Δ / L`，1.25 为垂向振动附连水质量因子（惯例量级 1.2–1.3）。

激励侧：`f_b = n·Z/60`，直接按定义计算，无近似。

### 2.2 参考实现的独立数值复核（这是本件最关键的一步）

解析解**不能自证**。因此用一套与解析解无关的数值方法复核：**200 单元、2 自由度/节点、
一致质量矩阵的梁有限元**，装配 `K`、`M` 后解广义特征问题 `K φ = ω² M φ`，free-free 条件下
前两个特征值应为刚体模态（≈0），第 3 个即两节点弯曲模态。

解析值与 FEM 值相对偏差见 §3 表 1「自检相对偏差」列，量级 `1e-8`。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 踩过的坑（已修复，写入测试防复发）

1. **FEM 刚体模态分离阈值错误**：初版用 `eigval > 1e-6 · max(eigval)` 过滤，结果 `f2v` 比解析解
   大 **119 倍**。原因是梁的弯曲特征值按 `λ⁴` 增长，200 单元下 `max(eigval)` 比 `ω₁²` 高 9 个量级，
   阈值把 1 阶弹性模态一并滤掉了。改为「free-free 梁恰有 2 个刚体模态，取其后首个正特征值」，
   并加自检断言（刚体特征值须 < `1e-3·ω₁²`），偏差降到 `1e-8`。
   *教训：用相对阈值筛特征值时，先检查特征值的量级分布。*
2. **本机无中文字体**（`fc-list :lang=zh` 为空），matplotlib 中文标签渲染成方框。图内文字改用英文，
   图注仍为中文。若后续要中文出图，需先装 Noto Sans CJK。
3. **`tests/` 里已有 MOCK 端点不得当 REAL 用**：`api/ai_cases_full.py` 另有 `/vibration-control`
   端点（summary 自带 `[MOCK]` 标记），与本件的 `/vibration/predict` 是两个不同端点，勿混。

### 5.2 局限（honest）

- **`I` 的估计是量级估计**：用 `W_min`（规范*最小*要求）反推剖面惯性矩，实船设计常显著大于最小值，
  故 `f2v` 参考值系统性**偏低**，不确定性主要由 `I`（±30%）与附连水因子（1.2–1.3）主导。
  本件**不声称**该参考值已达「与实测 2 节点频率 <15%」的精度——见 §6。
- **一维梁模型**：未含剪切变形与转动惯量修正（Timoshenko），对 `L/B` 较小的船（如 ULCS）会略微
  高估频率；上层建筑、舱壁等局部模态完全未覆盖。
- **船型参数为代表值**，非实船放样数据；结论对该参数不确定性是稳健的（差 2 倍以上的量级），
  但不能反过来用于某条具体船的振动预报。
- **本件未修改被测算例平台**（源码不在白名单），只登记缺陷与立判据。

### 5.3 对外部状态的适用范围

平台可达性检查在 `probe()` 内完成；不可达时工件 `evidence_level = "WITHHELD"`，测试 `skip`。
本件所有在线数值来自 `artifacts/vibration_gate.json` 的 `probed_at` 时刻，**不得当作当前态引用**，
复跑 `python3 tools/ref_vibration_8001.py` 即刷新。

## 6. 误差判定

| # | 关键量 | 基准 | 实测/计算 | 相对误差 | 是否 <3% |
|---|---|---|---|---|---|
| E1 | `f2v` 解析闭式解 vs 200 单元梁 FEM（4 船级最大） | FEM 独立数值解 | 解析值 | **4.20e-08** | **是** |
| E2 | 参考实现可复现性（工件值 vs 工具重算） | 工件 `vibration_gate.json` | 重算 | ≤ 1e-06（断言阈值） | **是** |
| E3 | 平台 `acceleration` 跨船级可分辨性 | 参考 `f2v` 动态范围 53.3% | 平台变化 **0.0%** | **≥53.3%（上界不可估）** | **否** |
| E4 | 平台 `noise_level` 跨船级可分辨性 | 同上 | 平台变化 **0.0%** | **≥53.3%** | **否** |
| E5 | 平台输出的绝对精度 vs 任何物理基准 | 无基准 | — | **WITHHELD** | **不可判定** |

**逐项回答「是否 <3%」**：

- **是**：E1、E2 —— 参考实现本身（解析 vs 独立 FEM）已达 `1e-8`，远优于 3%。
- **否**：E3、E4 —— 平台端点对 `f2v` 真实变化 53.3% 的船型输入给出 0% 变化，误差下界即 53.3%，
  **远超 15% 的不可接受线**，故判决 `MOCK`。
- **不可判定**：E5 —— `acceleration` / `noise_level` 未声明单位（m/s²？mm/s²？）、未声明统计量
  （RMS/峰值）、未声明频带（是否 1–80 Hz 计权）、未声明测点（驾驶室/甲板/机舱）。缺这四项，
  「0.15 与 65.0 是否合格」在数学上无定义，因此精度判决为 `WITHHELD`——**不得记为 PASS，
  也不得记为 0 误差**。
- **未做**：与文献实测 2 节点频率的逐船对照。原因：本席手上没有**可溯源**的逐船实测数据集，
  引用记忆值会违反「数字零手抄」纪律。故本次只声明「数值自洽（E1/E2）」，不声明「与实测吻合」。
