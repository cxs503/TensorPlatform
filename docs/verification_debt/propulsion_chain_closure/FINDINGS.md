# 推进功率链物理闭合审计（m1864）· 实测结论

**一句话**：线上 `:8001` 的 `POST /calculations/propulsion` 在 5 型船里给出 **4/5 的
开路效率 η_o > 1**（最大 1.792）、**5/5 的推进效率 η_D > 1（最大 1.972）**，且它与
`POST /calculations/resistance` 的动力链**5/5 不闭合**（P_E/(η_D·P_D) = 0.172…1.052）。
30 条硬判据里 28 条 FAIL。这是「物理不可能值」级缺陷，不是精度不足。

## 1. 为什么要复核（验证欠账）
报告 1561 已宣布「推进端点推力闭合修复 … 5 型船闸门 verdict_fail=0」。本单不复述结论，
改用**树内已发表基准**独立复核同一端点：Oosterveld & van Oossanen (1975) 瓦赫宁根
B 系列回归（`tools/verification/propulsion/b_series_reference.py`，REAL）+ 三条恒等式
（η_o = J·K_T/(2πK_Q) < 1；η_D = η_o·η_H；P_E ≡ η_D·P_D）。

## 2. 方法（可复算）
脚本 `audit_propulsion_chain.py`：5 型船（KVLCC2 油轮 / KCS 集装箱 / 18 万 t 散货 /
120 m 客滚 / 90 m 沿海）逐型
1. 调 `/calculations/resistance` 取 R_T、P_E（同一几何门：∇ 与 Cb·L·B·T 闭合）；
2. 调 `/calculations/propulsion` 取 T、Q、P_D、η_o、η_H、η_D；
3. 反解无因次量 K_T = T/(ρn²D⁴)、K_Q = Q/(ρn²D⁵)、以及推力闭合要求反解的 (1−t)=R_T/T；
   响应**无单位标注**，故对「kN/kN·m」与「N/N·m」两种单位假设都算，取 K_T 量级更接近
   B 系列的一支为主假设（本单 5/5 均为 kN/kN·m）；
4. 与同几何（P/D, A_E/A_O, Z）B 系列全 J 扫描上界比较。

判据（D1–D6）见脚本 `judge()`；每一条都 lint 过「正控」（
`tests/test_propulsion_chain_closure_m1864.py::test_g3_positive_control...` 构造一组
物理自洽读数，要求 6/6 PASS），因此闸门不是永假。

## 4. 缺陷清单
- **D1 开路效率越界**：η_o > 1（4/5）——J·K_T/(2πK_Q) 数学上必 < 1。
- **D2 超 B 系列上界**：η_o / η_o,max(B) = 1.37…2.74（5/5），即该几何在**任何** J 下都取不到。
- **D3 推进效率越界**：η_D = 0.998…1.972 > η_o,max·η_H,max ≈ 0.86（5/5），等价于
  螺旋桨把收到的功率放大，违反能量守恒。
- **D4 动力链不闭合**：P_E(阻力端点) ≠ η_D·P_D(推进端点)，比值 0.172…1.052（5/5）；
  最坏 KVLCC2 差 5.82×。
- **D5 推力系数不可达**：反解 K_T = 0.64…2.40 vs 同几何 B 系列 J∈[0,1.2] 上界 0.34…0.42，
  超界 2.1…6.7×；反解 K_Q 亦超界 1.2…3.2×。
- **D6 推力不闭合**：T·(1−t)=R_T 反解 (1−t) = 0.151…0.926，物理带 [0.65, 1.00] 只在
  客滚一支擦边通过；其余 4 型任何单位假设下都无法用合理推力减额闭合。
- **D7 不可审计**：响应既无 J、w、t，也无 K_T/K_Q，且无单位标注；上游报告 1561 的
  「5 型船闸门」显然只查了推力方向/单调性一类软判据，**效率上界与功率闭合不在门内**
  ——这是闸门覆盖面缺陷（gate blind spot），比单点算错更值得记录。

## 5. 局限与未完成（honest）
1. 本审计只测**已部署**的 `:8001`。报告 1561 的修复可能已在仓内而未部署（报告 1549 已
   记录一次「改仓 ≠ 改线上」的部署漂移），因此「代码是否已修、只是未部署」这一分支记
   **WITHHELD**，本单不下结论。
2. 缺陷代码在船舶私有仓（ship-performance-platform），按席位白名单不在 TensorPlatform
   仓的改动范围，本单只做**独立复核 + 可复算闸门 + 派单**，不越界改码。
3. B 系列上界是按树内 O&O 回归（完整 39+47 项）扫描 J∈[0,1.2] 得到的；未做端点修正
   （如叶数/桨毂效应）的进一步校核，若 O&O 实现本身有误，D5 的绝对倍数会变，但 D1/D3/D4
   （越界与不闭合）不依赖任何回归实现，仍成立。
4. 精度判定：本单的关键量是**无基准的物理不可能性**（η≤1、链闭合），不是与实验的百分比
   误差；因此「<3%」判据在此不适用，按能量恒等式判「是否闭合」。最接近的量化为链闭合
   恒等式的偏差 |P_E/(η_D·P_D) − 1| = **5.2%（客滚）… 82.8%（KVLCC2）**，5/5 型均 > 3%，
   其中 4 型 > 58%。效率越界本身是定性的（η_o=1.358…1.792 > 1），量化为
   η_o/η_o,max(B) = 1.37…2.74 倍。

## 6. 判定与去向
- 能力证据等级：`propeller.open_water`（REAL）与本链上 λ 的**在线行为**应降级为
  **MOCK**（效率为量级错误但结构完整的经验式输出），直到 D1–D6 转 PASS。
- 建议修复顺序：① 用 B 系列（或 BEMT）按 J 求 K_T/K_Q → 由推力闭合定 n；
  ② η_o = J·K_T/(2πK_Q)、η_D = η_o·η_H·η_R；③ P_D = 2πnQ 回代校验 P_E ≡ η_D·P_D；
  ④ 响应回显 J、w、t、K_T、K_Q 与单位（消 D7）。
- 回归闸门：`tests/test_propulsion_chain_closure_m1864.py`（5 passed + 4 strict-xfail），
  修复后 4 条 xfail 会转红，强制回来更新本文件。
