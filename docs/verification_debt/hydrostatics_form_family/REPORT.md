# 静水力 Cb 参数化闭式的剖面族锚点复核（m1858 审核席）

## ① 案例介绍

被复核对象是 `src/ship_perf/hydrostatics.py` 的两条闭式：

```
KB/T = (1 + 1/(2·max(Cb,0.5))) / 3      # 梯形剖面族
BM   = B² / (12·T·Cb)                     # 隐含：矩形水线面 + 满 Cwp
```

稳性闸门（`docs/verification_debt/stability_pontoon/`）直接吃 KM=KB+BM 作判据，所以这两式的**适用域**必须用闭式真值钉住，而不能靠「看起来对」。

## ② 怎么做

三级证据链，全部离线闭式、无重算力：

1. 为四种可解析求解的浮体写 KB/BM 精确表达式（矩形浮箱、三角棱柱、半椭球体、Wigley 型）；

2. 用**独立**的中点法双重积分（水线切片 + 竖切片，801×801）重算 ∇、KB、I_wl，与闭式互校，证明锚点本身可靠；

3. 同参数喂平台核 `kb_from_cb` / `bm_transverse`，算相对误差。

判定：锚点互校 <1.0%；平台误差 >15% 视为不可接受（平台通用精度标准）。

## ④ 注意点 / 局限

* 平台式对**梯形剖面族 + 矩形水线面**是精确的（两个控制算例误差恒为 0），所以这不是「公式写错」，而是**适用域没说清**：`Cb` 一个自由度无法同时编码竖剖面形状与水线面系数。

* 误差方向是**非保守**（KB、BM 都偏大 ⇒ KM/GM 偏大），比偏小危险，必须显式披露。

* 本复核只覆盖 KB/BM 的静水闭式，不涉及 GZ 曲线形状、自由液面、纵倾耦合。

* 未改生产代码：修正需引入 Cwp / 竖剖面一阶矩两个自由度，会改变全平台 GM 数值，属需 owner 裁定的接口变更，本单只登记欠账 + 给出锚点闸门。

## ⑤ 误差判定

| 判据 | 结果 | 是否 <3% |
|---|---|---|
| 锚点自洽（闭式 vs 独立数值） | 最大偏差 0.000% | 是 ✔ |
| 控制算例（矩形/三角）平台误差 | 0.000% | 是 ✔ |
| 曲剖面算例（半椭球/Wigley）KB 误差 | +4.3%, +6.7% | 否 ✘ |
| 曲剖面算例（半椭球/Wigley）BM 误差 | +69.8%, +118.8% | 否 ✘ |

**结论**：能力判级 `REAL_but_domain_limited` —— 平台核在棱柱族内 REAL，跨出棱柱族后 KB/BM 相对闭式误差 远超 15% 门槛（最大 +118.8%），且方向非保守。`tests/test_hydrostatics_form_family_anchor.py` 把上述四例钉成回归护栏。
