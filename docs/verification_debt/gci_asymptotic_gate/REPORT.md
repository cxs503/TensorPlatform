# GCI 渐近性判据恒真缺陷 + 双内核分歧审计（m2033，platform 席自找活）

**席位**：tp-impl-5（platform） · **单号**：m2033 · **分支**：`agent/m2033` · **日期**：2026-11-02
**EDIT_WHITELIST**：`docs/`、`src/`、`tools/`、`tests/`、`artifacts/`
**物理/数值域**：数值 V&V（离散误差不确定性，GCI/Richardson）

## ① 案例介绍

平台的每一个"网格无关"主张最终都落在两套 GCI 实现上，而它们服务于不同的对外出口：

| 项 | 内容 |
|---|---|
| 内核 A | `src/verification/gci.py:gci()`；被 CLI `tools/gci_report.py` 使用，输出 `verification_status: PASS/UNVERIFIED` **与进程退出码**（CI 门禁） |
| 内核 B | `backend/services/vv/gci.py:assess_convergence()`；带 `asymptotic_ratio`、`asymptotic_ok`、`exact` 覆盖率、`passed` 三态 |
| 输入 | 三套网格的代表尺寸 `h1<h2<h3` 与同一标量 QoI 的三个解 `φ1,φ2,φ3` |
| 方法学基准 | Roache (1994) JFE 116:405；Celik, Ghia, Roache et al. (2008) JFE 130:078001（工作示例）；ASME V&V 20-2009 |
| 安全因子 | 三网格 `Fs=1.25`；两网格/假定阶 `Fs=3.0` |

物理背景不必多说：GCI 是"把一个数字连同它的离散误差带一起发布"的唯一低成本手段；
若这个带子的"合格证"是恒真式，则平台上所有 GCI 证书都失去了可伪证性。

## ② 怎么做的

1. **双内核同题对拍**（`tools/audit/gci_dual_kernel_audit.py`）：10 个**写死的确定性**用例
   （文献算例、纯单项 `p=1/2/3`、非均匀细化比 `r21=1.5,r32=1.6`、两项截断假绿反例、
   振荡 `R<0`、发散 `R>1`、舍入退化、细化比不足）+ 2997 例固定 seed 随机 sweep
   （多项截断 + 5 位有效数字舍入 + 非均匀细化比）。
2. **判据的代数审查**：解析推导 `asym_ratio = e32/(r21^p · e21)` 在 `p` 由同一组三点
   估计时的取值；再用 sweep 数值验证。
3. **假绿反例**：`φ(h) = 1 + 4h^2 + 30h^3`（形式二阶，`r=2`，最细 `h=1/32`）——
   第三项不可忽略 ⇒ 估计阶漂移；这正是"网格还不够细"的典型形态。
4. **最小修复**：`gci()` 增加 `p_expected` / `order_tol`（形式阶判据）、输出
   `asym_ratio` / `asym_ratio_tautological` / `order_rel_dev` / `order_ok`；
   `asymptotic` 由"细化比代理量"改为"细化比足 + （若有形式阶）阶数校验通过"；
   CLI 增加 `asymptotic_check` 三态（PASS / FAIL / **WITHHELD**）。
5. 工具链：`python3 tools/audit/gci_dual_kernel_audit.py --out artifacts/gci_dual_kernel --figures`；
   回归闸门 `tests/test_gci_asymptotic_gate_m2033.py`（12 项）。

## ③ 计算结果

### 3.1 文献锚（Celik et al. 2008 三网格工作示例：0.97050 / 0.96854 / 0.96178，r=2）

| 量 | 文献值 | 内核 A | 内核 B | 相对偏差 |
|---|---|---|---|---|
| 观测阶 `p` | 1.786 | 1.786170 | 1.786170 | 0.0095 % |
| `GCI_fine` | 0.103 % | 0.103083 % | 0.103083 % | 0.0802 % |
| Richardson 极限 `φ_ext` | — | 0.971300 | 0.971300 | 双内核 1e-15 |

### 3.2 判据审计（sweep 2997 例，seed=2033）

| 指标 | 结果 | 含义 |
|---|---|---|
| `max |asym_ratio − 1|` | **1.11e-14**（区间 [1, 1]） | `asym_ratio` 是**恒等式**，不携带渐近范围信息 |
| 可比较阶的例数 | 2726 | 单调可估阶的比例 |
| `max rel. Δp` / `ΔGCI`（单调可估阶子集） | 1e-15 量级 | 两套实现**是同一个估计量** |
| 收敛类判决不一致 | 70 / 2997 | 集中在舍入退化与振荡/发散（策略分歧，见 ⑤） |

### 3.3 假绿反例与修复判决

| 用例 | 估计阶 `p` | 阶数偏差 | 修复前 `asymptotic` / CLI | 修复后 |
|---|---|---|---|---|
| `φ = 1+4h²+30h³`（形式 2 阶，r=2） | 2.4367 | **21.84 %** | `True` / `PASS` / 退出码 0（假绿） | `False` / `UNVERIFIED` / 退出码 1（`asymptotic_check=FAIL`） |
| 同上但未给形式阶 | 2.4367 | 无基准 | `True` / `PASS`（不诚实） | `asymptotic_check=WITHHELD`（如实声明判据不可用） |
| 干净二阶序列 `1+0.5h²` | 2.0000 | <1e-9 | `True` | `True`（无误伤） |

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **三网格 + 估计阶 ⇒ 范围检验不可伪证**：`(φ_ext, a, p)` 三个未知量恰好被三个数据点
   定死，拟合残差为零，`asym_ratio` 必然为 1。要真检验必须要么给**形式阶**（本单实现），
   要么加**第四套网格**（残差检验），要么给独立参考解（`exact` 覆盖率，内核 B 已有）。
2. **策略分歧要按"判决"读，不能按"数字"读**：振荡（`R<0`）与发散（`R>1`）序列上，
   内核 A 拒绝给 `p`（保守界 `Fs·(max−min)`），内核 B 仍给 `p`（被钳到搜索下限，如 1.0）
   与一条 GCI 带。消费方必须看 `regime/verdict/passed`，不要摘 `gci_fine` 这个数字。
   本单没有统一两侧策略（会改变已发布数字的语义），只把它记录成**显式分歧类**并用测试钉死。
3. **舍入退化**（最细两网格到 5 位有效数字已无变化）会被 A 判 `monotone` 且落到保守界，
   而 B 判 `indeterminate`：这是标签口径差异，不影响"不可认证"的结论，但报告里不要
   引用 A 的 `regime` 字符串作为"收敛类型"。
4. `asymptotic` 字段语义**收紧**（向后兼容：不传 `p_expected` 时行为不变），
   但语义变化对下游是实质性的 —— 任何"因为 `asymptotic=True` 就宣称网格无关"的
   旧结论必须重跑一次；`tools/gci_report.py` 的 PASS 现在要求形式阶校验或显式 WITHHELD。
5. 文献锚只钉 `p` 与 `GCI_fine` 两个发布到三位有效的量（文献本身只发布到这个精度），
   `φ_ext` 无发布值，故以"双内核互校 + 单调趋势"两条弱判据代替。

## ⑥ 误差判定（vs 基准，逐项，显式回答是否 <3 %）

| 关键量 | 基准 | 误差 | <3 % ? |
|---|---|---|---|
| 观测阶 `p`（Celik 2008 示例） | 1.786 | 0.0095 %（A、B 相同） | **是** |
| `GCI_fine`（同例） | 0.103 % | 0.0802 % | **是** |
| 纯单项序列的阶复原（p=1/2/3） | 解析真值 | ≤4.6e-15 相对 | **是** |
| 非均匀细化比下的阶复原 | 3.0（真值） | 4.6e-15 | **是** |
| 双内核 `p` / `GCI` 互差 | 另一内核 | ≤1e-14 相对（单调可估阶子集） | **是** |
| 假绿反例的阶数偏差检出 | 21.84 % 漂移 | 修复前漏检、修复后 100 % 检出 | 判据正确性，非精度误差 |

**结论**：误差量级 1e-14～1e-3，远优于 3 % 线；本单的缺陷不是数值精度问题，而是
**判据的可伪证性**（恒真谓词冒充检验），已修复并加闸门。
