## 一、案例介绍（物理背景 / 几何 / 参数表）

### 案例1：箱型驳船（Box Barge）

箱型驳船是最简单的船型，其横截面为矩形，沿船长方向不变。其静水力参数有精确的教科书解析解，是验证数值积分器的理想基准。

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 船长 | L | 100.0 | m |
| 船宽 | B | 20.0 | m |
| 型深 | D | 10.0 | m |
| 方形系数 | Cb | 1.0 | — |
| 水密度 | ρ | 1025.0 | kg/m³ |
| 吃水扫描范围 | T | 1.0 ~ 10.0 | m |
| 吃水步长 | ΔT | 1.0 | m |
| 站点数 | Nₛ | 41 | — |
| 水线数 | N_w | 21 | — |

**解析解公式**：
- 排水体积：∇ = L·B·T
- 排水量：Δ = ∇·ρ/1000
- 浮心垂向坐标：KB = T/2
- 横稳心半径：BM_T = B²/(12·T)
- 纵稳心半径：BM_L = L²/(12·T)
- 水线面面积：A_w = L·B
- 湿表面积：S = L·(B + 2T)

### 案例2：Wigley III 抛物线船型

Wigley 船型是船舶流体力学中经典的数学船型，其半宽由抛物线函数定义。该船型有精确的解析静水力解，广泛用于 CFD 和势流方法的验证。

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 船长 | L | 100.0 | m |
| 船宽 | B | 20.0 | m |
| 设计吃水 | T | 10.0 | m |
| 方形系数 | Cb | 4/9 ≈ 0.4444 | — |
| 中横剖面系数 | Cm | 2/3 ≈ 0.6667 | — |
| 水密度 | ρ | 1025.0 | kg/m³ |
| 吃水扫描 | T | 1.0 ~ 10.0 | m (10点) |
| 站点数 | Nₛ | 81 | — |
| 水线数 | N_w | 41 | — |

**解析解公式**（Wigley 抛物线）：
- 排水体积：∇ = 4·B·L·T/9
- 方形系数：Cb = 4/9
- 水线面面积：A_w = 2·B·L/3
- 浮心垂向坐标：KB = 5T/8
- 横稳心半径：BM_T = 3·B²/(35·T)
- 纵稳心半径：BM_L = 3·L²/(40·T)

## 二、方法（流程 / 关键设置 / 工具链）

### 验证流程

1. **几何生成**：调用 `barge_offsets()` 和 `wigley_offsets()` 生成离散型值表（stations × waterlines 的半宽矩阵）
2. **静水力积分**：调用 `compute_hydrostatics()` 执行 Simpson 复合积分（均匀网格）或梯形积分（非均匀网格）
3. **解析解对比**：将积分结果与上述教科书解析解逐量对比，计算相对误差
4. **误差判定**：所有关键量的最大相对误差 < 3% 即判定为 PASS

### 工具链

| 组件 | 路径 | 说明 |
|------|------|------|
| 几何生成器 | `backend/services/ship_hydrostatics.py` | `barge_offsets()`, `wigley_offsets()` |
| 静水力积分器 | `backend/services/ship_hydrostatics.py` | `compute_hydrostatics()`, `simpson_integrate()` |
| API 端点 | `backend/api/calculations.py` | `POST /calculations/hydro_curves` |
| 验证脚本 | `/tmp/gen_verify.py` | 程序化生成 result.json |
| 绘图脚本 | `/tmp/gen_figures.py` | matplotlib 生成 PNG |
| 测试套件 | `backend/test_hydro_curves.py` | 64 项 pytest 测试 |

### 关键设置

- Simpson 积分要求均匀网格且区间数为偶数；否则回退到梯形积分
- 箱型驳船使用 41 站 × 21 水线（Simpson 条件满足）
- Wigley 船型使用 81 站 × 41 水线（Simpson 条件满足）
- 所有数字由程序计算，零手抄

## 五、注意点（踩过的坑 / 局限 / 适用范围）

1. **箱型驳船 Cb=1.0**：任务描述中提到"箱型驳船 Cb=0.8"，但真正的箱型驳船（矩形截面）Cb 恒为 1.0。若需 Cb=0.8 的船型，应使用 Wigley 或其他瘦削船型。本验证以 Cb=1.0 的箱型驳船为准。

2. **Simpson 积分条件**：Simpson 复合积分要求网格均匀且区间数为偶数。`barge_offsets` 和 `wigley_offsets` 生成的网格天然满足此条件。若用户提供非均匀型值表（hull="table"），系统会自动回退到梯形积分，精度略低。

3. **Wigley 船型 BM 误差来源**：BM_T 和 BM_L 的误差来自水线面惯性矩的数值积分。Wigley 船型的水线面是抛物线形状，Simpson 积分对二次函数是精确的，但水线面惯性矩涉及 y³ 项（四次多项式），Simpson 积分有截断误差。增加站点数和水线数可进一步降低误差。

4. **湿表面积**：Wigley 船型的湿表面积没有简单的解析解，故未在 Wigley 案例中验证此项。箱型驳船的湿表面积公式 S = L(B+2T) 是精确的。

5. **适用范围**：本验证仅覆盖两种理想船型。实际船舶的复杂曲面（如球鼻艏、方尾）需要更密的网格和可能的自适应积分策略。
