# 破舱稳性 GZ 验证欠账清偿（m2043）：残存稳性力臂首次获得独立精确基准

**对象**：`backend/api/damage_stability.py`（ship-performance-platform 的 drop-in 替换件，落盘于 TensorPlatform 工作树）。
**承接**：修复单 m1507（报告 id≈1093 衍生）在 §6 明确留白——`GZmax / Range / 横倾` **无独立基准**，
判决一栏写「否（无基准，不作定量判定）」。本单把这个空白补上，并把该空白掩盖的三处缺陷定位、修复、复核。

---

## 1. 案例介绍（物理背景 / 几何 / 参数）

模型对象是**盒式驳船**（Cb = 1，等宽壁式），这是破舱稳性唯一的解析可解船型：

| 量 | 值 | 说明 |
|---|---|---|
| L × B × D | 100 × 20 × 8 m | 垂线间长 × 型宽 × 型深 |
| T | 6.0 m | 完整船吃水，∇0 = L·B·T = 12000 m³ |
| Δ | 12300 t | ρ = 1.025 t/m³，与 Cb·L·B·T 偏差 0（几何先验证） |
| KG | 5.0 / 5.5 m | 两个工况 |
| 舱室 | l×b = 20×12 m（C6 取 40 m），z_b = 0.5 m，z_t = 7.0 m | 舱底离基线 0.5 m（双层底），舱顶 7.0 m |
| 渗透率 μ | 0.95 / 0.50 | 对称中置（C1–C4、C6）与偏心 y_c = +4 m（C5） |

物理链条：破损舱与海连通 ⇒ 损失浮力法（重量不变、∇ = ∇0）⇒ 平行下沉 t′、水线面损失
（面积 μ·l·b 与惯性矩 μ·l·b³/12）⇒ 残存 GZ 曲线 ⇒ SOLAS 2009 Reg.7.2 生存概率
s = min(1, ((GZmax/0.12)(Range/16))^0.25) ⇒ Reg.6 要求分舱指数 R。

## 2. 怎么做的（方法与工具链）

三路独立复算，互相不共享数值路线：

1. **断点精确积分参考** `tools/verif/ds_exact_reference.py`：把横向截面积分区间按水面线与
   舱室边界（z = 0, D, z_b, z_t）的全部交点切开，每段用 3 点 Gauss–Legendre 精确积分
   （被积函数在每段上 ≤2 次多项式 ⇒ 精确），求水线 d 使 `A_bar(d)·L = ∇0`（二分至 1e-12）。
   平台实现是同一模型在 241 个 y 节点上的**梯形采样**，故两者构成「精确 vs 离散」对照。
2. **解析闭式锚**：损失浮力 t′、GM = z_B + I_eff/∇0 − KG、完整船壁式
   GZ = sinθ(GM + ½BM·tan²θ)、SOLAS Reg.6/7.2 规则常数。闭式与精确积分互为独立实现。
3. **平台内核直调** `tools/verif/ds_probe_m2043.py`（不经 HTTP，避免端点不可用时验证停摆）：
   6 个工况 × 逐角 GZ（0–cap，1°）× 全部关键量，落盘 `evidence.json`，机器判据写 `verdict.json`。
   修复前证据另存 `evidence_before.json` / `verdict_before.json`（同一探针 `--tag before`）。

工件：`artifacts/verif/damage_stability_gz_m2043/{evidence,evidence_before,verdict,verdict_before}.json`
+ 2 图；测试 `tests/verif/test_damage_stability_gz_m2043.py`（11 项，含 3 条缺陷锁）。

## 4. 三处缺陷（读码 + 探针互证）

**DS-01 破损舱自由液面被重复计入（量级 = 一次 FSC）**
截面模型已按损失浮力移除舱内水柱（隐含扣掉自由液面惯性矩），但 `analyze()` 又把
`GG0 = Σi_x/∇` 减了一次（`GZ = … − GG0·sinθ`，`GM_d = … − GG0`）。驳船工况 GG0 = 0.53 m，
正对应 C2/C3/C5 修复前 GM 偏差 +10.6% / +12.3% / +11.6%。判据：破损舱与海连通，其液面即海面，
**不存在**附加自由液面；未破损 slack 舱才需另加（当前输入模型无此字段，显式记为 0）。
修复 `_free_surface_correction()` 返回 0，`i_x_free` 保留为诊断量。

**DS-02 终吃水闭式解假定破损空间直达龙骨**
`t′ = ∇0/(Aw − Σμ·A_breach)` 只在 z_b = 0 且水线未追及舱顶 z_t 时成立。基准工况 z_b = 0.5 m，
闭式解高报 t′（C2 +0.96%、C6 +3.9%）。连锁后果比 t′ 本身严重得多：甲板边浸没角
`atan(2(D−t′)/B)` 被压低 ⇒ GZmax/Range 被低估 ⇒ **C5（偏心舱，残存稳性本就很小）被算成
`cap < heel`，曲线为空 ⇒ GZmax = 0、Range = 0、s = 0，把一条仍有 0.0231 m 残存 GZ 的船判成总损失**。
修复：改为解 `A_bar(d)·L = ∇0`（与 GZ 曲线同一水线面判据，几何自洽）。
注意旧测试 `test_f3_final_draft_matches_lost_buoyancy_analytic` 曾用 `rel < 1e-3` 把闭式解**钉成**
逐位基准（等于把缺陷锁进测试），已按物理适用域改写（闭式作上界 + 自洽反算 + 饱和闭式子工况逐位吻合）。

**DS-03 水线面惯性矩用「沿船长平均带宽」，比真值小 (l/L)² 量级**
旧式 `I_T_d = I_T0 − (A_loss·y_f² + L·b_f³/12)`，其中 `b_f = A_loss/L`；正解是移除舱室自身惯性矩
`Σμ·l·b³/12`。C2 上二者相差 110 倍（57 vs 6333 m⁴）。修复后 BM_d、GM_d 与解析锚一致。

**DS-04（顺带）概率破舱 A 指数非物理输入**
`p = zone.get("probability", 0.1)` 有静默默认、不校验 [0,1]、不校验 Σp ≤ 1 ⇒ 8 个区 p=0.2 时
A = 1.6 > 1（非物理）。改为缺 p → 422、越界 → 422、Σp > 1 → 422，并给出规范依据文本。

## 5. 注意点（局限与适用范围）

1. 参考模型与平台同构：都是「无纵倾的横向截面 + 按船长份额加权的渗透率」。**纵倾耦合**
   （水线沿 x 倾斜、舱室只占部分船长时的真实三维水线面）两侧都未建模，属已知范围；
   对中置对称舱室该近似精确，对艏艉端破损会有 O(trim·∂/∂x) 量级偏差，未在本次判据内。
2. `NY = 241` 的梯形离散给出约 1e-3 量级终吃水偏差（C6 实测 0.01 m / 1.3e-3），已在判据容差内显式记录。
3. C5 的 GZmax/Range 相对偏差在修复后仍达 48%/50%，但绝对量仅 0.011 m / 0.34°：残存稳性近消失时
   分母趋零，**相对误差不再是有意义的判据**，故该工况按绝对带（0.02 m / 1.0°）判定，并核对
   决策量 s（两侧同为 0）。这一条如实写，不粉饰成「3% 通过」。
4. SOLAS 概率破舱的 `A = 0.4·A_s + 0.4·A_p + 0.2·A_l` 三吃水加权仍未实现（现为单吃水）；
   p_i 仍由调用方给出而非 Reg.7-1 表值插值。这两条是**结构性缺口**，本单只堵住了「非物理输入」，
   已在 §6 记为遗留欠账。
