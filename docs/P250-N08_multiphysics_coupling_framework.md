## ① 案例介绍

### 物理背景

任何多物理耦合（流-固、流-冰、结构-声学……）在数值上都会落到同三件事上：
**界面通量是否守恒**、**全局守恒律是否闭合**、**耦合迭代是否收敛**。这三件事一旦出错，
单物理求解器再准也没有意义——耦合误差会静默地改写守恒量。本节点把这三点做成平台级、
可复用、可机器裁定的能力，而不是每个战役各写一份临时脚本。

### 为什么模型是"中性"的

平台铁律是零领域语义：域词条、域判据不得硬编码进 `backend/tools/tests`。
因此参考算例被抽象成**通用守恒输运链**（`N` 个区块由 `N-1` 个耦合面串联）：

```
每个区块 i：  -d/dx ( k_i du/dx ) = f_i          （体积源 f_i）
每个耦合面 i：q(x_i+) - q(x_i-) = s_i            （面源 s_i，通量跳变）
两端：        u(0)=u_left，u(L)=u_right           （外边界 Dirichlet）
```

`u`、`k`、`f`、`s` 的物理含义由调用点给定（本节点的三个量纲标签 `mass` / `momentum` /
`energy` 只是字符串，框架从不据此分支）。选择这个模型的关键理由：它**有闭式解**，
所以每一个被测量的误差都有一个独立参考，而不是"自己跟自己比"。

### 几何与参数表

| 项 | 取值 |
|---|---|
| 区块数 / 耦合面数 | 4 / 3（`length = 1.0, 0.8, 1.2, 1.0`） |
| 区块系数 k_i（matched 工况） | 1.0, 0.25, 4.0, 0.75 |
| 区块系数 k_i（contrast_40 工况） | 1.0, 4.0, 0.25, 0.1 |
| 区块系数 k_i（reversed 工况） | 0.1, 0.25, 4.0, 1.0 |
| 体积源 f_i | 0.05, 0.02, 0.03, 0.05 |
| 面源 s_i | +0.05, −0.03, +0.04 |
| 外边界 | u_left = −1.0，u_right = +1.0 |
| 每区块网格 | 12 单元，几何渐变 r = 1.04（两侧网格互不匹配，这是真实耦合常态） |
| 收敛容差 / 上限 | 1e-12 / 400 步 |
| 阻尼 ω | 0.5 |

A2 的三个守恒量各自独立跑一套系数/源（`scripts/run_p250_n08_multiphysics.py:QUANTITY_CASES`）。

## ② 怎么做的

### 单物理域求解器（每侧独立、守恒的有限体积）

`tools/coupling/multiphysics.py:solve_block_dirichlet`：非均匀网格上的面通量形式有限体积，
每个面只有一个通量（离散散度定理逐单元成立），边界用半单元距离。界面通量由**该侧自己的
模板**算出——这正是耦合界面必须对上的那份数据。

### 耦合驱动（分区耦合，界面准牛顿）

`run_coupled`：
1. 界面值 φ 作为两侧的 Dirichlet 数据，每个区块独立求解一次；
2. 每一侧报告自己算出的界面通量 `q_left_side`（发送侧）与 `q_right_side`（接收侧），
   发送侧交付 `q + s_i`；
3. 界面失衡 `r_i = q_right_side − (q_left_side + s_i)` 驱动更新 `φ ← φ − ω D⁻¹ r`。

`D` 由 `scheme` 决定：
- `newton`（生产方案）：`D = ∂r/∂φ`，在初始猜测处做一次有限差分扫描测得——
  这就是分区耦合里 IQN-ILS / Anderson 类方法的思路。**对线性模型可以预言收敛率
  ρ = |1−ω|**，所以"实测收敛率"是可校验的，不是拟合出来的。
- `jacobi`：只取对角（对角预条件）。
- `scalar`：`D = I`，即朴素 Dirichlet–Neumann 迭代——保留它作为**反例**，
  证明闸门能拒绝烂耦合方案。

### 五个锚（判据先于动手，阈值集中在 `THRESHOLDS`）

| 锚 | 定义 | 判据 |
|---|---|---|
| A1 界面通量守恒 | `|r_i| / max(|q_left|, |q_right|, |s_i|)`，逐面统计 | < 1 % |
| A2 全局守恒 | `(q_out − q_in) − Σ s_i − Σ f_i V_i`，用**实际交换的**通量闭合 | < 2 % |
| A3 耦合收敛 | 残差序列 `‖Δφ‖/‖φ‖` 的几何衰减率 ρ 与经典观测阶 p（`ln r_{n+1}` vs `ln r_n` 回归） | ρ < 1 且 p ≥ 1（且必须收敛到容差） |
| A4 误差传播 | `S = (Δy/y)/(Δp/p)`，中心差分，对 5 个输入逐一 | \|S\| < 1 |
| A5 负控 | 关掉耦合后与**单物理域直接解**的偏差 | < 0.1 %，且注入 1 % 界面污染必须被抓到 |

每个锚都带**缺陷注入**钩子（A1/A2 的 `transfer_scale`、A5 的 `injected_leak`）：
一个只有"总是通过"的闸门等于没有闸门，因此每个闸门都要证明自己会红。

### 工具链

纯 numpy（无 scipy 依赖）；图用 matplotlib（Agg 无头）；工件 JSON 带 case/run digest 与图 sha256，
报告数字由 `report_metrics.json` 程序化注入，零手抄。

补充结果：

- **A3 方案对照**（同一算例，`scheme_study`）：`newton` ρ=0.5000、43 步收敛；
  `jacobi` ρ=0.9378、400 步仍未到 1e-12 → 闸门拒绝；`scalar` ρ≈1.0000、失衡停在 1.16
  （发散）→ 闸门拒绝。即闸门对"好/坏耦合方案"有分辨力，不是恒定通过。
- **A1/A2 缺陷注入**（`defect_study`）：transfer scale 1.0005 → 5.0e-4 / 1.12e-3；

- **A5 判别力**：耦合打开 1/2/3 步后，与单物理域解的偏差升至 0.662 / 0.993 / 1.159
  （相对值），即"耦合关掉"这一状态确实是被检验出来的，而不是恒等于零的假象。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **守恒误差是"机器精度"，这不是白拿的，但也不能当成"框架很难"的证据。** 有限体积
   面通量形式 + 一致的界面表示，使 A1/A2 落在 1e-13。真正的证据是**缺陷注入**：
   注入 2 % 非守恒后 A1 实测 2.0e-2、A2 实测 4.47e-2，闸门翻红。没有缺陷注入的守恒
   闸门无法排除"恒真"。
2. **"收敛阶 p"单独不能识别发散。** 线性迭代的 p 恒为 1，发散时也是 1。因此 A3 的闸门
   是联合判据：ρ < 1 **且** p ≥ 1 **且** 达到容差；`scalar` 方案正是 p=NaN/ρ≈1 被拒。
3. **观测阶估计器有噪声底。** 对纯几何序列 0.5ⁿ 回归给出 1.0000 ± 1e-3（
   `test_order_estimator_reproduces_a_known_geometric_series` 校验），因此闸门带
   `order_estimator_tolerance = 1e-3` 的估计器余量；实测 0.99995–0.99998 是估计器噪声，
   不是收敛质量差异。这个余量是**测出来的**，不是拍的。
4. **`transfer="halo"` 已实现但不进验收。** 该模式让接收侧只能拿到发送侧用自己单元平均值
   外推出来的面值（真实异构代码的做法），会引入 O(h²) 界面一致性下限，使残差在 1e-3 量级
   触底、A3 的几何衰减被打断。它保留给"测量界面表示误差"的场景，生产验收用
   `transfer="face"`（两侧共享面值）。这个选择本身是本节点的一条经验：
   **耦合验证必须先声明界面表示约定，再谈守恒**。
5. **适用范围**：稳态、线性、单通道（`N` 个区块串联）。多维界面、非线性系数、
   界面上的鞍点型约束（不可压流-固）尚未覆盖——框架的数据结构（区块/面/通量/源/面值）
   是通用的，但耦合算子的实现需要各自扩展；A3 的"预言 ρ = |1−ω|"只在接头为线性映射时成立。
6. **A4 的 5 个参数是可选的**，敏感度值取决于所选输入与输出的组合（此处输出取进口通量）。
   换输出口径（如某面通量）会得到不同的 \|S\|；结论"传播系数 <1"只对当前口径成立。

## ⑥ 误差判定（关键量 vs 基准，逐项回答是否 < 3 %）

基准 = 链式问题的闭式解（独立于有限体积组装，`analytic_solution`）。

| 关键量 | 基准 | 实测误差 | 是否 < 3 % |
|---|---|---|---|
| 三个耦合面的界面通量 | 闭式 `q(x_i±)` | 9.63e-13（相对） | **是** |
| 系统吞吐通量 q(0)（A4 输出、A2 流入） | 闭式 `throughput` | 1.0e-13 量级（relative 见表） | **是** |
| 界面值 φ_i | 闭式 `interface_values` | ≤1e-12（耦合收敛容差 1e-12 决定） | **是** |
| 区块单元值 u（2.5 长度上 12 单元渐变网格） | 闭式解 | 1e-4 ~ 7e-4（离散 O(h²)，随加密下降） | **是** |
| 耦合收敛率 ρ | 预言值 \|1−ω\|=0.5 | 0.49995–0.50003（偏差 ≤1e-4） | **是** |
| 5 个输入敏感度 S | 闭式敏感度 | ≤1e-11 绝对差 | **是** |

结论：所有关键量与闭式基准的偏差均 **< 3 %**（其中守恒类量在 1e-12 量级），
A1–A5 五条判据全部 PASS（`artifacts/p250_n08/report_metrics.json:passes = true`）。
唯一需要读者注意的"非小误差"是区块单元值的 O(h²) 离散误差（1e-4 量级），
它来自单物理域求解器而非耦合——A5 负控正是把它与耦合泄漏区分开的那个锚。
