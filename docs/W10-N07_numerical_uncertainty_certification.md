## ① 案例介绍：物理背景、几何与参数

### 1.1 为什么用「理想化冰航道阻塞」作为冰阻力的表征算例

船舶在冰区航道中的冰阻力由三部分构成：破冰/挤压形成的**形状阻力**、碎冰块被推挤、翻转造成的**附加动量交换**、以及冰-水-船表面间的摩擦。要把「数值不确定度」作为一个可测量的量，需要一个**QoI 完全由离散解决定**、且有两条彼此独立离散路径的算例。因此本节点取冰区航道的标准理想化：

- **层冰（level ice）算例**：航道被一个连续冰脊/冰槛收窄，抽象为单个方形阻塞物，阻塞比 D/H = 0.25；QoI 是阻塞物的无量纲阻力系数 $C_D = F_x/(\tfrac12 \rho \bar U^2 A_{front})$。
- **碎冰（brash ice）算例**：三个交错布置的小冰块（边长 D/3），代表必须被推开的碎冰块群；QoI 为冰块群总阻力系数。
两个算例都是**x 方向周期**的槽道 + 体积力驱动：周期单元是「船在准均匀冰场中前进」的标准理想化，同时把入口/出口边界条件从误差预算里彻底移除——这正是要测量离散误差时需要的。

障碍物按**格心索引**布置（`cases.solid_mask`），因此三个网格上离散体积完全相同：层冰 81/144/225 格，碎冰 27/48/75 格（= 3×3²/3×4²/3×5²）。这一点是 GCI 的前提：若用连续坐标判据 `|x−x_c| ≤ side/2`，边长 9 的方块在网格上会覆盖 10 格，不同水平代表的**不是同一个几何**，三网格 GCI 就失去意义（本节点实测到该陷阱，见 §6）。

### 1.3 结构算例：板格跨间屈曲

船底纵骨在横舱壁/强横梁之间受总纵弯矩轴向压力 P，附着板格用 Winkler 弹性地基 k 约束，控制方程为 Hetényi 梁柱方程 $EI w'''' + P w'' + k w = 0$（简支两端），极限状态取**弹性分岔载荷** $P_{cr}$。参数：
E = 2.060e+11 Pa，I = 3.400e-06 m⁴，L = 2.4 m，k = 7.200e+05 N/m²，A = 1.800e-03 m²，σ_y = 3.150e+08 Pa。
解析参考：$P_m = EI(m\pi/L)^2 + kL^2/(m^2\pi^2)$，$P_{cr}=\min_m P_m$；无限长梁的 Hetényi 极限 $2\sqrt{kEI}$ 是其上界之一。

## ② 方法：工具链与关键设置

### 2.1 GCI 内核（`scripts/vv/gci.py`）

三网格过程按 Roache (1994/1998) 与 ITTC 7.5-03-02-01：

$$\varepsilon_{21}=\frac{f_2-f_1}{f_1},\quad \varepsilon_{32}=\frac{f_3-f_2}{f_2},\quad R=\frac{\varepsilon_{21}}{\varepsilon_{32}},\quad GCI_{fine}=F_s\frac{|\varepsilon_{21}|}{r_{21}^{p}-1}$$

相对老内核（`tools/gci/core.py`、`src/verification/gci.py`）的三处硬改进：

1. **非均匀细化比**：$p$ 由一般三点关系 $\varepsilon_{32}/\varepsilon_{21}=r_{21}^{p}(r_{32}^{p}-1)/(r_{21}^{p}-1)$ 二分求解，均匀比退化为闭式 $\ln(\varepsilon_{32}/\varepsilon_{21})/\ln r$。本节点两个算例的 $(r_{21},r_{32})=(1.24,1.32)$ **不相等**，闭式公式会给出错误的 $p$。
2. **可伪证的渐近性判据**：m2033 审计指出老判据 $\varepsilon_{32}/(r^p\varepsilon_{21})\equiv1$ 是恒真式；这里改用外部给定的形式阶 $p_{expected}$ 判 $|p_{obs}-p_{expected}|\le 0.1p_{expected}$，并已用反例（$\phi=1+4h^2+30h^3$）验证它**会失败**（测试 `test_asymptotic_test_can_fail`）。
3. **显式降级**：$R<0$（振荡）、$|R|>1$（发散）、$r<1.25$、$p_{obs}>4$ 或 $|\varepsilon_{21}|=0$ 一律置 `certifiable=False`，GCI 仍报告但只作可追溯量，裁决器随后返回 `WITHHELD`；降级原因写入 `degradation` 字段，不允许静默通过。

不确定度合成与裁决（ASME V&V 20 / ITTC 7.5-03-01-01）：

$$U_{SN}=\sqrt{U_{GCI}^2+U_{input}^2},\qquad U_V=\sqrt{U_{SN}^2+U_D^2},\qquad \text{achieved}\iff |D|\le U_V$$

裁决器额外输出 `certified_band = U_V`：**证据能认证的最小区间**。于是「误差 < 10%」这类声明可以被机器否证——只要 $U_V>10\%$。

### 2.2 两套求解器

| | FVM（`scripts/vv/fvm.py`） | LBM（`scripts/vv/lbm.py`） |
|---|---|---|
| 方程 | 不可压 N-S，人工压缩性（Chorin 1967）伪时间推进 | D2Q9 BGK + Guo (2002) 力项 |
| 网格 | 交错 MAC（u 在 x 面、v 在 y 面、p 在格心） | 规则格，halfway bounce-back |
| 对流 | 二阶中心 + 25% 迎风混合（压制钝角奇偶失稳） | 无（介观） |
| 壁面 | 镜像 ghost（$\phi_{ghost}=-\phi$） | halfway bounce-back（壁在格心之间） |
| 压力 | ACM 伪压力，收敛后即物理解 | $p=c_s^2\rho$ |
| 力 | 共享的 `force.surface_force`（同一泛函！） | 同左 |

**关键设计**：两套求解器把**同一份** `solid_mask`、同一 ∇p/ρ 驱动、同一 Re 交给**同一个**壁面应力积分器（`scripts/vv/force.py`），所以 $C_D$ 的差异只能来自离散化本身，而不是力提取方式不同。半程反弹壁与 FVM 镜像 ghost 壁都落在格心连线中点，几何一致。

### 2.3 收敛判据与可复算性

每个求解单元以数据驱动的确定性判据停机（相邻 500 步窗内 $\bar U$ 相对变化 $<2\times10^{-5}$），迭代步数是数据的确定函数，无随机数、无计时依赖 → 逐位可复现。粗网格解用于给细网格做**网格序列初始化**（最近邻重采样 + 平衡态重构），把细网格的收敛步数从 4.5 万降到 1 万量级。

## ⑤ 注意点（踩过的坑与适用范围）

1. **力积分器的两个符号/项陷阱**（都曾让结果偏差 10–30 倍/倍级）：(a) 切向摩阻贡献方向恒沿当地流速，不能再乘一次法向分量——否则槽道两壁的摩阻恰好相消；(b) 法向速度的**法向**导数不是无滑移量，用单侧无滑移梯度伪造 $2\mu\partial u/\partial x$ 会引入量级超过压力阻力的伪项。共享积分器在解析 Poiseuille 上校准到 1.39%。
2. **相对差商约定偏差**：ITTC 用 $(f_2-f_1)/f_1$；当修正量不小时分母偏差会污染 $p_{obs}$。同为精确二阶族，修正量 60% 时相对约定给出 $p_{obs}=1.32$（真值 2），绝对差商约定给出 2.000000000000。CFD 数据修正量在 1% 量级，偏差可忽略，但**读数前必须确认约定**。
3. **几何必须逐水平自相似**（按格心索引布置障碍物），否则三网格研究的不是同一几何。
4. **ACM 稳定性**：格心 Péclet 数超过 ~2 时中心通量失稳；把碎冰算例的 Re 参考长度误设为单冰块边长，使 ν 降到 0.009、$Pe\approx5.6$，FVM 在 500 步内发散——这是**算例定义**的错，不是物理。统一以 D 为 Re 参考长度后稳定。
5. **ACM 还需要伪声速与 CFL**：$\beta=4u_0^2$、二维 CFL 含 $1/\sqrt2$ 因子；β 取 4 时 2D 限制被违反 2 倍。
6. **适用范围**：$C_D$ 是阶梯几何、周期单元、体积力驱动的理想化量，**不能**直接当作实船冰阻力；本节点认证的是「数值不确定度方法链」与「历史声明的可认证性」，不是实船冰阻力的精度。
7. **未完成/未支持**：板格**弹塑性极限强度**（von Kármán 大挠度 + 材料非线性）未实现，本节点只做弹性分岔；`TensorFEM` 仓库的 plan3/4 屈曲节点几何未直接复用（本节点用独立 Hermite 梁柱单元，因为需要解析参考）。这两项如实记为未覆盖。
