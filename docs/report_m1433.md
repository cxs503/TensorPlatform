## 1. 案例介绍（物理背景与问题定义）

### 1.1 物理背景

耐波性（seakeeping）研究船舶在波浪中的六自由度运动响应。核心计算量是 **RAO（Response Amplitude Operator）**——
单位波幅下的运动响应幅值，是频率和遭遇角的函数。平台实现的物理模型：

- **入射力**：长波 Froude-Krylov 近似 + Smith 修正
- **辐射/衍射**：耦合吸收进无量纲衰减系数 κ 和阻尼比 ζ
- **运动方程**：频域线性叠加，ITTC/PM/JONSWAP 谱积分得统计量

### 1.2 原单 m1433 目标

审计 `backend/services/seakeeping.py`（518 行）与 `backend/api/domain/ship_seakeeping.py`（171 行路由）的
数值正确性，清偿验证欠账。

### 1.3 参数范围

| 参数 | 典型值 | 说明 |
|---|---|---|
| L, B, T | 150 m, 22 m, 8 m | 主尺度 |
| Cb | 0.65 | 方形系数 |
| Δ | 17589 t | 排水量（几何闭合反算） |
| κ (heave/pitch/roll) | 0.80/0.25/0.35 | 与船型无关的衰减系数 |
| ζ (heave/pitch/roll) | 0.20/0.12/0.10 | 与船型无关的阻尼比 |
| ω 范围 | [0.05, 2.5] rad/s, n=201 | 默认网格 |

## 5. 注意点（踩坑、局限、适用范围）

### 5.1 开发期被锚点抓出的错误（m1649 教训）

1. **S4 容差设错**：初版 5e-9，实测 5.343e-09 打红。根因：ζ=0.05 时共振峰极尖锐，
   双精度在峰附近只能分辨 ~1e-8。容差必须设在**浮点可实现的精度**上。
2. **S9 判据自身写反**：初版把 `heading=0`（随浪）当 U=0 基准，误差 1.346 打红；
   改为随浪/迎浪各自独立一阶运动学式后误差 0.0。

### 5.2 局限

- **无试验基线**：RAO 绝对精度只能标 WITHHELD；κ/ζ 为与船型无关的常数，服务已如实声明
- **未做线上复核**：修复前 `/api/v1/seakeeping/rao` 为 404；m1649 已在 `backend/main.py` 接线，
  需重启 :8001 才线上生效
- **模型物理边界**：入射力为长波 Froude-Krylov 近似 + Smith 修正；λ ≲ L 时 heave 激励
  刻意省略长度相位因子，属定性有效域

### 5.3 适用范围

- 模型内部一致性/解析极限/缩比不变性/谱矩恒等 → **REAL**（11 项机器可裁）
- 试验或实船 RAO 绝对精度 → **WITHHELD**（仓内无耐波试验基线）
- 修复前的线上可达性 → **NOT_SUPPORTED**（路由从未挂载，实测 404）
