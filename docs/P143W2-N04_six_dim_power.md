## 2. 方法

1. **方向化配对差**：`delta_i = direction_k * (v_treatment,i - v_control,i)`，`direction_k` 见 `DIMENSION_DIRECTION`（accuracy/efficiency/reproducibility 的数值口径是「越小越好」，故取 -1）。正值 = 实验组更好。
2. **效应量**：配对 Cohen's `d_z = mean(delta)/sd(delta)`（ddof=1）、配对差中位数（稳健），均值 CI 用 t 分位，中位数 CI 用二项序统计量。
3. **置换检验**：配对符号翻转（sign-flip）置换，10000 次随机符号翻转，统计量 = 配对差均值，`p=(1+#{|T_perm|>=|T_obs|})/(1+B)`；零假设下精确（不依赖正态）。
4. **FWER 控制**：Bonferroni-Holm 逐步下降，六维为一个族；Holm 在任意相依结构下都控 FWER，且比均匀 Bonferroni 有功效。
5. **MDE(n)**：解析 `MDE=(z_{1-a/2}+z_b)σ_d/√n`（α=.05/功效 .8 → 2.802σ_d/√n）；数值反解用**同一置换检验**做蒙特卡洛 + 对数二分；参考基准为精确非中心 t 反解。
6. **A/A 空对照**：同一路线两次（两臂同分布），跑完整六维族判决，统计误报率；主判据是**族判决**（≥k 维显著）的误报率——这正是战役真正要用的规则，其零假设率天然低于逐维 α（独立零维时 P(≥2 个逐维误报)≈3.3%）。
7. **回溯性功效**：对既有战役产物（每臂单测）计算方向化相对效应；n 不足则借 σ 代理反解所需 n，并给 σ 敏感性表；输出三态（可判 / 需n=N / 不可判）。

## 6. 注意点与局限

* **小 n 的离散化**：等幅配对下双侧符号翻转检验可达最小 p=2/2^n，n=5 时为 6.25%（拒绝不了），n=6 才 3.1%；`MIN_TESTABLE_PAIRS=9` 是**设计下限**（保证 0.05 以下的 p 阶梯不止一两档），不是数学下限——这是选择，已在 docstring 声明。
* **方向性备择需预声明**：命题是「优于」而不是「不同」，故主判据用单侧；双侧行（`primary_two_sided`、`power_two-sided` 列）同时报告，结论方向不因换备择而翻转。
* **配对收益 rho 是设计假设**：rho=0 时 d=0.5/n=20 的检出率仅 0.448（单侧），此时 n=20 不够——真实战役必须实测配对相关，不能假定。
* **σ 代理是跨量转移假设**：回溯性功效里的 σ 借自同路线复跑差异或敏感性网格，不是测量；因此结论只作「量级/所需 n」用，不能当 p 值。
* **回溯数据的口径瑕疵**：既有产物里 accuracy 行（对照 arm 的解析锚点误差 vs 实验 arm 的路线间差）口径存疑，已在 `p12_spec.json` 的 note 与工件里登记；这类维即便显著也不能单独当结论。
* **A/A 的 10^2 分辨率**：100 族的点估计分辨率是 1%，主判据落在族判决（≥2 维）上，并对 5 个 seed 汇总（500 族）报告抽样波动。
* **适用边界**：本门只做统计裁决，不替代物理验证；六维数字本身的正确性由各自的解析锚/守恒律验证负责。
