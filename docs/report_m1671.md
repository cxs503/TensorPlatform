## 1. 案例介绍（物理背景与审计目标）

### 1.1 物理背景

TensorPlatform 船舶总体性能平台覆盖 21 项核心能力，其中 3 项为 REAL 级别计算能力：
- **阻力计算**（calc.resistance）：ITTC-1957 摩擦线 + 经验剩余阻力系数
- **稳性计算**（calc.stability）：Wall-sided 公式 + 精确箱形驳船交叉验证
- **推进计算**（propeller.open_water）：Lanchester-Glauert 动量理论 + 开放水曲线

### 1.2 审计目标

对 21 项能力进行验证状态审计，重点审查 3 个 REAL 级别核心计算能力的：
1. 测试覆盖率与通过率
2. 解析验证完整性（机器精度 vs 实验对标）
3. 基准数据溯源可靠性
4. 已知局限与适用范围声明

### 1.3 关键参数表

| 能力 | 方法 | 关键参数 | 验证基准 |
|------|------|---------|---------|
| 阻力 | ITTC-1957 + 经验 Cr | Re, Fn, Cb, S | SUBOFF (Roddy 1990) |

## 5. 注意点（踩坑与局限）

### 5.1 阻力系统已知局限

**问题 1：湿表面积公式对船型不适用**
- 当前公式：`S = π·B·L·(0.5 + 0.25·Cb)`（针对轴对称体校准）
- 对 KVLCC2/DTMB-5415 产生 40-60% 高估
- **影响**：船型阻力误差 45-602%（不可接受）
- **建议**：引入船型专用公式 `S = L·(2T + B)·(0.453 + 0.442·Cb - 0.286·(B/T) - 0.0035·(L/B))`

**问题 2：剩余阻力系数无文献溯源**
- 当前公式：`Cr = 0.002 × (1 + 2Cb) × Fn^2.5`（经验拟合）
- 无文献来源，不得引用为验证模型
- **建议**：补充 Holtrop-Mennen 方法或 ITTC 推荐方法

**问题 3：SUBOFF 高 Fr 案例误差 >15%**
- Fr=0.918 时误差 34.6%（超出适用范围）
- **原因**：经验公式高频限制 + SUBOFF (Cb≈0.542) 超出 Holtrop-Mennen 适用范围 (Cb>0.55)
- **建议**：声明适用范围或补充高频修正

### 5.2 基准数据溯源问题

**DTMB-5415**：
- 记录航速 5/10/20/30 kn 与模型尺度 L=5.72 m 搭配时 Fr=0.34-2.06（物理不可能）
- Fr 列隐含船长 181.2 m ≠ L=5.72 m
- **结论**：整列 WITHHELD，不可用于验证

**KVLCC2**：
- 缺失湿表面积 S
- 由 Rt=8.2 N 反推 S_imp=17.49 m²，S_imp/(L·B)=4.028 超出物理带 [1.0, 3.2]
- **结论**：参考值 WITHHELD，需补充 SIMMAN 2008 可靠数据

### 5.3 审计局限

1. **未执行新 CFD 计算**：受高负载环境限制（load=112/128），仅做代码审查 + 测试执行
2. **未补充基准数据**：DTMB-5415/KVLCC2 参考值溯源问题未解决（需人工查阅 SIMMAN 2008 原始文献）
3. **API 测试跳过**：部分集成测试因 API 不可用被跳过（8/17 skipped）

### 6.2 显式回答

**问题**：关键量误差是否 <3%？

**回答**：
- ✅ **推进系统**：是（机器精度，<1e-11）
- ✅ **稳性系统**：是（机器精度，<1e-15 m）
- ⚠️ **阻力系统（SUBOFF）**：否（1.2-13.5%，>3% 但 <15% 可接受）
- ❌ **阻力系统（船型）**：无法判定（基准数据 WITHHELD）

**原因说明**：
1. 推进/稳性系统为解析验证，无经验依赖，误差至机器精度
2. 阻力系统为经验公式，SUBOFF 3/4 案例误差 <15%（工程可接受），但 >3%（不满足高精度要求）
3. KVLCC2/DTMB-5415 基准数据存在溯源问题，无法用于验证
