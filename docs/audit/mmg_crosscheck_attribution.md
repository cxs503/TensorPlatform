## ① 案例介绍（物理背景 / 几何 / 参数）

操纵性预报的核心是 3-DOF MMG 方程（纵荡-横荡-艏摇）：

```
(m+m_x) u̇ − (m+m_y) v r = X_H + X_P + X_R
(m+m_y) v̇ + (m+m_x) u r = Y_H + Y_R
(I_z+J_z) ṙ             = N_H + N_R
```

同一船型、同一舵角，两条独立实现给出 18–32 % 不同的回转指标。m1651 已把它记为
WITHHELD（无实船/水池试验数据，无法判谁对），但**没有追查分歧来源**。本单补这一步：
不做绝对真值判定，只做**归因**——分歧落在哪个力/力矩子模型上，差多少，需要补哪个项才能闭合。

| 项 | 值 |
|---|---|
| 船型 | KVLCC2 主尺度（L=320 m, B=58 m, T=20.8 m, Cb=0.8098） |
| 航速 | 设计航速 15.5 kn = 7.974 m/s |
| 工况 | 35° 右满舵回转，t_end=1200 s |
| 实现 A | `backend/services/digital_twin/models/manoeuvring.py`（DT：横流阻力条带 + 细长翼升力 + 2π 舵；RK4） |
| 实现 B | `backend/physics/ship_env_maneuvering/mmg.py`（W3-N08：**经验导数式** MMG，Y'_v=−0.315 / N'_v=−0.137 / N'_r=−0.075 …，Fujii 舵升力梯度 + 桨尾流放大；RK4） |
| 工具链 | `tools/benchmarks/mmg_crosscheck_attribution.py`（纯离线、只读、无新物理）→ `artifacts/mmg_crosscheck/` |

## ② 怎么做的（方法 / 流程 / 关键设置）

四条判据，**没有一条用到"记忆里的文献表值"**（沿用 m1413/m1651 纪律）：

1. **A 复现（reproduction）**：同船同速同舵，六个指标并排对照，确认复现 m1651 的 18–32 %。
2. **B 导数提取（derivatives）**：把两套实现的**船体力**单独取出（DT 的横流+升力项、W3-N08 的
   `Y_H/N_H` 多项式），对 (v, r) 做**中心差分**，用**同一套无量纲化**
   （Y' = Y/(½ρLTU²)，N' = N/(½ρL²TU²)，v'=v/U，r'=rL/U）。
   同时给出**闭式仲裁量**：细长体附加质量 my'=2πT/L、Munk 力矩 N'_v = −(m_y′−m_x′)
   （用**各自实现自己声明的**附加质量代入，不引用外部表）。
3. **C 敲除实验（knockout）**：给 DT 模型注入两类缺失力矩，其余一字不改：
   - C1 纯势流 Munk 力矩 λ·(m_y−m_x)uv，λ∈{0,0.1,0.2,0.3,0.5,1.0}；
   - C2 线性稳定力矩 N'_v（并取 N'_r=0.55 N'_v，比例取自 W3-N08 自身两个导数的比值），
     N'_v∈{−0.05,−0.10,−0.137,−0.18,−0.25}。
   每个算例都记录**是否真的完成了 180° 回转**（`turned_180`）——失稳的模型不许"看起来更好"。
4. **D 判定（verdict）**：归因表 + 闭合所需力矩 + 残留误差，机器可读 JSON。

λ=0（全部注入关闭）逐位复现出厂模型（pytest 断言 rel<1e-6），证明敲除只添加了那一项。

### 3.2 B 线性水动力导数（同口径）

| 导数 | DT（差分） | W3-N08（差分） | W3-N08 代码声明值 | 含义 |
|---|---|---|---|---|
| Y'_v | −0.2216 | −0.3432 | −0.3150 | 横荡力，**仅差 35 %** |
| N'_v | **+0.0102** | −0.1335 | −0.1370 | **船体漂角力矩，DT 几乎为零（且符号不稳）** |
| Y'_r | +0.0102 | +0.0829 | +0.0830 | 艏摇引起的横荡力，DT 小 8 倍 |
| N'_r | **−0.0005** | −0.0750 | −0.0750 | **转艏阻尼力矩，DT 缺失** |
| （闭式）Munk N'_v | −0.3791 | — | — | 用 DT **自己的**附加质量（m_y′=0.408，m_x′=0.029）算出的势流力矩 |

**结论性事实**：DT 的升力项只作用在单一作用点 x_L=−0.05L 上，横荡力几乎不产生力矩，
因此其船体**力矩族（N'_v, N'_r）实质为零**；它只能靠横流阻力的非线性（|v+xr|(v+xr)）
去平衡舵力矩——这正是需要 19.9° 漂角（而 W3-N08 只要 13.3°）、直径大 30 % 的机制。

### 3.3 C1 纯势流 Munk 修补（naive patch）——失败

| λ | 战术 D/L | 漂角 [°] | u/U0 | 1200 s 内最大首向变化 | 完成回转? |
|---|---|---|---|---|---|
| 0.0 | 3.802 | 19.88 | 0.294 | 180.0° | 是 |
| 0.1 | 5.829 | 18.08 | 0.367 | 180.0° | 是 |
| 0.2 | 9.900 | 15.16 | 0.486 | 180.0° | 是 |
| 0.3 | 20.170 | 12.42 | 0.653 | 180.0° | 是 |
| 0.5 | nan | 8.34 | 1.082 | **31.6°** | **否（失稳）** |
| 1.0 | 19.319 | 4.13 | 1.216 | 180.0° | 是（但指标无意义） |

漂角确实朝 13.3° 方向走，但直径**爆炸**：把势流 Munk 力矩（−0.379）单独加进去会让船体
**航向失稳**（λ≥0.5 时 1200 s 内只转过 31.6°，根本不回转）。→ **"补 Munk 项"不是正确修复。**

### 3.4 C2 需要多少线性稳定力矩才能闭合直径

| 注入 N'_v | N'_r | 战术 D/L | 进距/L | 漂角 [°] | u/U0 |
|---|---|---|---|---|---|
| −0.05 | −0.028 | 3.431 | 2.860 | 20.46 | 0.268 |
| −0.10 | −0.055 | 3.175 | 2.954 | 21.16 | 0.247 |
| −0.137 | −0.075 | 3.033 | 3.005 | 21.69 | 0.234 |
| **−0.18** | **−0.099** | **2.901** | 3.052 | 22.30 | 0.222 |
| −0.25 | −0.138 | 2.738 | 3.110 | 23.27 | 0.206 |

W3-N08 基准：D/L=2.875、进距/L=3.315、漂角 13.26°、u/U0=0.326。
**直径在 N'_v≈−0.18（N'_r≈−0.10）处闭合到 0.9 %，但漂角反而恶化到 22.3°（+68 %）、
速度比掉到 0.222**——说明力矩族只能解释一部分，**舵/桨子模型（W3-N08 有桨尾流放大
`u_R·min(factor,2.0)`、`(1+a_H)` 增额、Fujii 舵梯度 2.05 vs DT 的 2π）是第二个独立贡献**。
单一线性力矩无法同时闭合直径与漂角，**两套模型不是同一套物理**。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **导数提取的偏差**：中心差分步长 β=1°，Y'_v 会带入 `Y_vv|v'|v'` 的 O(β) 偏置
   （W3-N08 的 Y'_v 测得 −0.3432 vs 代码声明 −0.315，偏 8.9 %）。**线性项 N'_v/N'_r/Y'_r
   的复现误差 ≤2.6 %**，Y'_v 两侧同偏置、可比；结论（力矩族差 1 个数量级）不受影响。
2. **W3-N08 的导数集本身不是金标准**：其 `data.py` 溯源声明明说"literature-shaped，
   未离线核对原表"。所以本单判的是**分歧归属**，不是谁对；绝对真值仍 WITHHELD。
3. **DT 几何是理想化船体**（矩形横剖面、抛物线水线，Cwp=Cb），m1651 已声明其绝对
   回转直径不可当 KVLCC2 预报值使用。
4. **敲除注入是诊断性的**，不是修复：`_ExtraCore` 只活在工具与测试里，**没有改动任何生产
   模型**（DT 与 W3-N08 的源码一行未动）。要真修，必须先有可核对的船体力矩族来源。
5. **未做**：没有给 DT 换经验导数集（等于引入无出处的表值，违反 m1413 纪律）；
   没有重标定舵/桨子模型（需实船/水池数据）；没有改 `surrogate_registry.py` 里用 m1651
   前数据训练的 PCE 代理。
6. **容量纪律**：本单全部为纯公式求值 + 短时积分（21 s），load15≈70 < 100，未起重算力进程。

## ⑥ 误差判定（逐项，显式回答是否 <3 %）

| 判据 | 基准 | 实测 | 是否 <3 % |
|---|---|---|---|
| 导出差分器复现 W3-N08 的 N'_v | 代码声明 −0.137 | −0.1335（2.6 %） | ✅ 是 |
| 同上 N'_r | −0.075 | −0.0750（0.0 %） | ✅ 是 |
| 同上 Y'_r | +0.083 | +0.0829（0.1 %） | ✅ 是 |
| 同上 Y'_v | −0.315 | −0.3432（8.9 %） | ❌ 否（β=1° 差分的 O(β) 偏置，两侧同偏置） |
| λ=0 敲除复现出厂模型 | DT 战术 D/L 3.802 | 3.802（<1e-6） | ✅ 是 |
| **DT 的 N'_v vs 闭式 Munk** | −0.3791 | +0.0102（偏 103 %，比值 −0.027） | ❌ 否——**这就是缺陷本体** |
| **DT vs W3-N08 的 N'_v** | −0.1335 | +0.0102（差 1 个数量级） | ❌ 否（分歧来源） |
| 注入 N'_v=−0.18 后战术 D/L vs W3-N08 | 2.875 | 2.901（0.9 %） | ✅ 是 |
| 同一注入的漂角 vs W3-N08 | 13.26° | 22.30°（+68 %） | ❌ 否（第二个独立贡献：舵/桨子模型） |
| DT vs 实船试验 绝对回转直径 | **无可用试验数据** | — | **WITHHELD**（不粉饰） |

**结论（honest）**：18–32 % 分歧的**根因已定位**——DT 船体力模型缺失整个力矩族
（N'_v≈0、N'_r≈0，比闭式 Munk 小 1 个数量级），只能用横流阻力非线性平衡舵力矩，
导致 50 % 过大的漂角与 30 % 过大的直径；naive 补 Munk 会失稳；线性力矩只能闭合直径
（0.9 %）不能闭合漂角（+68 %），故**至少还有一个舵/桨子模型差异**。
绝对真值仍 **WITHHELD**——仓内无 KVLCC2 操纵试验数据，本单不开"谁的数对"的口子。
