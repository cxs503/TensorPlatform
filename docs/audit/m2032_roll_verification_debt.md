## ② 方法（做了什么）

1. **F1 缺陷定位与修复**：通道 B 的横摇激励写成 `m4 = C44·k·|cos β|·Γ·e^(-kT)`，归一化又除 `k|cos β|`。
   横摇由**横向波面斜率（|sin β|）**驱动，用 |cos β| 把航向依赖整个倒置：横浪（β=90°）横摇恒为 0、
   顶浪（β=180°）横摇最大，且 β=90° 时 `roll_rao_rad_per_rad = 0/0 → nan`。
   修复 = 3 处符号面（激励、注释、归一化）+ 头注释的极限表述，未改任何其它物理量。
   锁死该缺陷的旧测试 `backend/tests/feat/test_ship_seakeeping.py::test_long_wave_limits…`
   同步改为在**横浪**下取长波极限（该测试原先把 |cos β| 口径当基准）。
2. **解析锚定（通道 A）**：横浪+零航速下，逐站 FK 矩满足 `f4/slope = ρg∇GM·sin β = C44 sin β`（因 ΣA_s dx = ∇），
   故内核横摇 RAO **恒等于** SDOF 放大因子 `1/√((1-ν²)²+(2ζν)²)`。据此 8 条判据（K1–K8）在机器精度内裁决。
3. **参考对比（R1/R2/R3）**：T44 与 IS Code 2008 §2.3.4 回归 `T_R = 2CB/√GM`，
   `C = 0.373 + 0.023(B/d) − 0.043(L/100)`；另以**均质棱柱回转半径下界** √(B²+T²)/√12 检 k_eff 是否物理。
4. **欠账登记**：双通道 T44 漂移、ζ44 约定分裂（0.08 vs 0.10）→ 定量 + 债务标记测试。

产物：`tests/physics/test_roll_verification_m2032.py`（31 判据）、`src/ship_verification/audit_roll.py`（可重跑）、
`docs/audit/m2032_roll_audit.json`（本报告所有数字的唯一来源）。

## ⑤ 注意点（坑 / 局限 / 适用域）

- **恒等式 ≠ 外部精度**：K1 证明内核"内部接线正确"，对 k_eff、ζ 的物理正确性零信息。二者仍是输入约定。
- **IS Code C(L,B,d) 为离线转录**，无法在线复核原文；仅作 ±15% 带用，不作 1% 真值。其 C 随 L 下降（VLCC C=0.3325），
  故"固定 0.36 B"在大船上偏长约 +8.6%——这正是长船横摇周期不确定性的主项。
- 通道 B 的 FK 横摇项未含**横向衰减因子**（通道 A 升沉用的 sinc 类比项），故其长波极限虽 →1，
  短波侧偏保守；已作为适用范围声明，未擅自加项（无锚不增物理）。
- 航向扫描**非单调**：Γ(u) 在 u≈4.49 处过零导致 45° 可大于 60°；只有"横浪最大 + 左右对称"是精确陈述。
- ζ44 无文献/试验锚（未实现 Ikeda 分量法）⇒ 横摇**绝对幅值 WITHHELD**，仅比例与形状可判。
- 未做：Ikeda 横摇阻尼补全（需分量公式，离线不可靠）；双通道 T44 统一（会动生产默认值，需 owner 决策）。

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| K1 横浪横摇 RAO | SDOF 闭式解 | 1.33e-15 | **是**（机器精度） |
| K6 顶/随浪横摇激励 | 精确 0 | 1.57e-18 rad/rad | **是**（精确 0） |
| K2 长波横摇极限 | 1.0 | ≤1e-4 | **是** |

| T44（通道 B） | IS Code 2008 回归 | +22.71%（max） | **否**（且超 15% 门槛 → DEBT） |
| 双通道 T44 一致性 | 两通道互比 | +12.96% | **否** → DEBT-ROLL-1 |
| 横摇共振绝对幅值 | 无锚 | — | **不适用（WITHHELD）** |

**结论**：F1 是**实锤缺陷**（横浪无横摇、归一化 nan），已修复并有回归锁；横摇通道的**内部**因果链从此可机器裁决，
**外部**绝对精度仍欠 Ikeda 阻尼与 k_eff 约定统一两项，如实登记未清。
