## ① 案例介绍（对象与背景）

平台精度标准是**硬约束**：「对标实验/参考值误差 **>15% 不可接受**」，且每篇进展报告须**显式回答是否 <3%**。
但这条标准此前只活在散文里——没有任何机器闸门核对「报告写的数字」与「报告下的结论」是否自洽。

已有三个组件都**不覆盖**这个空档（逐个读过源码确认）：

| 组件 | 检查什么 | 漏什么 |
|---|---|---|
| `tools/report_corpus_audit.py` | 六要素**结构存在性**（有没有「是否<3%」句式） | 数字是 19.6% 却照样通过——只看句式不看量值 |
| `tools/validation_debt_ledger.py` | 「局限/待办」节的**欠账陈述** | 不碰正文里的**数值宣称** |
| 质检席 LLM 复审 | 主观判定 | 不可复算、跨批不可比 |

**审计对象（参数表）**

| 项 | 值 |
|---|---|
| 语料 | `tensor_reports` **1224** 篇（只读 SELECT id/title/markdown/mission_id） |
| 硬标准 | `HARD_TOL_PCT = 15.0 %`（>15% 不可接受） |
| 目标阈值 | `TARGET_TOL_PCT = 3.0 %`（⑥ 显式答复口径） |
| 抽取单元 | 「误差/偏差/error/deviation」标签 ±12 字窗口内的百分比数字 |
| 判定单元 | 数值所在子句 + 紧邻两子句内的**验收判定词** |

## ② 怎么做的（方法/流程/关键设置/工具链）

### 2.1 三条裁决规则（显式常量，测试钉死）

| 规则 | 触发条件 | 语义 |
|---|---|---|
| `HARD_GT15` | 数值 **>15%** 且同句带**验收判定**（达标/合格/PASS/满足判据…） | 直接违反平台精度标准 |
| `SOFT_THRESH` | 数值 **> 句内声明的容差**（如「满足 <3% 判据」却写 9.6%） | 自相矛盾：阈值被自己的数字推翻 |
| `UNSUPPORTED` | 有「<3%：是」答复，但全篇**无实测百分比/科学计数数字** | 不可复算的达标 |

### 2.2 「判定词必须背书这条误差」的四个守卫（v1→v2 的关键）

第一版用「子串判定词」，实测 **39 条 HARD 全为误报**（审计对照表里的 `✅`、`通过率`、`优于另一模型`、
`符合二阶收敛预期` 全被当成验收背书）。第二版加四条机器可判守卫：

1. **子句作用域**：判定词必须在数值所在子句或紧邻两子句内，否则 `DEFERRED`（不当罪证）；
2. **否定形态**：`无一项满足` / `未达标` / `失败` → `HONEST_FAIL`（诚实 FAIL 是纪律要求，不是缺陷）；
3. **披露语境**：`缺陷|旧实现|修复前|未披露|最差|无关|检测到` → `DISCLOSURE`（审计发现不是背书）；
4. **收敛链**：`73.9% → 27.2% → 0.05%，PASS` 类链式句 → `DEFERRED_CHAIN`（判定只背书最细档）。

另有两处「数字不是实测」的排除：`满足 3 % 判据` 里的 3 %（判据）、`<3%` 里的 3（阈值，比较符前导）。

### 2.3 变异测试：给探测器造真值（本单的方法学核心）

没有违规的语料**无法证明**探测器会抓——所以用**变异测试**造真值：把 7 个模板句追加进真实报告
（每模板 40 篇，固定种子 `MUTATION_SEED=20261102`），测量

- **正控制召回**（3 个必抓模板：HARD ×2 形态、SOFT ×1）；
- **负控制误报**（4 个必不抓模板：合规 4.5%<5%、1.8% 达标、诚实不达标、缺陷披露）。

工具链：python3 标准库（re/dataclass/hashlib）+ matplotlib（仅 `--figures`）；psql 只读拉语料。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **v1 全误报的坑**：把 `✅`「通过率」「优于另一模型」「符合二阶收敛预期」当验收词 → 39/39 误报。
   结论：**验收判定词必须白名单化**，比较语义词一律不算。这是本单最贵的教训。
2. **`DEFERRED_TABLE = 413`**：表格行一律不判级——静态解析分不清「实测值列」与「判据/文献列」。
   这是**召回上界**：表格里的自相矛盾抓不到（本单主动选择保守，宁漏不错判）。
3. **`UNJUDGED = 608`**：数值有判定词缺失（多为分节表格外的孤立数字），机器不下结论。
4. **2 条 UNSUPPORTED 为误报**：人工抽查为 QA 元报告转述别篇的「均<3%」，数字在相邻小节。
   量级小（2/1224=0.16%），未再迭代（诚实标注，不粉饰）。
5. **不裁物理精度**：本器只裁「宣称与自引数字是否自洽」。物理精度是否达标仍需 benchmark 复核
   （Wigley/Michell、SUBOFF、敞水 B 系列等台账见 `docs/validation_debt/`）。
6. **适用域**：中文为主 + 部分英文报告；对纯图/纯数值(无 %)的误差表述不敏感。
