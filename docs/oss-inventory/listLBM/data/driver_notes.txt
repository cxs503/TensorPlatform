m8285 listLBM 运行期实验说明（2026-11-09）
=========================================
目的：对 sorush-khajepor/listLBM 的 SC 伪势实现做独立数值验证（不是仓内测试，仓内无测试）。
这两个 driver 是本单自写的验证脚本（只调用其模块 API），不进入 TensorLBM，不构成其衍生作品。

编译（gfortran 12.3.0）：
  1) sed -i "s/stop'/stop '/g" collision/pseudopotential/{ppot_mod,mcmp_mod}.f90   # 修其源码 stop 语法缺陷（本地副本）
  2) 迭代编译库模块（排除 writeout/ 与 examples/，因 writeout 依赖 VTKFortran）：
     for pass in 1..6: 对尚未生成 .o 的 .f90 逐个 gfortran -O2 -ffree-line-length-none -J. -c
     结果：43 个模块全部编译成功（首轮 41/43，2 个因 stop 语法失败）
  3) gfortran -O2 <objs> driver_laplace.o -o laplace ; 同理 porous

运行：
  ./laplace <rad> <nsteps>   # 2D D2Q9 SCMP 液滴，128x128，y 周期/x 通道，rho_wall=1.4，G=-1.5，tau=1
  ./porous  <0|1> <nsteps>   # 0=无固体, 1=加 4 个 26x26 盒子；输出 imgproc.rep 的孔隙率报表
