# PB-010 评价漂移防护：盲序+只降不升

**症状**：E1回填由机器扫描产生、reason_source=rule_derived，可能照着结论找证据、随事实漂移而过期、把执行性成果说成能力增量。

**根因**：回填器与重算器复用同一套代码，形成自证循环。

**设计规则**：
1. 盲序：复算器只吃事实（mission行/报告/增量/证据引用），grade/e_level/grade_reason结构性不存在于载荷中；
2. 只降不升：断链证据→REJECT、申报超天花板→REJECT、申报E高于重算→DOWNGRADE_EVIDENCE；
3. 正控：注入46条受控篡改，检出率46/46证明装置非空转。

**来源**：m5180 (IN24-E1) + m5182 (IN24-E5)
