# m1851 · 耐波 2D 辐射阻尼：闭合 `seakeeping.EVIDENCE['radiation_damping']=WITHHELD`

## ① 案例介绍（物理背景 / 几何 / 参数）

m1809 建的耐波参考核（`src/ship_perf/seakeeping.py`）把升沉附加质量做到了可判据
（解析锚 ρπa²/2 + ω→0/ω→∞ 恒等式），但**阻尼**只能取参数化阻尼比
`damping_ratio=0.15`，自述 `EVIDENCE['radiation_damping']='WITHHELD'`，理由是
「2D 辐射阻尼需自由液面 Green 函数」。后果：**RAO 峰值幅值不可裁决**——而峰值正是
耐波学科最常被引用的量。

本单给出一个独立、可自证的 2D 频域辐射解算器，把阻尼从"参数"变成"物理解"。

几何：半浸圆剖面（半径 a = 1.00 m 等截面棱柱，船长 L = 20.0 m）。
物理参数：ρ = 1028 kg/m³（海水，模块常量 RHO_SEA）、g = 9.81 m/s²、深水色散 k=ω²/g。
算例船：Cb = 0.85、B = 2.0 m、T = 1.0 m、
排水质量 m = 34881 kg、A33_hull = 28406 kg、A_wp = 40.0 m²。

## ② 怎么做的（方法 / 关键设置 / 工具链）

- 极坐标**贴体**网格（半环域 r∈[a,R]，θ∈[-π/2,π/2]，z=-r cosθ）解 φ：
  φ_rr + (1/r)φ_r + (1/r²)φ_θθ = 0；物面二阶单侧 Neumann ∂φ/∂r = V·n = -cosθ
  （升沉单位速度）；自由液面 φ_θ = ±k r φ；外边界 Dirichlet。
- **辐射条件用自由液面吸收层（damping beach）**：k → k + iν(r)，ν 在 r>0.55R 内平方压扩到
  1.2k。**虚部符号必须随射线翻转**（+x 侧外行波 e^{+ikr}、-x 侧 e^{-ikr}），
  否则 beach 会放大波——这是第一版实测到的坑。
- 径向网格 r=a+(R-a)[(1-β)ξ+βξ³]，β=0.7（均匀网格在 ka 小、λ≫a 时近物面步长会粗到 1a，
  第一版 ka=0.15 的 A33 因此虚高 2.5×）。全部二阶非均匀差分。
- 力：F = -∮p n̂ds（n̂ 由物体指向流体）；单位升沉速度下
  **A33 = -Re C、B33 = -ω Im C**，C = ρ∮φ n₃ ds。第一版用了 + 号 ⇒ A33 整体反号，
  被 A-SHORTWAVE 判据当场抓到。
- 工具链：numpy + scipy.sparse（SuperLU 复稀疏解，n≈3×10⁴）、matplotlib（图）、pytest（判据）。
  单点耗时 2–9 s，**载机 load15≈120（nproc=128）下仍属轻量**，未起重型算力进程。

## ④ 误差判定（逐项 vs 基准，显式回答是否 <3%）

| 判据 | 基准（独立来源） | 实测 | 误差 | <3%? |
|---|---|---|---|---|
| A33 短波极限（ka=4） | ρπa²/2 = 1611.5 kg/m（Dirichlet 镜像，精确） | 1516.6 | 5.89% | **否**（5.9%，见局限） |
| A33 与既有面板法交叉（半浸圆） | 全圆面板 ρπa² = 3241.3（面板锚自检误差 0.57%），取半 1620.7 | 1516.6 | 6.42% | **否**（6.4%） |
| 能量恒等式（全 ka） | ½B33V²（物面压力积分） | 控制面能流 | 1.76%–2.97% | **是** |
| 网格收敛（ka=1/4） | 加密解 | 粗网格解 | 0.21% | **是** |
| RAO ω→0 极限 | 1.0（精确恒等） | 1.0049 | 0.49% | **是** |
| RAO 峰值 vs 旧口径 | ζ=0.15 参数化 | 物理 B33 | 3.45% | 差异 3.4%（见注意点：巧合，不是验证） |

**结论：能流恒等、网格收敛、RAO 长波极限三项 <3% 达标；A33 的两个"横向"比对落在
5.9%–6.4%（远场吸收层 + 曲线未到 ka→∞ 的渐近尾部所致），按平台 >15% 不可接受的
标准属可接受区间，但**没有**达到 3% 的严格门，故如实记为"未达 3%"。**

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **吸收层虚部符号**：自由液面两条射线上外行波方向相反（+x 侧 e^{+ikr}、-x 侧 e^{-ikr}），
   ν 的符号必须随射线翻转；否则 beach 变成放大器（第一版 B33 反向、能流比 2.2）。
2. **力方向符号**：压力合力是 -∮p n̂ds；写成 + 号会让 A33 整体反号（第一版 -0.93×极限），
   靠 A-SHORTWAVE 判据一次抓到——这就是"锚先于代码"的价值。
3. **低 ka 网格陷阱**：均匀径向网格在 λ≫a 时近物面步长 >1a，ka=0.15 的 A33 虚高 2.5×；
   改立方伸缩后回到合理值。本实现声明的适用区间是 **ka ∈ [0.3, 6]**，ka<0.3 不声明。
4. **远场幅值口径未闭合**：沿自由液面行对 φ 做 e^{±ikr} 最小二乘得到的幅值，与由能量
   一致的每侧幅值 √(2P/ρω) 之比稳定为 1.42/√2（四种窗口、n_theta=320 下不变），而同一解的
   物面功率与控制面能流一致到 3% 以内。即**能量口径已闭合，FS 行定点幅值含 √2 离散污染**；
   故 `far_field_amp`/`energy_ratio` 只作诊断、记 WITHHELD，**不作判据**。
5. **RAO 峰值对比的诚实解读**：该算例上 ζ=0.15 恰好接近物理等效阻尼（峰值差 3.4%），
   这**不是**对旧口径的验证——等效 ζ 随 ka 变化，旧口径在任何其他周期/船形上都可能显著偏离；
   本单只是把"峰值幅值"从不可裁决变成可裁决。
6. 适用范围：深水、线性势流、单自由度升沉、半浸圆剖面；一般剖面（含真实船形剖面）
   仍需贴体映射，记 WITHHELD。
