## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 物理背景
船舶在碎冰区航行时，船体与大量浮冰（ice floes）发生频繁碰撞，产生额外的附加阻尼和附加质量，显著改变船舶运动响应。当碎冰场颗粒数达到 100k+ 量级时，离散追踪每个颗粒在计算上不可行，物理上也不必要——此时应采用**均值场（mean-field）均匀化方法**，将离散碰撞统计平均为连续阻尼/质量贡献。

本节点实现了碎冰场船舶耐波性的均值场模型，等效表征 100k+ 颗粒碎冰场的集体动力学效应。

### 100k+ 颗粒等效规模
- 浮冰面积 A_floe = π(D/2)² = 78.5 m²
- 数密度 n = c/A_floe = 0.00764 floes/m²
- 水线面上浮冰数 N_wp = n × A_wp ≈ 111
- **100k 浮冰场所需面积**: A_field = N/n = 1.31×10⁷ m² ≈ 3.6 km × 3.6 km

均值场模型在此尺度下是物理上正确的选择：当颗粒数 N→∞ 时，离散碰撞的统计涨落 → 0，均值场描述精确。

## 2. 方法 / 流程 / 关键设置 / 工具链

### 2.1 算法架构

模型由四个子系统组成：

1. **OpenWaterRAO** — 开水面基线（条理论参数化近似）
   - 附加质量 A₃₃(ω)：Franck 紧密拟合近似
   - 辐射阻尼 B₃₃(ω)：共振峰参数化模型
   - 激励力 F₃(ω)：Smith 效应 + Froud-Krylov 近似

2. **FloeCollisionModel** — 浮冰碰撞模型
   - Hertz 接触力 F = k·δ^(3/2)
   - 碰撞冲量 J = (1+e)·μ·v_rel（μ 为约化质量）
   - 动量守恒 + 恢复系数约束

3. **IceAddedDampingModel** — 冰附加阻尼/质量均值场
   - 碰撞频率 f_coll ∝ c·n·v·D·A_wp
   - 附加阻尼 B_ice = f_coll·m_floe·(1+e)/ω
   - 附加质量 A_ice = c·ρ_ice·h·A_wp·α(ω)

4. **LogDecrementAnalyzer** — 对数衰减法阻尼辨识
   - δ = (1/(n-1))·Σ ln(xᵢ/xᵢ₊₁)
   - ζ = δ/√(4π²+δ²)（精确恒等式）

### 2.2 运动方程
含冰修正的纵摇运动方程：
$$[-\omega^2(M + A_{33}^{water} + A_{ice}) + i\omega(B_{33}^{water} + B_{ice}) + C_{33}] \cdot X_3 = F_3$$

## 5. 注意点 / 局限 / 适用范围

### 已验证
- 守恒律（动量、能量）在机器精度内成立
- c→0 极限正确退化为开水面
- 阻尼比随浓度/冰厚单调性正确
- 对数衰减法阻尼辨识精度 < 1e-6

### 局限
1. **均值场近似**：本模型用统计平均代替离散碰撞，适用于 N >> 1 的密集碎冰场。对于稀疏冰场（c < 0.1，N < 20 于水线面），离散效应可能显著，需 DEM 验证。
2. **条理论近似**：开水面基线采用参数化条理论，非面板法/边界元法精确解。与实验数据对标需进一步校准。
3. **二维简化**：当前仅实现纵摇（heave）和纵摇（pitch），横摇（roll）、艏摇（yaw）未包含。
4. **浮冰形状**：假设圆柱形浮冰，实际浮冰形状不规则。
5. **无实验对标**：当前结果为数学校验（conservation laws + monotonicity + limits），尚无模型试验或全尺度数据对标。

### 适用范围
- 冰浓度 c ∈ [0.1, 1.0]（密集碎冰场）
- 浮冰直径 D ∈ [1, 50] m
- 冰厚 h ∈ [0.1, 1.0] m
- 频率 ω ∈ [0.1, 3.0] rad/s
