# CMA-ES 内核文献/解析基准独立复核（optimizer.core.cmaes）

## 1. 案例介绍

船舶总体性能优化闭环（KCS 艏部型线 CMA-ES 优化，`optimizer/core/cmaes.py`，服务于水动力评估循环）依赖一个自研 CMA-ES 内核。该内核已在主干合并并用于型线优化，但仓库内**此前没有任何针对该内核的测试或文献对标**（`grep -rl cmaes tests/` 结果为空）。本单属于「验证欠账」：把已合并的内核拉去对 Hansen (2016) 的闭式参数与独立重写的参考实现做交叉复核。

被复核对象：

- `optimizer/core/cmaes.py::CMAES` —— 手写 CMA-ES（Cholesky 采样参数化、罚函数式箱约束、停滞收敛判据）；
- `optimizer/core/cmaes.py::optimize` —— 外层驱动（评价预算、历史记录）。

物理/数学背景：CMA-ES 是型线优化这类昂贵黑箱（每次评价=一次阻力计算）的主力无梯度优化器，其步长控制、协方差自适应与路径长度判据都有严格闭式定义；任何一处公式偏离都会改变搜索效率而不报错，属于典型的「静默精度损失」风险，必须用外部基准钉住。

参数表（本次复核工况）：

| 项 | 取值 |
|---|---|
| 测试函数 | sphere / ellipsoid(cond=1e6) / cigar / rosenbrock / rastrigin / ackley |
| 维度 N | 2, 3, 5, 8, 10, 20（参数核对）；2, 5, 10（收敛） |
| 初始步长 sigma0 | 1.0（收敛）/ 0.7（采样统计） |
| 箱约束 | ±10（收敛）、±1e6（采样统计，避免裁剪干扰） |
| 评价预算 | 4e4 次/工况；随机种子 42（旋转不变性另取 1,2,3） |
| 解析最优 | 全部函数 f\* = 0（解析已知） |

## 2. 方法与工具链

复核**不使用**内核自身作为参照，三条独立证据链：

1. **闭式参数链**：`optimizer/verification/cmaes_reference.py::hansen2016_params` 按 Hansen (2016, arXiv:1604.00772) 式 (5)(49)-(55) 独立转写 λ, μ, w_i, μ_eff, c_c, c_s, c_1, c_μ, d_σ, χ_N，与内核 `__init__` 逐项比对相对误差。
2. **异实现交叉链**：`ReferenceCMAES` 用教程原始的 B/D 特征分解参数化（而非内核的 Cholesky 参数化）从零重写，同一函数、同一种子下比较「达到目标精度所需评价次数」。
3. **性质链**：采样分布统计检验（经验协方差 vs σ²C）、旋转不变性（Hansen 教程 §3.3）、同种子逐位复现、协方差正定性、箱约束遵守。

判据全部机器可裁，落地为 `tests/test_cmaes_literature_verification.py`（15 个用例）。

复核中定位并修复的 4 处偏差（最小改动）：

| # | 偏差 | 修复 |
|---|---|---|
| B1 | rank-one 的 (1−h_sig) 修正项缩放的是**已衰减**的 C，而非 Hansen 式(47) 要求的 C_old | 改用 C_old |
| B2 | C 失去正定性时 `cholesky` 抛异常 → 静默替换为各向同性矩阵，**丢弃全部自适应状态** | 改为特征值钳位修复（`_ensure_spd`），并计数 |
| B3 | 分布均值 `mean` 未约束在箱内，采样全被裁剪时分布中心会漂出可行域 | 均值投影回箱 |
| B4 | `optimize()` 用 `locals()` 兜底返回收敛标志、打印判据恒假 | 显式初始化 + 修正判据 |

## 4. 注意点与局限

- **预算限制下的诚实结论**：多峰函数（rastrigin/ackley）在 N=10、4e4 评价内两者都停在局部极小（本单正式表未把 rastrigin/ackley 列入收敛判据，只作为局限性说明），因此本复核覆盖的是「凸/可分离与小维度非可分离」工况，不能外推为「内核在多峰高维全局最优上已对标」。
- **不同采样参数化带来的一次性随机差异**：内核用 Cholesky、参考用 B/D 特征分解，两条链的随机流不同，单种子比较本身带 ±30%~80% 抖动的量级，故判据取比值 ≤3 而非逐位比对；逐位一致性检查只用于「同实现同种子」（C5）。
- **箱约束实现方式**（裁剪而非重采样/罚项）会在最优解贴边时使采样分布非高斯，本单只保证「越界为 0」，未证明贴边工况的收敛无损——若后续出现贴边最优的型线算例，需要改为重采样或镜像采样再复核。
- 参考实现是非 active CMA-ES（Hansen 教程版本），内核同样非 active，因此对比公平；若将来升级为 active CMA-ES，本复核的参考基准需同步更换（pycma 离线不可用，需按论文重写）。

## 5. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 本单实测偏差 | 是否 <3% |
|---|---|---|---|
| 9 个策略参数 + 权重向量 | Hansen 2016 式(49)-(55) 闭式值 | ≤0（机器精度） | 是 |
| 采样协方差 | σ²C（精确） | 0.24%（统计下限 ~0.3%） | 是 |
| 收敛评价数 | 独立参考实现的评价数 | 最坏 +80.0%（比值 1.800） | 否（>3%），判据为比值≤3，判据通过 |
| 达到的最优值 vs 解析最优 | f\* = 0 | N=2 各工况 f_best 精确为 0；N=5/10 最坏 4.191e-30 | 是（远优于 3%） |
| 旋转不变性 | 轴对齐工况评价数 | 最坏 +4.6% | 否（>3%），判据为比值≤3，判据通过 |

答辩口径：**闭式参数与采样分布两项是严格的 <3% 通过**；**收敛效率一项与参考实现的差超过 3%（单种子噪声量级所致），判据是「比值≤3 且全部达标」，通过但不宣称 3% 精度**；**多峰高维工况未通过全局最优判据，属未覆盖范围，已如实列出**。
