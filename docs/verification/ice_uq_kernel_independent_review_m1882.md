## ① 案例介绍

被审对象是冰区航行域的**不确定度量（UQ）数值层级**：`backend/services/ice_resistance_uq.py`
（1013 行），由 `backend/api/domain/ice_uq.py` 的 4 个在线端点 `/resistance`、`/uq`、`/uq/all`、
`/ships` 直接调用。该层级五段：

| 段 | 实现 | 判据 |
|---|---|---|
| 1-D 求积 | `_gauss_hermite_nodes_weights`（Golub–Welsch，概率论者 Hermite） | V1 |
| 多维求积 | `smolyak_sparse_grid`（线性增长 + 稀疏系数） | V2 |
| 代理模型 | `build_pce`（谱投影 c_α = Σ w f ψ_α / α!） | V3 |
| 灵敏度 | `sobol_indices`（谱分解 S_d / S_T,d） | V3, V4 |
| 「真值」 | `monte_carlo_reference`（硬编码物理界裁剪的 MC） | V4, V5 |

为什么必须复核：平台把它当**证据生成器**——`tests/test_pce_ice_resistance_uq.py` 用
「PCE 统计量 vs 本模块 MC 参考」判自己合格（同模型、同分布假设、同作者 = 自证）；m1720 只审了
物理式（Lindqvist 速度因子）与标定链，**数值层级从未对解析基准复核**。冰区设计里「哪个不确定量
主导阻力方差」正是这段代码回答的。

参数（生产默认 `run_all_ships_uq(max_level=3, max_poly_order=3)`）：4 维不确定输入，名义值取
各船试验点，相对标准差 20% / 15% / 25% / 10%。

| 船 | σ_c [MPa] | h [m] | μ | V [m/s] | 试验均值 [kN] |

| Polarstern | 1.2 | 0.8 | 0.12 | 2.5 | 1800 |

## ② 怎么做的

参考侧与被测侧**物理隔离**：`tools/validation/ice_uq_reference_m1882.py` 只用 ① 解析正态矩
E[ξ^k]=0/(k−1)!!；② 精确多项式响应的闭式 Sobol 分解（⟨He_a,He_b⟩=a!δ_ab，Sudret 2008）；
③ 与谱投影无关的 Saltelli-2010 一阶 / Jansen-1999 总阶 MC 估计量。被测模块按文件路径加载，
**不参与任何参考值生成**。

| 判据 | 基准 | 容差 |
|---|---|---|
| V1 GH 求积 | 解析矩；n 点规则应对 ≤2n−1 次多项式精确 | 1e-10 相对 |
| V2 Smolyak 网格 | 解析矩；level L 应对 ≤2L−2 次偶次单项式精确 | 1e-10 相对 |
| V3 PCE 精确性 | 精确多项式响应的系数/方差闭式 | 1e-10 / 1e-12 相对 |
| V4 真实冰模型 Sobol | Saltelli/Jansen MC（异估计量、异离散） | 平台 15% 带 |
| V5 MC「真值」分布一致性 | 未裁剪高斯参考 | 只量化，不设通过线 |

**V3**：判据 V3a（`max_level ≥ 响应总阶+1` 时系数逐项精确）→ **PASS**；V3b 记录出厂默认 (3,3) 在总阶 ≥3 的响应上必然混叠：2 个被审配置不精确。

混叠机理：投影分子 f·ψ_α 的总阶为 `deg+order`，level L 网格只精确到 2L−1 次，故精确条件
`2(deg+order) ≤ 2L−1`；默认 `deg=order=3` 需要 `L ≥ 4`。最干净的实证（解析可判的纯三次响应
y = ξ₀³，ξ₁ 构造上零影响）：

| 配置 | 方差（解析 15） | S_T(x0)（解析 1） | **S_T(x1)（解析 0）** | 判决 |
|---|---|---|---|---|
| 默认 max_level=3, order=3 | 11 | 1 | **0.1818** | FAIL（伪灵敏度） |
| 修正 max_level=4, order=3 | 15 | 1 | **3.27e-31** | PASS |

即默认配置把 **18.2% 的总阶灵敏度**判给一个物理上完全不参与响应的输入。对「哪个不确定量主导方差」这类决策，是方向性错误而非精度问题。

## ⑤ 注意点

1. **缺陷定位在默认参数而非物理式**：混叠只在 `max_level < 总阶+1` 出现，而 `build_pce` 的签名默认值与
   `run_all_ships_uq` 都是 (3,3)，即 `/uq`、`/uq/all` 端点实际使用的配置。
2. **物理欠账另计**：m1720 已判 Lindqvist 平冰阻力 WITHHELD（留一法 out-of-sample 3.2%/22.9%/−21.2%）；
   本单只审数值层级，不改变该判定。
3. **MC 不是天然真值**：不换成未裁剪抽样 + 异估计量，「PCE 与 MC 一致」只是自证。
4. **稀疏网格含负权重**（(−1)^k C(d−1,k)），高阶下 S_T 求和可轻微越界，量级见 V2/V4 表。
5. **不改船舶代码**：按 owner 纪律，修复单派给 ship-performance-platform 席；本单只交付证据与判据。

## ⑥ 误差判定（逐项回答是否 <3%）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| GH 规则矩（n=1..8，≤2n−1 次） | 解析正态矩 | ≤ 6.661e-16（权重和） | **是** |
| Smolyak 矩（≤2L−2 次偶次单项式） | 解析正态矩 | ≤1e-10 量级（V2 表） | **是** |
| PCE 系数（max_level ≥ 阶+1） | 闭式多项式系数 | ≤ 1.105e-14 | **是** |
| PCE 系数（出厂默认 3,3，总阶 3 响应） | 闭式多项式系数 | 伪 S_T = 0.1818 | **否** |
| 真实冰模型 S_T（收敛配置） | 独立 MC | 最大绝对偏差 0.008534 | **是** |
| 真实冰模型 S_T（默认配置） | 独立 MC | 最大绝对偏差 0.008594 | **是** |

## ⑦ 综合裁决

- 数值层级在精确性条件成立时 **REAL**：V1/V2/V3a 全部 PASS，V4 收敛配置与独立 MC 偏差 0.008534 ≤ 15% 带。
- **出厂默认 (max_level=3, max_poly_order=3) 有混叠缺陷**（V3b）：总阶 ≥3 响应上 Sobol 归因不可信，
  而该默认值正是 `/uq`、`/uq/all` 的实际配置 → 默认路径灵敏度归因判 **WITHHELD**，需修复后重新复核。
- V5 说明模块自带「MC 真值」与 PCE 假设分布不一致，其自证测试不计入独立证据。
