## ① 案例介绍：被审的对象与它欠的账

平台对外发布的静水力（排水体积 ∇、Cb、LCB、KB、BM_T、水线面积 Aw、湿表面积 S_wet）与稳性（GZ 曲线、GZ 曲线下面积）都是**数值积分**的产物：

| 生产者 | 离散化 | 数值积分 | 早前状态 |
|---|---|---|---|
| `compute_hydrostatics(offsets)` | 站位数 `n_stations` × 水线数 `n_waterlines` 的偏移表 | 均匀网格复合 Simpson，非均匀退化为梯形 | 有验证（validate 对解析量）**无离散误差棒** |
| `gz_area(angles, gz, 0, 30)` | 横倾角步长（生产调用 `range(0, 91, 5)`，即 **5°**） | 梯形 | 无 |

即：这些数字隐含"网格无关"的声明，但仓内没有任何代码能量化、夹逼或证伪该声明。补上的是 verification（离散误差本身），不是 validation（对实验值）。

## ② 怎么做的（判据 / 工具链）

**细化研究**：两个解析可解的船型——矩形驳（`barge_offsets`，100×20×8 m）与 Wigley 抛物线船（`wigley_offsets`，L=6 m, B=0.6 m, T=0.375 m）。偏移表按**恒定细化比 r = 2** 同时加倍两个方向：`(21,11) → (41,21) → (81,41) → (161,81) → (321,161)`（n_stations−1 与 n_waterlines−1 同步加倍，故可用单一 r 描述，这是 GCI 的前提）。网格尺度取 h = 1/(n_stations−1)。

**判据（先于动手定死）**：
- **解析锚**（闭式，非记忆数字，逐条可验）：
  驳 `∇=LBT, Cb=1, Aw=LB, LCB=0, KB=T/2, BM_T=B²/(12T), S=L(B+2T)`；
  Wigley `∇=4BLT/9, Cb=4/9, Aw=2BL/3, KB=5T/8, BM_T=3B²/(35T)`。
- **Wigley 湿表面积无闭式**（截面周长是椭圆型积分）→ 用 `scipy.integrate.quad` 双重自适应积分
  `S=∫₀ᴸ 2∫₀ᵀ√(1+(dy/dz)²)dz dx`（epsrel 1e-12）作独立参考。生产者的算法是把截面周长**多边形化**再沿 x 积分，误差真实非零，必须夹逼。
- **GZ 面积闭式**：墙舷式 `GZ=sinφ(GM+½BM tan²φ)`，
  `∫₀^Φ GZ dφ = GM(1−cosΦ) + ½BM(cosΦ+secΦ−2)`（Φ 取弧度；推导：∫sin³/cos²dφ = cosΦ+secΦ−2）。
  测试再用 `scipy.quad` 对 φ 直接数值积分交叉验证该闭式（独立于推导）。
- 判定：`assess_convergence(..., exact=参考值)`，输出观测阶 p、Richardson 外推值、细网格 GCI、解析真误差是否被 GCI 覆盖、渐近区比值是否落在 Roache 带内；闸门 = 所有 QoI 在生产网格上误差 ≤ 3%。

**工具链**：`examples/verification/hydrostatics_gci_study.py`（一次运行 ~9 s，纯 CPU 毫秒级/量级，无求解器、无重算力进程——入场时 load15=122 ≥ 100，按容量纪律只做轻量）→ `study.json` + `tables.md` + 2 张 PNG；`pytest` 23 项 9.4 s。

读法（这是本单最实质的两条发现）：
1. **多项式被积函数被 Simpson 精确积出**——∇、Cb、KB、Aw、驳的全部量在 21 站位时已达机器精度（误差 ~1e-14）。即这些量**没有**离散误差欠账，任何"网格无关性"的担心在此不成立（此前无人证明这一点）。
2. 两个**真非零误差**的量被钉住并给出误差棒：
   - Wigley `BM_T`（被积函数含 y³，Simpson 对三次在均匀网格上仍精确到机器精度附近）观测阶 **p=3.999 ≈ 4**，与 4 阶理论一致；生产网格误差 2.3e-5 %。
   - Wigley `S_wet`（多边形周长 → 二次收敛，**不是** Simpson 的 4 阶）观测阶 **p=1.999 ≈ 2**；生产网格（81×41）误差 **1.78e-3 %**，最细网格 4.5e-4 %。这是"生产默认网格够不够"的直接答案。

## ④ 注意点 / 局限 / 适用范围

- **r=2 的适用条件**：两个方向同步加倍才能用单一细化比；若只加密站位而不加密水线，GCI 公式不成立（此时应做双参数敏感性而非 GCI）。
- 墙舷式 GZ 闭式仅在**无水舱边缘露出、无甲板浸没**的倾角区间成立（本案例 D=14 m、30° 内成立）；大倾角须用真实剖面几何，闭式锚失效。
- `S_wet` 的多边形化误差是**系统性偏小**（折线周长 ≤ 弧长），因此生产值偏小 ≈1.8e-3 %，对摩擦阻力（∝S）的影响同量级，可忽略但不为零；若换成粗网格（21×11）则偏小 2.8e-2 %，仍远小于 15%/3% 闸门。
- 本单只做 **verification**（离散误差），不涉及与试验值的 validation；`Cb/几何前置校验` 未在此重复（见 `docs/geometry_verification_m1609.md`）。
- Heel 10° 步长误差 2.52 % 虽仍在 3 % 内，但**余量仅 0.5 个百分点**——若未来 GZ 曲线含强非线性段（舭部出水、甲板浸没），10° 会越线；生产代码用 5°（`src/ship_perf/hydrostatics.py: range(0, 91, 5)`）是对的，本单把它从"习惯"变成"有误差棒的选择"。
