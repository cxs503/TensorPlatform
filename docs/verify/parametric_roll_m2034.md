## ① 案例介绍（物理背景 / 几何 / 参数）

参数横摇（parametric roll）是集装箱船与 PCTC 的实船失效模式：船舶在纵浪中航行时，
**波浪沿船长把水线面形状周期性改变**，初稳性高 `GM(t) = GM_0 + ΔGM·cos(ω_e t)` 随时间变化；
当遭遇频率满足 ω_e ≈ 2ω_n 且参数激励幅值超过阻尼吸收能力时，横摇振幅指数增长直至倾覆 ——
**即使静水 GM 完全满足 IS Code 2008 的全部静稳性衡准**。它属于 IMO 第二代完整稳性（SGISC）
三模式之一，而平台此前整块缺失：

| 扫描面 | 结果 |
|---|---|
| `grep -riE 'parametric_roll\|pure loss\|surf-riding' backend src api` | **0 命中**（稳性域只有静稳性 GZ / IS Code 2008 / 天气衡准 / 破舱） |
| 近 20 篇平台报告（id 1754–1781） | 覆盖耐波附加质量、波浪增阻、扭振、BEMT 敞水、风阻、冰阻力 UQ、NSGA-II、GCI；**无参数横摇** |
| `docs/verification_debt/` 8 个已建目 | stability 只有 `stability_pontoon`（静稳性），无动力学稳性目 |

**几何（解析可积的浮箱族 `FlaredBarge`）**：`B(x,u) = Bx(x)·(1−κ+κu)`，`u=z/T`，
`Bx(x)=B0(1+β·2x/L)`。于是剖面面积 `a(x,d)=Bx[(1−κ)d+κd²/(2T)]`（d 的二次式）、
水线宽 `b(x,d)=Bx(1−κ+κd/T)`、水线面惯性矩 `b³/12`、对龙骨一阶矩 `m_z` 全部闭式。
基准船参数：`L=200 m, B0=32 m, T=9 m, KG=5 m, β=0.55`；外飘 κ∈{0, 0.45, 1.0} 扫描。

## ② 怎么做的（方法 / 流程 / 工具链）

**层 A · 波浪中 GM（几何）**：以波形作为水线（IMO Level-2 惯用），
`d(x) = T + a·sin(kx+φ) + h + τx`，未知数 heave `h` 与纵倾斜率 `τ` 由
体积与纵向矩双守恒牛顿求解（解析 2×2 雅可比），收敛残差 < 1e-9；
再由 `KB=∫m_z/∇0`、`BM=∫i_x/∇0` 得 `GM(φ) = KB+BM−KG`。
扫一个遭遇周期得到 `ε = (GM_max−GM_min)/2 / GM_mean`。

**层 B · 阻尼 Mathieu 横摇**（单自由度，线性）：
`θ'' + 2ζω_nθ' + ω_n²(1+ε cos ω_e t)θ = 0`，`ω_n = 2π/T_roll`（自然横摇周期由外部给定，
**不使用赝造的惯性半径**），`ω_e = ω + kU cos β`。
无量纲化到标准 Mathieu `a=(ω_n/ω_e)²`，**主参数共振位于 a=1/4**（=ω_e=2ω_n）；
Floquet 单值矩阵用 RK4 积一个激励周期，`|ρ|max>1` 即不稳定。

**判据层**：`assess_parametric_roll()` 端到端输出 ε / a / ε_cr / |ρ|max / 增长速率 / 判决。

**验证策略（先造判据再动手，全部解析、无经验常数）**：
1. 箱型极限对接**已验证**的 `src/ship_perf/hydrostatics.py`：`KB=T/2`、`BM=B²/(12T)`；
2. `a→0` 必须回归静水；浮态守恒残差；ΔGM 对波幅/外飘单调、在 λ≈L 峰化；
3. 主共振阈 `ε_cr = 4ζ`（一阶解析）→ 与 Floquet 数值二分逐点比对；
4. 与独立实现 `scipy.integrate.solve_ivp`（rtol 1e-12）的单值矩阵互校；
5. Floquet 增长速率 vs 时域 RK4 包络拟合增长速率互校。

## ⑤ 注意点 / 踩过的坑 / 适用边界

1. **踩到的真坑（已修，并留下探针测试）**：草稿用 `δ=(2ω_n/ω_e)²` 当 Mathieu 系数，
   等价于把**主共振错放到 δ=1**——那是第二不稳定区。后果：ζ=0.02 时阈从 0.0803 被高估到
   **0.466（+480%）**，会把绝大多数真实船判成「安全」。修正为 `a=(ω_n/ω_e)²`（主共振 a=1/4）后
   与解析 `4ζ` 吻合到 0.14% 以内。`test_second_region_needs_much_larger_excitation` 就是这条的探针
   （要求第二区阈值 ≥5× 主共振区）。
2. **几何模型低估真实外飘**：梯形外飘在 H/L=2.5% 时仅给出 ε=1.3%~4.4%；实船集装箱船
   ΔGM/GM 可达 0.3–0.5（水线以上大外飘 + 舭部出水）。因此本内核当前的判决**偏保守**：
   它能把「明显起振」判对，但不能替代实船 Level-2 计算。要闭合该欠账需把剖面模型扩展为
   「水线以上外飘 + 舭部圆弧」，属后续单。
3. **单自由度线性横摇**：无升沉/纵倾动力耦合、无横摇-首摇耦合、无 Froude–Krylov 横摇力矩
   与绕射；参数激励只取 GM(t) 的几何部分。因此输出是**参数激励幅值的几何估计 + 稳定性判决**，
   不是横摇响应幅值预报（不报最大横摇角）。
4. **`T_roll` 与 ζ 必须外部给定**：本模块不给默认物理值，避免赝造。3.2 的 T_roll 由「a=1/4」
   反解得到（同步共振构造），不是实船测量值。
5. 波形作水线的做法在陡波（H/λ>1/10）下失效；`n_clipped>0` 时说明剖面高度被截断，结论不可用。
