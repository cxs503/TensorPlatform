# IN59-P2 冰层断裂与接触模型：五角色×七环 ABM 与理论/实现/实验三腿闭合

## ① 案例介绍（物理背景 / 几何 / 参数表）

- **物理背景**：海冰/淡水冰是准脆性多晶材料，其宏观力学由晶间键合（cohesion）与接触摩擦共同决定。冰区船舶与结构设计（ISO 19906）需要冰的抗压/抗拉强度、弹性模量与尺寸效应作为输入；这些量在实验上分散性很大，DEM 是唯一能同时给出**破坏模式**（劈裂/剪切带）与**宏观强度**的数值途径。

- **几何**：二维颗粒切片（平面应变近似），厚度 t = 0.05 m，颗粒半径 r = 0.0025 m（±2.5% 分散）；单轴试样 544 颗粒 / 1528 键（H/W≈1.9）；直接拉伸试样（上下运动学夹头）；巴西劈裂圆盘（削平加载弦）；三点弯梁。

- **参数表**（标定后，全部来自 `experiments.json:spec`）

|---|---|---|

| 剪/法刚度比 ks/kn | 0.01 | 由格理论 ν=(kn-ks)/(3kn+ks) 反解目标 ν≈1/3 |

## ② 怎么做的（方法 / 流程 / 工具链）

**五角色**（知识包差异化，见 `run_abm.py:KNOWLEDGE_PACKS`）：攻关负责人（问题树/门）、理论研究者（离散元/接触力学/断裂力学）、实现工程师（数值离散/性能）、挑战者（反例与适用边界，独立判断权）、独立验证者（盲序复算）。

**七环**（`tools/abm` 通用机制，零领域语义）：问题树 → 基线 → 多假设+预测盲 → 实验 → 挑战 → 六维验收 → 沉淀；前一环未过则后一环不可关闭（`GateSequence`）。

**模型**（`dem_bpm.py`）：接触（线性弹簧+黏性阻尼+库仑摩擦的 tanh 滑移正则）+ 平行粘结（轴向/切向/弯矩，梁类比 k_n=E_bA/L、k_b=E_bI/L，增量式）+ 断裂准则（σ=F_n/A+|M|/W > σ_b 或 |τ|>τ_b，σ_b 按 Weibull 抽样）。

**流程纪律**：先按文献弹性模量标定 → 再**封存**两假设卡的预测（sha256 承诺）→ 才跑实验；标定前的 P0 冒烟跑单独留痕并在报告中披露（不做选择性报告）。

**工具链**：Python/numpy + scipy(cKDTree) 近邻；matplotlib 出图；`pytest tests/abm domains/ice_fracture_contact/tests` 19 项全绿；留痕为哈希链 JSONL（逐条可复算）。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

- **坑**：二维圆盘 DEM 转动自由度需弯矩阻尼与合适步长，否则切向力自反馈发散（已修）
- **坑**：质量缩放放大惯性，小试样/短荷载路径算例峰值被惯性污染（需 β 无关性检验）
- **坑**：壁面接触阻尼符号与库仑摩擦正则是两处隐蔽缺陷（由稳定性测试锁定）
- **局限 1**：二维切片无法表达海冰板的三维弯曲与碎块尺寸分布；外推冰荷载需三维 BPM。
- **局限 2**：质量缩放 β=3600.0 放大惯性；巴西劈裂峰值随 β 变化（β=3600/400/100 → 988/329/165 N），故该算例不作强度判据。
- **局限 3**：破坏后摩擦用 tanh 滑移正则（无静摩擦累积），残余强度偏保守。
- **适用范围**：完整冰盖的弹性/强度/破坏模式可表征；碎冰冰花区需另行标定。
