## 关键路径与坑（复用价值最高的四条）
- **pick-freeze Sobol' 不能用低差异点集作 A/B 基底**：两条置乱 Sobol' 网之间存在相关结构，
  闭合性样本间散度从 ±24% 恶化到 ±500%。`sobol_hdmr` 里已注释禁用，勿再加 `design="qmc"`。
- **闭合性是"小差分"估计**：7 输入、阶数≤2 的闭合性 = 1+7+21 项之和，二阶项来自小对比，
  单次运行标准误 3–5%。裁决必须多种子平均并报 SE（`sobol_hdmr_replicated`），
  否则"落在 [0.95,1.05]" 只是运气。
- **乘性响应的相对 Jacobian 恒为秩 1**：`d ∝ K·σ_c·√h·√V·c·φ²/H` 使每个站位/年份的相对敏感性
  向量完全相同（48×6 矩阵秩 1，条件数 1e11）。条件数对这类链没有前向稳定性含义；
  改用放大因子 ‖S‖₂ 与 delta 法 vs MC 一致性。副产品：`K` 与 `H` 只以 K/H 进入磨蚀 → 反演不可辨识。
- **区间宽度一致性必须同预算比较**：单次 N=100000 vs 重复 N=5000 的宽度比恒为 √(5000/100000)=0.22，
  会伪判 FAIL。`replicate_ci_width(n_per_rep=...)` 必须与单次样本数一致。
- 模型太便宜（6 µs/次）时墙钟加速比失真（本例 1.02×），加速结论要用模型评估数比（260×）。
