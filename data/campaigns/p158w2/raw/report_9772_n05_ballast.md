## 1. 案例介绍

### 1.1 物理背景

压载水舱是散货船/油船的典型薄壁结构：舱壁板与加筋（纵骨/扶强材）在内部静水压 + 船舶运动惯性力下承受面外弯曲与面内压缩，失效模式有三类——板格/加筋屈曲（含防倾tripping）、角隅与舱壁-甲板连接处的疲劳裂纹、以及板格极限强度耗尽。工程上这三类失效由 IACS CSR（散货船/油船共同结构规范）以"屈服 / 屈曲 / 极限 / 疲劳"四类判据覆盖。本节点把这条链做成**可机器复算的闭环**：同一输入下从运动加速度 → 压力场 → 结构应力 → 四类判据逐项给出利用率与极限状态方程余量，并以 sha256 锚定输入。

## 2. 怎么做的

### 2.1 四验证面与公式

**A 水压力分布。** 船体以设计加速度 a₀=(a_x,a_y,a_z) 运动时，舱内液体准静态压力满足 ∇p = ρ(g⃗ − a₀)。取 a₀ 为舱室中心处的刚体加速度（规范惯用做法，舱室内的加速度极值另行取来构造规则包络），得到解析压力场

```
p(x,y,z) = ρ[ (g + a_z)(z_fs − z) − a_y (y − y_c) − a_x (x − x_c) ]
```

a₀ 为常量时该式严格满足 ∂p/∂y = −ρa_y、∂p/∂z = −ρ(g+a_z)，p=0 等压面就是倾角正确的自由面；零加速度严格退化为 ρgh。动压来源：横摇 θ̈ 与纵摇 φ̈ 在点位上的分量 a_z += θ̈(y−y_rc) − φ̈(x−x_pc)、a_y = −θ̈(z−z_roll_axis)、a_x = φ̈(z−z_pitch_axis)。规则包络取 p_rule = ρ[(g+a_v)(z_fs−z) + a_h·b/2]（a_v、a_h 为舱室范围内加速度极值），外部海水压力 p_ext = ρg·max(T−z,0) + 0.5ρgH_w（水线以上按指数衰减），校核净压 p_net = max(p_rule − p_ext, 0)。

**B 加筋板屈曲。** 五个模式并行计算弹性临界应力：

```
板格        σ_cr = k(α) π² D/(b² t),  k(α) = min_m (m/α + α/m)²,  D = Et³/(12(1−ν²))
筋弯曲(Euler) σ_E = π²EI/(A L²)      （I、A 含带板，带板宽 = 筋间距 s）
筋扭转(tripping) σ_Et = (GJ + π²E C_w/L_trip²)/I_p   （薄壁开口剖面）
腹板局部     σ_w = 4π²E/(12(1−ν²))·(t_w/h_w)²
板架整体     Huber 正交异性板 N_x = min_(m,n) (π²/a²)[D_x m² + 2H(na/b)² + D_y(na/b)⁴/m²]
```

控制模式取 σ_cr 最小者，折减用 EC3/CSR 同形柱曲线 Φ = ½[1+α_imp(λ−0.2)+λ²]、κ = 1/(Φ+√(Φ²−λ²))，λ = √(σ_y/σ_cr)，设计临界应力 = κσ_y。板格/筋/整体屈曲与船体梁面内压应力（IACS UR S11 波浪弯矩，复用 `hull_girder` 内核）比较；同时由净压算出筋弯曲应力 M = pₙsL²/12（两端固支）、板横向弯曲 σ = 6M_p/t²、腹板剪应力 τ = 1.5F/(h_w t_w)，供屈服判据使用。CSR 最小剖面模数要求 Z_req = pₙsL²/(12σ_allow) 与提供值对照。

**C 角隅应力集中与热点疲劳。** 角隅用 Neuber/Inglis 椭圆缺口解

```
K_t = 1 + 2√(a/ρ)          （ρ = 角隅半径, a = 缺口等效半轴）
Δσ_hs = K_t · Δσ_nominal · (t_ref/t)^0.2      （DNV-RP-C203 板厚修正, t_ref = 25 mm）
N = DNV-RP-C203 C 曲线(Δσ_hs)   →   寿命 = N / (年循环数)   （Palmgren-Miner 单块谱）
```

Δσ_nominal 由动压幅值按同一线性传力比放大得到（载荷→应力闭环，不是常数）。

**D IACS CSR 校核。** 四判据 + 极限状态方程 g = R − E：

| 判据 | 抗力 R | 荷载效应 E | 判据式 |
|---|---|---|---|
| 屈服 | σ_allow = σ_y/1.05 | von Mises √(σ_x²−σ_xσ_y+σ_y²+3τ²) | σ_eq ≤ σ_allow |
| 屈曲 | κ σ_y | 船体梁面内压应力 | σ ≤ κσ_y |
| 极限 ULS | min(φ_Faulkner σ_y, σ_u,PR, σ_y) | 面内压应力 | σ ≤ σ_u |
| 疲劳 | Δσ_allow(N_req) ／ 寿命 25 年 | K_t Δσ_nom 板厚修正 | 寿命 ≥ 25 年 |

极限强度两路：Faulkner (1975) 板格 φ = 2/β − 1/β²（β = (s/t)√(σ_y/E)）；Perry-Robertson 加筋柱 σ_u = ½[S − √(S²−4σ_yσ_E)]，S = σ_y+(1+η)σ_E。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 踩过的坑（已修正，留证）

1. **逐点加速度的压力场不是精确解。** 初版按每个测点的刚体加速度写 p，验收 probe 发现 ∂p/∂y ≠ −ρa_y（差 ~ρθ̈(z_fs−z_roll)）。原因是角加速度场旋度非零（∇×a = −2θ̈≠0），此时不存在严格静力平衡的压力场。改为**舱室中心单一设计加速度 + 线性自由面项**后，∇p = ρ(g−a₀) 精确成立（probe A3/A4 相对差 1e-12），与规范准静态做法一致。
2. **tripping 跨度必须显式给。** 初版 tripping 直接用筋跨距 L，导致参考工况屈曲判据被判死（UTR 1.19）。核查后确认不是公式错，而是**未计防倾肘板**：T 型细长筋的 tripping 临界应力对无肘板跨度极其敏感（σ_Et ∝ 1/L_trip²，L_trip 3.6→1.8 m 使 σ_Et 由 70.0 升到 141.4 MPa）。因此加 `tripping_span_m` 显式输入（默认＝筋跨距，保守），并把参考工况的 FAIL 与设计改进的 PASS 都作为判别力证据保留。
3. **规则包络必须单侧判据。** 包络 vs 物理场是"上界"关系而不是相等，写成相对差判据会在横向加速度小时误判；改为单侧不等式判据。
4. **柱曲线渐近收敛慢。** κλ²→1 的渐近在 λ=8 时仍差 4%，λ=16 才进 5% 带内，故判据明写 5% 带并把 λ 写进 note（避免把"收敛慢"误当实现错）。

### 5.2 局限（模块 LIMITATIONS 同源）

* 液体按刚体随船运动，**不含晃荡（sloshing）冲击压力**；半舱工况的剧烈晃荡需 CFD/模型试验，本模块只给准静态最不利自由面倾角。
* 等体积自由面取"过舱室中心"的一阶近似，倾角 ≲15° 误差 O(θ²)；更大倾角需按体积守恒重解。
* 规则包络的 a_h·b/2 项按横向距离线性简化，未区分纵横舱壁的分区冲击系数。
* 屈服/屈曲许用值用**可配置设计系数**（默认屈服 1.05、屈曲与 ULS 1.0），与本平台其它结构端点口径一致；不声称复刻某一版规范的全部系数表。
* 外底板/内底板的分工（压载舱底与海水侧的最不利组合）只按净压简化处理，未做完整的装载工况枚举。

### 5.3 适用范围

船体梁面内应力水平 σ_hg ≲ 0.6σ_y、板格长宽比 0.3 ≲ α ≲ 10、腹板高厚比 h_w/t_w ≤ 60、缺口等效半轴 a ≲ ρ 的邻域（K_t 近似）。超出该范围需用非线性 FE（含初始缺陷与焊接残余应力）复核。
